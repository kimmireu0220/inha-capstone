반영 상태: 아래 40장은 앞선 비교 연구의 발표 자료다. 2026-10-06의 S·T 유지·삭제 방법 검증은 아직 반영하지 않았다. 기존 인증 갱신이 실패해 계정 재연결이 필요하며, 최신 연구 상태는 [현재 상태](../CURRENT_STATUS.md)에서 확인한다.

[교수님 면담용 발표 자료](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

완료된 실험을 반영한 40장 발표 자료다. 1–20장은 초기 10단계 탐색과 웹 편집기 비교, 21장은 별도 합성 인물 3단계·18쌍 비교, 22–24장은 실제 인물 6명·108장 최종 요구 종합 비교다. 25–27장은 새 대화 4종·96장의 자동 상태 갱신 방법과 두 AI 평가·실패·비용을 설명한다. 28장은 전체 대화 상태 추출의 추가 48개 조건(고유 RGB 이미지 36종), 29장은 통합 결론, 30장은 자료 안내다. 31–40장은 초기 실험 부록이다.

추가 대조의 목표 충족은 1차 AI 127/288·2차 AI 142/288, 평균 ArcFace는 0.846995다. 얼굴 유사도와 요청 반영을 구분하며 AI 평가 방법과 평가자 간 점수 차이를 명시했다. 서로 다른 실험이나 인물 내 반복을 독립 표본으로 합산하지 않는다. 실제 인물 비교 사진은 논문의 공개 범위에 맞춰 싣지 않았다.

발표자 노트에 구두 설명과 원자료 링크를 기록했다. 기존 디자인의 제목·본문·배치를 유지하며 추가 결과와 결론을 갱신했다. 최종 40장을 한 번의 PDF 내보내기로 렌더링해 모두 시각 확인했으며 글자 겹침·잘림은 발견되지 않았다.
