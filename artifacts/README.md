# Google Slides

[교수님 면담용 발표 자료](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

이 자료는 2026년 9월 교수님 면담 당시의 33장 발표본이다. 합성 인물의 입력 정책 비교와 당시까지의 실험을 설명한다. 이후 추가한 실제 인물 6명·최종 요구 종합 108장 실험은 반영하지 않았다. 현재 논문 발표에 재사용할 때는 [논문](../paper/README.md)의 연구 질문·표본 수·결론으로 갱신해야 한다.

33장 모두 발표자 노트에 구두 설명과 근거 링크를 기록했다. 초기 실험은 합성 인물 6명에게 각각 10단계 편집을 한 번씩 진행한 실험으로 설명한다.

슬라이드의 비교 사례는 발표용 명칭으로 표시하고 시드 번호는 원자료에 보존한다.
