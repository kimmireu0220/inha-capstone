# 연구 발표 자료

[교수님 면담용 Google Slides](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

최신 논문 「반복 인물 이미지 편집에서 지시 검사를 이용한 상태 갱신」에 맞춘 10장이다. 2장은 초기 6인물·10단계 편집의 얼굴 변화와 원본 기반 생성 비교, 3장은 유지·삭제 구성요소 비교, 4장은 고정 코드로 새 요청 96개를 검증한 결과이다. 5장은 앞선 실제 인물 편집 사례, 6장은 전체 이력·검사 전 조건·검사 후 조건으로 생성한 새 비교 사진이다. 7–8장은 AI 평가 오류와 복합 요청 결과를 설명한다. 9장은 새 이미지 18장의 길이·요청 충족·얼굴 지표를 비교하고, 10장은 결과와 적용 범위를 정리한다.

[추가 상태 검증](../experiments/extended-state-validation-v1/RESULTS.md)은 네 가지 표현 틀의 대화 12개, 요청 96개로 구성하였다. 대화 단위 분석과 실제 코드 재생 결과는 발표자 메모에 기록했다.

마지막 요청의 평균 프롬프트는 204.00→122.67토큰으로 39.87% 줄었다. 7B AI의 목표 충족 수는 전체 이력 34/36, 검사 전 조건 24/36, 검사 후 조건 36/36이다. 얼굴 코사인은 검사 후 조건이 높았으나 전체 이력과 비교한 정렬 MAE·SSIM·LPIPS는 불리했다. 이 방향 차이와 3B·7B 평가 오류를 발표자 메모에 함께 기록했다.

표 4개와 원본 전체 영역의 이미지 7개는 Google Slides 기본 객체이다. 새 이미지 세 장은 고정 커밋 66723f7의 첫 생성 출력에 연결한다. [검수 기록](slides-verification.json)은 온라인 원문·표·이미지 해시·메모와 기본 미리보기를 대조한다. [논문과 실험 기록](../paper/README.md), [전체 연구 색인](../RESEARCH_INDEX.md)에 분석 근거를 연결했다.
