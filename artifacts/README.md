# 연구 발표 자료

[교수님 면담용 Google Slides](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

최신 논문 「반복 인물 이미지 편집에서 지시 검사를 이용한 상태 갱신」에 맞춘 10장이다. 1–2장은 한 번의 추출과 지시 검사 절차, 3장은 유지·삭제 규칙의 구성요소 비교, 4장은 두 모델에서 한 번 추출하는 방법의 새 요청 검증, 5–6장은 실제 인물의 편집 사례, 7장은 AI 이미지 평가 오류, 8장은 포즈·표정 복합 요청, 9장은 재검토 오류와 지시 검사, 10장은 구성요소 검증과 최종 결과를 다룬다.

새 요청 12개에서 Qwen3와 Llama 모두 한 번 추출과 지시 검사가 12/12였다. 추출·재검토와 같은 검사를 결합하면 각각 12/12와 4/12였고, 같은 최초 응답을 단순 적용하면 두 모델 모두 3/12였다. 제안 방법에는 요청당 모델 호출 한 번이 필요하다. 복원 표현 검증 32개와 실행 대상 검사 검증 16개의 결과, Llama의 0/16과 개발 자료 재계산도 발표자 노트에 설명했다.

표 3개와 본문은 편집 가능한 Google Slides 객체다. 실제 인물의 편집 출력 8개는 전체 영역과 원본 비율을 유지하고 사진 출처와 AI 편집 사실을 표시했다. 모델별 점수와 각 검증의 분모·실제 호출 횟수를 구분하여 적었다.

실제 미리보기 10장을 확인한 후 수치·표·노트·이미지 출처를 자동 대조한다. 결과는 [검수 기록](slides-verification.json)에 있다. 문구와 수치 연결은 `scripts/method_slides_content.py`, API 갱신은 `scripts/publish_method_slides.py`, 읽기 결과 대조는 `scripts/verify_method_slides.py`가 담당한다.

[초기 실험 상세 기록](실험_프롬프트와_상세수치.md)은 앞선 연구 자료이며 현재 구현과 결과는 [논문](../paper/README.md)과 [현재 상태](../CURRENT_STATUS.md)를 기준으로 한다.
