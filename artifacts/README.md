## 교수님 면담용 문체

이 자료는 정식 발표 원고가 아니라 교수님께 연구 진행 상황을 설명할 때 보여주는 자료다. 설명은 긴 완성형 문장 대신 짧은 항목·핵심어·수치 중심으로 작성한다. 예: `AI 생성 인물 6명 / 인물 3: 동일 원본으로 2회 반복`, `실험별 입력: 해당 인물 원본 1장`. 실험 조건과 해석의 한계는 짧게 남기고, 실제 영문 프롬프트·수치는 유지한다.

2026-09-12: Google Slides 1~24번의 한국어 설명을 면담용 핵심 표현으로 정리하고 화면을 검토했다. 25번은 기존 자료 링크 목록을 유지했다. 논문 본문이나 실험 결과를 변경한 작업은 아니다.

2026-09-13: 사람 평가 문항·결과 슬라이드 3장과 관련 문구·출처·설문 링크를 삭제했다. 당시 22장. 21장에 웹 편집기 기능 시험 요약(요청 처리 35/35, 실제 생성·복원)을, 22장에 `편집기 열기 · 로컬` 링크(http://localhost:8770/)를 반영했다. 이 링크는 해당 컴퓨터에서 local-studio 서버 실행이 필요하다. 기존 표지의 논문 PDF 링크는 유지했다.
