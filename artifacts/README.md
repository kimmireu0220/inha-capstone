본문은 초기 연구 발표 스냅샷이며 후속 실험 전체가 반영된 자료는 아니다. 최신 실험 범위와 결론은 [현재 상태](../CURRENT_STATUS.md)와 [논문 원고](../paper/README.md)를 기준으로 한다.

2026-09-11: 사용자 요청에 따라 Google Slides 1번 표지 왼쪽 아래를 `논문 PDF 열기` 링크로 변경했다. 연결 대상은 https://github.com/kimmireu0220/inha-capstone/blob/main/paper/manuscript.inha.pdf 이다. 논문 본문을 슬라이드로 재구성하지 않고 원고 링크만 추가했다. 이 링크 변경은 Google Slides에 적용했다.

## 교수님 면담용 문체

이 자료는 정식 발표 원고가 아니라 교수님께 연구 진행 상황을 설명할 때 보여주는 자료다. 설명은 긴 완성형 문장 대신 짧은 항목·핵심어·수치 중심으로 작성한다. 예: `AI 생성 인물 6명 / 인물 3: 동일 원본으로 2회 반복`, `실험별 입력: 해당 인물 원본 1장`. 실험 조건과 해석의 한계는 짧게 남기고, 실제 영문 프롬프트·설문 질문 원문·수치는 유지한다.

2026-09-12: Google Slides 1~24번의 한국어 설명을 면담용 핵심 표현으로 정리하고 화면을 검토했다. 25번은 기존 자료 링크 목록을 유지했다. 논문 본문이나 실험 결과를 변경한 작업은 아니다.
