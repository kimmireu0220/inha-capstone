# Google Slides

[교수님 면담용 발표 자료](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

이 자료는 2026년 9월 교수님 면담용 발표본에 2026년 10월 논문 결과를 반영하는 중인 39장 발표 자료다. 앞부분에는 초기 10단계 탐색과 웹 편집기 실험을 남겼다. 21장부터는 논문의 별도 합성 인물 3단계·18쌍 비교, 실제 인물 6명·108장 최종 요구 종합 비교를 설명한다. 25–27장에는 U1–U4 자동 상태 갱신의 96장 비교 방법, 두 AI 평가 결과, 실패와 한계를 추가했다. 각 실험의 인물 내 반복을 독립 표본으로 합산하지 않는다.

기존 36장과 새 3장의 발표자 노트에 구두 설명과 근거를 기록했다. 초기 실험은 합성 인물 6명에게 각각 10단계 편집을 한 번씩 진행한 실험으로 설명한다. 실제 인물 비교 사진은 논문의 공개 범위에 맞춰 싣지 않았다. 추가 대조 결과, 통합 결론과 자료 목록 갱신, 전체 시각 점검은 진행 중이다.

슬라이드의 비교 사례는 발표용 명칭으로 표시하고 시드 번호는 원자료에 보존한다.
