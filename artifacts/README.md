# 연구 발표 자료

2026-10-24 편집 계정의 API 인증을 갱신하고 최신 논문의 용어·정의·해석을 온라인 자료에 반영했다. 표에는 전체 상태 일치율·최종 상태 일치율·유지 위반 수를 사용하고, 발표자 노트에는 분자·분모와 유지 지시 위반의 정의를 적었다. 이미지 평가의 항목별 충족률과 상태 기록의 일치율을 구분한다.

[교수님 면담용 Google Slides](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

2026-10-25 최신 방법 논문을 반영한 10장이다. 1–2장은 연구 질문과 유지·삭제 검사, 3–4장은 유지·삭제 규칙 비교와 새 대화에서의 재검증, 5–6장은 입력이 달랐던 네 쌍의 전체 이미지, 7장은 AI 이미지 평가와 해석 범위, 8장은 포즈·표정을 포함한 복합 요청 실험, 9장은 표현 변화에서 찾은 구절 경계 오류와 정규화의 새 대화 검증, 10장은 논문과 재현 자료 안내다. 9장에는 기준 9/16, 기존 유지·삭제 10/16, 정규화 16/16의 결과와 대화별 개선 범위를 표시했다. 본문과 발표자 노트에서는 실험 목적을 나타내는 이름을 사용한다.

표 3개와 본문은 편집 가능한 Google Slides 객체다. 실제 인물의 편집 출력 8개는 전체 영역과 원본 비율을 유지했다. 사진 출처와 AI 편집 사실을 표시하고 발표자 노트에 설명과 근거 링크를 넣었다. S·T의 연구용 합성 대화와 실제 인물 사진을 구분하며, 실험별 표본 수와 같은 출력을 공유한 비교 쌍을 구분해 집계했다.

Google Slides의 실제 미리보기 10장을 모두 확인했다. 수치·표·노트·이미지 출처와 배치 확인 결과는 [검증 기록](slides-verification.json)에 있다.

슬라이드 문구와 수치 연결은 `scripts/method_slides_content.py`, API 갱신은 `scripts/publish_method_slides.py`, 읽기 결과 대조는 `scripts/verify_method_slides.py`가 담당한다. 내용 모듈은 Google 인증 없이 읽고 검사할 수 있다.

이전 40장의 스냅샷은 로컬 비공개 빌드 폴더에 보존하고, 과거 슬라이드 중간 기록과 갱신 도구는 Git 이력으로 정리했다. 실패 실험과 원자료는 재현 자료로 보존했다. [초기 실험 상세 기록](실험_프롬프트와_상세수치.md)은 역사 자료이며 현재 결과는 [논문](../paper/README.md)과 [현재 상태](../CURRENT_STATUS.md)를 기준으로 한다.
