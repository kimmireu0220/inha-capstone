# Google Slides

[교수님 면담용 발표 자료](https://docs.google.com/presentation/d/1UjTZ-HbxiGbb3QH2mnUWeFUk-_o9POx3Ay134fZ9qb8/edit)

발표 자료는 위 Google Slides에서 직접 편집한다. 현재 33장이다. 본문은 연구 질문, 두 방식의 이미지 비교, 자동 지표와 AI 평가, 웹 편집기, 6인물·18쌍의 웹 생성 결과를 설명한다. 영문 프롬프트와 세부 방법은 부록에 있다.

33장 모두 발표자 노트에 구두 설명과 근거 링크를 기록했다. 4장의 ‘10단계 편집 7회’는 인물 6명 중 인물 3을 두 번 실행한 횟수다.

슬라이드의 비교 사례는 발표용 명칭으로 표시하고 시드 번호는 원자료에 보존한다.
