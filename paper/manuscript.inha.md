# 반복 인물 이미지 편집에서 지시 검사를 이용한 상태 갱신

State Updates Using Instruction Validation in Iterative Portrait Editing

저자: 김미르, 장윤석

지도교수: 안남혁

## 초록

반복 이미지 편집에서 원본 사진을 재사용하려면 누적된 요청을 현재 편집 조건으로 정리해야 한다. 본 연구는 언어 모델이 한 번 추출한 변경 사항에 삭제·복원·유지 및 실행 대상 검사를 적용하는 방법을 제안한다. 합성 인물 6명의 10단계 편집에서 위치 보정 MAE·SSIM·LPIPS는 최종 6쌍 모두 원본 기반 재생성에 유리하였다. 새 합성 영어 요청 96개에서 Qwen3-4B의 전체 상태 일치는 첫 응답 단순 적용 52/96, 제안 방법 96/96이었고, Llama-3.2-3B-Instruct는 각각 27/96과 93/96이었다. 실제 인물 두 명에게 세 대화를 적용한 이미지 18장에서는 전체 요청 이력을 현재 조건으로 바꾸어 평균 프롬프트 길이를 204.00토큰에서 122.67토큰으로 39.87% 줄였다. 7B AI 평가의 목표 충족 수는 전체 이력 34/36, 지시 검사 후 조건 36/36이었다. 얼굴 보존 지표의 변화 방향은 측정 항목에 따라 달랐다. 상태 갱신 평가는 여섯 편집 항목과 지정한 영어 문형의 합성 대화를 대상으로 하였다.

주요어: 반복 인물 이미지 편집, 상태 갱신, 지시 검사, 프롬프트 작성

## Abstract

Original-referenced portrait editing requires compiling accumulated requests into current editing conditions. We propose a method that extracts changes once and checks removal, restoration, preservation, and instruction eligibility. In an initial ten-step experiment on six synthetic people, original-referenced regeneration was closer to the source on all six final pairs using registered MAE, SSIM, and LPIPS. On 96 new synthetic English requests in twelve eight-request dialogues, direct application and the proposed method matched 52/96 and 96/96 full reference states for Qwen3-4B, and 27/96 and 93/96 for Llama-3.2-3B-Instruct, respectively. The implementation was frozen before evaluation. A follow-up comparison generated eighteen images from two real-person photographs and three dialogues. Compiling checked current conditions reduced the mean final prompt length from 204.00 to 122.67 tokens, a 39.87% reduction. A post-hoc Qwen2.5-VL-7B evaluator scored 34/36 target attributes for full request histories and 36/36 for checked conditions. Facial preservation metrics showed mixed directions across input forms. State-update evaluation used six editing attributes and supported English instruction forms in AI-generated synthetic dialogues.

## 1. 서론

자연어 지시를 이용한 이미지 편집은 사용자가 원하는 변화를 문장으로 입력하고, 입력 사진의 일부 속성을 수정하는 방식이다. InstructPix2Pix는 입력 이미지와 편집 지시를 함께 조건으로 사용하는 모델을 제시하였으며[1], ChatEdit는 얼굴 이미지 편집을 여러 차례의 대화로 확장하였다[2]. 이러한 편집 환경에서는 한 번의 요청을 반영하는 능력과 함께, 대화가 이어지는 동안 사용자가 유지하거나 취소한 조건을 구분하는 능력이 요구된다.

인물 사진의 반복 편집에서는 변경할 속성과 보존할 속성이 동시에 존재한다. 사용자는 재킷이나 장신구, 배경을 바꾸면서도 얼굴과 자세는 유지하기를 원할 수 있다. 또한 새 요청이 앞선 요청을 대체하기도 한다. 은색 목걸이를 추가한 뒤 금색으로 바꾸고 다시 제거하도록 요청했다면, 마지막 편집에는 목걸이가 없어야 한다. 반면 목걸이를 최초 사진의 모습으로 되돌리라는 요청은 원본의 목걸이를 보존하는 지시이다. 대상이 같은 문장이라도 삭제와 원본 복원은 서로 다른 결과를 요구한다.

편집을 반복하는 방법은 입력 이미지의 선택에 따라 나눌 수 있다. 순차 편집은 직전 출력을 다음 편집의 입력으로 사용하므로 앞선 결과를 자연스럽게 이어갈 수 있다. 다만 출력에 생긴 변화도 다음 입력에 포함된다. 원본 기반 재생성은 최초 사진에 현재의 전체 편집 조건을 적용한다. ChatEdit는 원본 이미지를 편집하는 구조를 통해 오류 누적과 속성 망각을 다루었다[2]. 본 연구의 초기 합성 인물 실험에서도 동일한 최종 요구를 적용한 여섯 쌍의 위치 보정 얼굴 지표가 원본 기반 방식에 유리하였다. 이를 바탕으로 최초 사진을 재사용하되, 그 사진에 전달할 편집 조건을 관리하는 문제에 초점을 맞추었다.

원본을 재사용할 때 이전 요청을 모두 전달하면, 이미지 생성 모델이 대화 전체에서 현재 유효한 요구를 다시 판단해야 한다. 반대로 마지막 요청만 전달하면 앞서 지정한 의상이나 배경이 누락될 수 있다. 따라서 전체 이력과 마지막 문장 사이에서, 지금도 유효한 편집 내용을 명시적으로 표현할 필요가 있다. 본 연구에서는 재킷·상의·핀·목걸이·배경·소품의 값을 각각 저장하고, 새 요청이 들어오면 변경할 항목만 갱신한다. 이렇게 저장한 항목과 값의 집합을 편집 상태라 정의한다. 이미지 생성에는 원본 사진과 현재 편집 상태를 문장으로 변환한 프롬프트를 사용한다.

편집 상태를 저장하더라도 새 요청의 의미를 잘못 적용하면 오류가 남는다. 예를 들어 “목걸이를 없애고 배경은 유지하라”는 요청에서 언어 모델이 두 항목을 모두 원본 복원으로 추출하면, 목걸이가 다시 생기거나 배경이 이전과 달라질 수 있다. 캡션에 인용된 편집 문장을 실제 명령으로 적용하는 경우도 구분해야 한다. 상태 갱신에는 속성값의 추출뿐 아니라 지시의 동작, 적용 대상, 실행 여부를 확인하는 절차가 함께 요구된다.

본 연구는 언어 모델이 한 번 추출한 변경 사항에 코드로 작성한 지시 검사를 적용하는 방법을 제안한다. 삭제는 대상의 부재로, 원본 복원은 최초 사진의 모습으로, 유지는 직전에 저장된 값의 보존으로 처리한다. 또한 지시 구절을 분리하고, 부정문·조건문·명시된 인용문의 적용 범위를 확인한다. 언어 모델은 변경 사항을 추출하고, 프로그램은 저장된 상태에 이를 반영하는 역할을 담당한다. 이 구조에서 별도의 재검토 호출이 정확도에 미치는 영향도 함께 비교한다.

실험은 편집 상태의 정확도와 이미지 생성 결과를 나누어 평가한다. 먼저 두 언어 모델에 동일한 새 요청 96개를 입력하여 전체 상태와 항목별 일치율을 측정한다. 다음으로 실제 인물 사진에 전체 요청 이력, 검사 전 현재 조건, 지시 검사 후 현재 조건을 각각 적용하여 프롬프트 길이와 생성 결과를 비교한다. 이를 통해 지시 검사가 요청 해석의 오류를 줄이는지, 현재 조건만으로 입력을 구성했을 때 편집 목표와 얼굴 보존 지표가 어떻게 달라지는지 분석한다.

본 논문의 구성은 다음과 같다. 2장에서는 자연어 이미지 편집, 대화 상태 추적, 모델 응답의 재검토에 관한 연구를 살펴본다. 3장에서는 편집 상태의 표현과 지시 검사 방법을 설명하고, 4장에서는 실험 자료와 평가 지표를 제시한다. 5장에서는 상태 갱신과 이미지 비교 결과를 분석하며, 6장과 7장에서 결과의 의미와 결론을 기술한다.

## 2. 관련 연구

### 2.1 자연어 지시를 이용한 이미지 편집

InstructPix2Pix는 입력 이미지와 편집 지시를 이용하여 수정된 이미지를 생성하는 조건부 확산 모델이다[1]. 언어 모델과 이미지 생성 모델로 편집 예제를 합성하고, 이를 이용해 자연어 지시를 따르는 편집 모델을 학습한다. 이 연구는 사용자가 목표 이미지 전체를 묘사하는 대신, 현재 이미지에 가할 변화를 문장으로 제시하는 방식을 다룬다.

실제 편집 요청의 다양성을 평가하기 위한 자료도 제안되었다. MagicBrush는 원본 이미지·편집 지시·목표 이미지로 이루어진 수작업 주석 자료이며, 한 차례의 편집과 여러 차례 이어지는 편집을 포함한다[3]. 자연어 이미지 편집을 평가할 때에는 생성 결과가 지시한 변화를 반영하는지와 원본의 다른 내용을 얼마나 보존하는지를 함께 살펴야 한다. 본 연구에서도 요청 충족 평가와 얼굴 보존 지표를 나누어 측정한다.

앞의 연구들은 이미지와 지시를 연결하는 학습 및 평가의 기반을 제공한다. 본 연구는 이 중 이미지 생성에 앞서 입력 지시를 구성하는 과정에 초점을 둔다. 사용자의 요청을 항목별로 저장한 뒤 마지막에 유효한 조건만 전달함으로써, 이미 취소된 값과 유지할 값을 구분한다. 따라서 비교 대상은 편집 모델의 학습 방식보다, 같은 원본에 제공하는 세 가지 입력 방식이다.

### 2.2 대화를 이용한 얼굴 이미지 편집

ChatEdit는 얼굴 이미지 편집을 위한 대화 자료와, 대화 처리 모듈 및 이미지 편집 모듈로 구성된 구조를 제안하였다[2]. 대화 처리 모듈은 전체 이력에서 현재 요청을 추적하고 응답을 생성하며, 이미지 편집 모듈은 추적한 요구를 최초 이미지에 적용한다. 직전 출력 대신 최초 이미지를 사용하는 설계는 반복 편집 중의 오류 누적과 속성 망각을 다루기 위한 것이다.

이 구조는 대화에서 얻은 요구와 이미지 편집을 연결한다는 점에서 본 연구와 관련된다. 본 연구에서도 최초 사진을 재사용하고, 이미지 생성에 필요한 조건을 언어 처리 단계에서 관리한다. 여기서 검증하는 문제는 원본 재사용 자체보다, 저장된 조건에 새 요청을 반영할 때 발생하는 삭제·복원·유지의 혼동이다. 동일한 추출 응답에 지시 검사를 적용한 경우와 적용하지 않은 경우를 비교하여 이 처리의 효과를 살핀다.

본 연구의 편집 상태는 지정한 여섯 항목의 값을 명시적으로 저장한다. 따라서 오류를 추적할 때 이미지의 인상만으로 판단하는 대신, 어느 요청에서 어떤 항목이 정답과 달라졌는지 확인할 수 있다. 생성된 이미지의 편집 목표 충족 여부는 이 상태 평가와 별도로 분석한다.

### 2.3 항목별 대화 상태 갱신

대화 상태 추적은 대화 중에 나타난 사용자의 목표를 항목과 값으로 유지하는 과제이다. SOM-DST는 대화 상태를 고정된 크기의 메모리로 보고, 항목별 갱신 동작을 예측한 뒤 필요한 값만 생성하는 방법을 제안하였다[4]. 전체 상태를 매번 새로 생성하는 대신 변경할 부분을 선택하여 갱신한다는 점이 특징이다. 이 연구는 상태 갱신 동작의 정확도가 최종 상태 추적 성능과 연결됨을 분석하였다.

인물 이미지 편집에서도 새 요청에 언급되지 않은 속성은 직전 값을 유지하고, 변경 대상만 갱신해야 한다. 본 연구는 이러한 선택적 갱신의 관점을 적용하여 언어 모델이 새 요청의 변경 사항만 추출하도록 구성한다. 다만 대상은 인물 편집을 위한 제한된 속성이며, 삭제·원본 복원·유지는 각각 ‘없음’·‘원본’·‘직전 값 보존’으로 정의한다. 예를 들어 같은 목걸이를 대상으로 하더라도 제거하는 동작과 원본의 목걸이로 되돌리는 동작을 상태값에서 구분한다.

변경 사항을 구조화된 값으로 얻는 것만으로는 지시의 적용 범위가 결정되지 않는다. “목걸이를 원본으로 돌리되 배경은 유지하라”는 문장에서는 복원과 유지가 서로 다른 항목에 적용되어야 한다. 이에 본 연구는 항목별 상태 저장에 지시 구절의 분리와 적용 대상 검사를 결합한다. 이 과정을 통해 값 추출의 오류와 저장 상태의 갱신 오류를 구분하여 분석한다.

### 2.4 언어 모델 응답의 재검토

Self-Refine은 모델이 생성한 첫 응답에 대해 스스로 피드백을 만들고, 이를 이용해 응답을 반복 수정하는 방법이다[5]. 추가 학습 없이 생성·피드백·수정을 수행하며, 여러 언어 과제에서 응답 개선을 평가하였다. 이러한 접근은 첫 응답에 오류가 있을 때 같은 모델의 재검토를 이용하는 비교 조건의 배경이 된다.

편집 상태의 갱신에서는 재검토가 변경값을 고치는 동시에, 이미 올바른 항목을 누락하거나 불필요한 변경을 추가할 수도 있다. 따라서 응답을 다시 생성하는 과정과, 생성된 응답을 상태에 적용하기 전에 검사하는 과정을 나누어 비교할 수 있다. 본 연구에서는 한 차례 재검토한 응답을 우선 사용하는 방법과 첫 응답만 사용하는 방법에 동일한 지시 검사를 적용한다. 이는 재검토 응답 선택의 영향과 코드 검사의 영향을 같은 입력에서 비교하기 위한 구성이다.

본 연구의 재검토 조건은 새 요청과 첫 추출 결과를 다시 입력하여 수정된 JSON을 얻는 한 차례의 절차이다. 이를 통해 편집 상태 갱신에서 한 차례의 응답 재검토를 사용하는 조건과 첫 응답에 코드 검사를 적용하는 조건의 차이를 분석한다.

## 3. 제안 방법

### 3.1 편집 상태의 표현과 처리 절차

반복 편집의 입력은 최초 사진, 직전까지 저장한 편집 상태, 새 편집 요청으로 구성한다. 출력은 요청을 반영한 새 상태와 이미지 생성 프롬프트이다. 편집 상태에는 재킷·상의·핀·목걸이·배경·소품의 여섯 항목을 저장한다. 각 값은 지정된 속성, ‘원본’ 또는 제거 가능한 항목의 ‘없음’이다. ‘원본’은 최초 사진의 모습이며, ‘없음’은 대상을 제거한 상태이다. 처음에는 모든 항목을 ‘원본’으로 설정한다.

상태 갱신은 변경 사항 추출, 값 검증, 지시 검사, 프롬프트 작성의 순서로 수행한다. 요청을 받으면 언어 모델이 변경할 항목과 값을 JSON 형식의 변경 목록으로 한 번 추출한다. 프로그램은 허용된 값을 항목별로 검사하고, 직전 상태를 복사한 뒤 변경 사항을 반영한다. 이어서 현재 요청의 삭제·복원·유지 대상과 실행할 지시를 확인한다. 최종 상태와 적용 근거를 저장하고, 현재 조건을 문장으로 바꾸어 원본 사진과 함께 이미지 생성 도구에 전달한다.

### 3.2 삭제·복원·유지 검사

삭제는 대상을 ‘없음’으로 바꾸고, 복원은 ‘원본’으로 바꾼다. 유지는 모델 응답을 적용하기 전의 값을 보존한다. 직전 배경이 파란색인 상태에서 배경 유지와 목걸이 삭제를 요청했다면, 모델이 두 항목을 모두 ‘원본’으로 추출해도 배경은 파란색, 목걸이는 ‘없음’으로 보정한다.

지시 동사와 항목 이름을 확인하여 적용 범위를 나눈다. 원본 복원 뒤의 leaving·preserving 구절은 유지 지시로 분리하고, bring back이나 source photo를 포함한 지원 표현은 표준 복원 지시로 바꾼다. 이 처리를 구절 정규화라 한다. keep the necklace off처럼 값 변경을 뜻하는 구절은 단순 유지로 처리하지 않는다. 검사에는 지정한 어휘와 문형을 사용하고, 나머지 변경은 모델의 추출 결과를 따른다.

### 3.3 현재 실행할 지시의 구분

부정 동작, if가 포함된 조건문, 캡션이나 인용문이라고 명시한 문장의 인용 범위를 검사한다. 항목의 마지막 언급이 이 범위 안에 있으면 직전 값을 보존한다. 같은 항목에 대한 직접 지시가 뒤에 나오면 그 지시를 적용한다. 부정 구절의 범위는 다음 동작 지시가 시작되는 곳에서 끝난다.

예를 들어 캡션 속 “Remove the pin”은 핀 삭제로 적용하지 않지만, 뒤에서 실제로 핀을 삭제하라고 요청하면 삭제한다. 다른 항목의 직접 변경도 함께 반영한다. 검사 결과에는 적용 항목과 근거 구절을 남긴다.

### 3.4 응답 선택과 프롬프트 작성

응답 선택과 지시 검사의 영향을 구분하기 위해 모델 응답의 수와 검사 적용 여부를 달리한다. 개발 단계의 기준 방법은 변경 사항 추출과 한 차례 재검토에 모델을 두 번 호출한다. 비교 조건은 첫 응답만 단순 적용하는 방법, 유효한 재검토 응답을 우선 적용하는 방법, 두 응답에 지시 검사를 결합하는 방법, 첫 응답에만 검사를 결합하는 제안 방법이다. 같은 요청에서 얻은 응답을 공유하여 응답 선택과 후처리의 차이를 비교한다.

프롬프트에는 저장된 현재 조건만 적는다. 변경된 이전 값과 취소한 조건을 지우고, 얼굴·표정·자세·인물 조명·카메라 구도에 대한 공통 보존 문구를 붙인다. 원본 사진에서 생성하므로 ‘원본’인 항목은 최초 사진의 모습을 유지하도록 기술한다. 지시 검사는 코드로 수행하며 제안 방법의 모델 호출은 요청당 한 번이다.

## 4. 실험 설계

### 4.1 실험 자료와 비교 조건

실험은 원본 기반 구성의 얼굴 보존 비교, 편집 상태 갱신의 정확도 평가, 실제 인물의 이미지 생성 비교로 구성하였다. 원본 기반 구성의 비교에는 합성 인물 6명에게 동일한 순서의 편집 10단계를 적용한 자료를 사용하였다. 순차 편집은 직전 출력에, 원본 기반 재생성은 최초 사진에 같은 최종 요구를 적용한다. 얼굴·표정·자세와 인물 조명은 유지하도록 요청하였다. 출력 크기는 1024×1536이며 순차 출력 60장과 원본 기반 최종 출력 6장을 분석하였다.

상태 갱신 실험에는 AI를 이용해 작성한 합성 영어 대화를 사용하였다. 정답은 대화 작성 시 정한 항목별 변경을 초기 상태에 순서대로 적용하여 계산하였다. 개발 자료로 규칙을 수정한 뒤, 코드·요청·정답·모델 설정을 고정하고 별도의 대화로 검증하였다. 앞선 비교는 세 대화의 서로 다른 요청 12개이며 Qwen3-4B와 Llama-3.2-3B-Instruct[6,7]에 같은 요청을 입력하였다. 모두 4비트 양자화 모델이고 온도 0, 최대 출력 260토큰, 공통 예시 7개를 사용하였다. 비교용 추출·재검토 응답은 모델별 24개, 총 48개를 저장하였다.

주 비교 자료는 코드와 모델 설정을 그대로 고정한 뒤 새 대화 12개에 요청을 여덟 개씩 적용한 96개이다. 네 가지 표현 틀에 세 가지 속성 조합을 배정하고 삭제·복원·유지·부정·인용·조건·뒤 직접 지시를 조합하였다. 조건문·명시된 인용문·부정 지시는 즉시 실행하지 않고, 뒤에 나온 직접 지시를 적용하는 정책으로 정답을 구성하였다. 중간 요청의 순서를 바꾸어 오류가 후속 상태에 미치는 영향도 관찰하였다. 모든 문장은 기존 검증 자료와 중복되지 않으며 정답은 채점에만 사용하였다. 두 모델에 동일한 96개를 각각 입력하여 최초 추출·재검토 응답 총 384개를 저장하였다.

구성요소 검증은 유지·삭제, 지시 구절의 분리, 복원 표현, 부정·조건·인용 지시를 차례로 다룬다. 각 검증에는 그 단계에서 고정한 구현을 적용하였다. 문장 구조 대조의 요청 36개는 서로 다른 문장 18개, 표현·순서 변경의 요청 48개는 서로 다른 문장 32개로 구성하였다. 같은 초기 설정과 후속 요청을 반복한 경우를 독립된 문장으로 세지 않았다. 복합 요청 실험은 별도 구현으로 여섯 항목에 몸 방향·손동작·표정을 더한 아홉 항목을 평가하였다. 요청 조건 세 종류와 목표 구성 네 개의 요청 네 개씩, 총 48개를 사용하였다. Qwen3-4B에 온도 0, 최대 출력 320토큰, 공통 예시 두 개를 적용하였다.

실제 인물 원본은 Pexels에 공개된 Monstera Production의 사진 두 장이다[8,9]. R01과 R02를 각각 512×336, 512×768 크기로 입력하였다. 앞선 유지·삭제 이미지 실험은 요청 32개·인물 두 명·두 방법의 128조건이다. 같은 원본과 프롬프트는 이미지를 공유하여 실제 출력은 66장이며, 방법 간 64쌍 중 입력이 다른 경우는 4쌍이다.

최종 방법의 이미지 비교에는 기존 세 대화의 마지막 요청을 사용하였다. 전체 요청 이력, Qwen3의 첫 응답을 단순 적용한 현재 조건, 같은 응답에 지시 검사를 적용한 현재 조건을 두 인물에게 각각 적용해 18장을 생성하였다. 모든 조건은 최초 원본에서 생성하고 첫 성공 출력을 보존하였다. 이미지 도구의 내부 모델 버전과 시드는 비공개이다. 정답 상태는 평가에만 사용하였다.

### 4.2 평가 지표

전체 상태 일치율은 요청 처리 후 모든 항목이 정답과 일치한 요청의 비율이다. 항목별 일치율은 전체 평가 항목 중 정답과 일치한 비율이며, 최종 상태 일치율은 마지막 요청에서 모든 항목이 맞은 대화의 비율이다. 유지 위반은 직전까지 맞았고 현재 요청에서도 보존해야 하는 값을 잘못 바꾼 횟수이다. 결과는 일치 건수/평가 건수로 표기하고, 같은 대화에 속한 요청의 의존성을 고려하여 건수와 비율을 비교하였다.

96개 요청의 주 비교에서는 대화 내 의존성을 고려하여 대화 12개를 단위로 20000회 복원 추출한 정확도 차이의 95% 백분위 구간을 계산하였다. 첫 응답 단순 적용과 제안 방법의 주 비교는 대화별 차이에 대한 4096개 부호 조합의 양측 무작위화 검정으로 분석하고, 두 모델의 p값에 Holm 보정을 적용하였다. 표현 틀을 공유하는 합성 자료 안에서의 변동을 측정하였다.

초기 얼굴 지표는 인물별 원본에서 정한 320×360 영역의 MAE·SSIM·LPIPS[10]이다. 원본과 출력의 위치 차이는 NCC로 ±64픽셀 안에서 찾고, 평활화 sigma 3을 주 분석으로 사용하였다. MAE와 LPIPS는 작을수록, SSIM은 클수록 원본에 가깝다. sigma 1과 6도 함께 비교하였다. 원본·출력 해시를 대조하고 저장 지표를 재계산하였다.

실제 인물의 얼굴 코사인 유사도는 InsightFace buffalo_l[11]로 측정하였다. 후속 이미지 18장은 랜드마크로 원본과 출력을 각각 112×112로 정렬한 뒤 MAE·SSIM·LPIPS도 계산하였다. 이 수치는 초기 실험의 320×360 영역과 전처리가 다르다.

편집 목표는 Qwen2.5-VL-3B의 4비트 모델[12]이 성공·실패·판단 불가로 한 번 평가하였다. 입력은 이미지와 여섯 목표이며 생성 방식과 프롬프트는 제공하지 않았다. 형식 오류와 판독 불가는 분모에 남기고 성공에서 제외하였다. 3B 응답의 오류를 관찰한 뒤 같은 이미지·목표 전체를 Qwen2.5-VL-7B로 사후 평가하였다. 두 평가의 원문과 점수를 각각 보존하였다.

프롬프트 길이는 공통 보존 문구를 포함한 문자열의 문자 수·단어 수·고정 Qwen3 토크나이저의 토큰 수이다. 세 대화에서 요청이 추가될 때마다 총 12개 묶음을 측정하였다. 모델 호출 수는 상태 갱신에 필요한 횟수이며, 시간과 요금은 측정하지 않았다.

### 4.3 재현 자료

요청·정답·모델 응답, 생성 이미지와 실행 설정은 연구 저장소에 공개하였다. 개발 자료의 재계산과 새 대화 검증은 실험별로 구분하였다. 코드로 구성한 상태 검사 1323개를 수행하였다. 기존 저장 응답 24개와 추가 검증의 첫 응답 192개를 실제 실행 코드에 재생하여 상태 갱신과 프롬프트 작성도 대조하였다.

### 5.2 한 번 추출하는 방법의 정확도

새 요청 96개에서 응답 선택과 지시 검사 적용 여부에 따른 전체 상태 일치율을 표 2에 제시하였다. 첫 응답만 단순 적용한 경우와 제안 방법은 같은 최초 추출 결과를 사용하므로, 두 조건의 차이는 지시 검사에 해당한다. 두 번 호출하는 조건은 같은 요청에 대한 재검토 응답을 추가로 사용한다. 별도의 기본 검증 요청 12개에서는 첫 응답 단순 적용이 두 모델 모두 3/12, 제안 방법이 모두 12/12였다.

| 방법 | 요청당 호출 수 | Qwen3-4B | Llama-3.2-3B |
| --- | --- | --- | --- |
| 첫 응답만 적용 | 1 | 52/96 | 27/96 |
| 재검토 응답 우선 | 2 | 48/96 | 9/96 |
| 추출·재검토+검사 | 2 | 96/96 | 44/96 |

## 6. 논의

### 6.1 편집 상태 갱신에서 지시 검사의 역할

전체 상태 일치율의 차이는 언어 모델이 추출한 값과 이를 저장하는 절차를 함께 설계해야 함을 보여준다. 동일한 첫 응답을 사용했을 때 Qwen3는 52/96에서 96/96, Llama는 27/96에서 93/96으로 높아졌다. 따라서 이 비교에서 얻은 개선은 더 많은 모델 응답을 생성한 결과보다, 추출값에 지시 검사를 적용한 효과로 볼 수 있다. 특히 항목을 바꾸는 동작과 그대로 두는 동작이 함께 등장하는 요청에서 적용 대상을 구분하는 처리가 중요하였다.

유지와 복원은 모두 이전 정보를 참조하지만, 참조하는 시점이 다르다. 유지는 직전에 저장된 값을, 원본 복원은 최초 사진의 모습을 참조한다. 유지 규칙을 넓게 적용하면 잘못 저장된 값도 그대로 남고, 복원 대상을 넓게 잡으면 유지할 항목까지 원본으로 바뀐다. 구성요소 검증에서 관찰한 오류는 이러한 동작을 하나의 값 변경으로 묶기보다, 동작과 대상의 조합으로 처리할 필요가 있음을 보여준다.

응답의 재검토도 같은 관점에서 해석할 수 있다. Qwen3에서는 첫 응답과 재검토에 검사를 적용한 결과가 모두 96/96이었지만, Llama에서는 각각 93/96과 44/96이었다. 재검토 응답에서 일부 초기 설정이 누락되면 이후 요청이 다른 항목을 바꾸더라도 빠진 값은 회복되지 않을 수 있다. 첫 응답과 코드 검사를 결합하는 구성은 이런 응답 교체를 줄이면서 요청당 한 번의 모델 호출로 상태를 갱신한다.

### 6.2 프롬프트 간결화와 생성 이미지의 관계

원본 기반 재생성에서는 현재 유효한 조건을 모두 전달해야 한다. 전체 요청 이력은 변경 과정을 보존하는 반면, 현재 조건은 그 과정에서 취소되거나 대체된 값을 제외한다. 세 대화의 마지막 프롬프트 길이는 전체 이력 평균 204.00토큰에서 지시 검사 후 122.67토큰으로 39.87% 감소하였다. 첫 요청에서는 상태를 명시하는 문장이 더 길었으나 요청이 누적된 이후에는 현재 조건을 전달하는 방식이 짧았다. 입력 길이의 이점은 대화 이력의 축적과 함께 나타난 결과이다.

생성 이미지의 목표 충족은 프롬프트 길이와 별도로 해석해야 한다. 7B 평가의 성공 항목은 전체 이력 34/36, 검사 전 조건 24/36, 검사 후 조건 36/36이었다. 검사 전 조건이 더 짧으면서도 성공 항목이 적었다는 점은, 문장을 줄이는 것만으로 편집 요구가 정확해지지는 않음을 보여준다. 이 비교에서 현재 조건의 정확성을 확보하는 과정이 입력 간결화와 함께 작용하였다.

얼굴 보존 지표는 다른 양상을 보였다. 검사 후 조건의 얼굴 코사인 평균은 전체 이력보다 높았지만, 정렬 MAE·SSIM·LPIPS는 전체 이력에 유리하였다. 얼굴 특징의 유사도와 픽셀·구조 차이는 서로 다른 측정값이다. 따라서 본 실험은 지시 검사에 따른 상태 정확도와 프롬프트 길이의 개선을 뒷받침하며, 얼굴 보존의 변화는 각 지표의 방향을 함께 제시하는 것이 적절하다.

### 6.3 자료 구성과 결과의 적용 범위

96개 요청은 네 가지 표현 틀에 속성 조합과 중간 지시 순서를 달리한 합성 영어 대화이다. 대화마다 여덟 요청을 이어서 적용하므로 앞선 상태 오류가 후속 결과에 미치는 영향까지 포함한다. 대화 단위로 계산한 구간과 대응 검정은 이러한 자료 구성 안에서 관찰된 정확도 차이를 나타낸다. 속성값과 동작의 조합을 통제한 검증이라는 점에서, 임의의 사용자 발화를 표집한 실험과 구분된다.

Llama의 세 오류는 인용문 뒤에 나온 원본 복원 표현에서 발생하였다. 잘못된 색 변경을 거부했더라도 복원 지시를 인식하지 못하면 직전 값이 남는다. 복원 표현 확장 전의 0/8과 재검토 응답의 초기 설정 오류가 이어진 0/16도 어휘 범위와 응답 선택이 결과에 미치는 영향을 보여준다. 지정한 여섯 항목과 지원 문형, 조건문·인용문을 실행하지 않는 처리 정책이 본 구현의 범위를 이룬다.

이미지 비교는 실제 인물 두 명과 세 대화에서 조건별 첫 출력 한 장을 사용한 여섯 대응 사례이다. 생성 도구의 내부 버전과 시드는 노출되지 않았으며, 얼굴 지표는 이 출력들의 기술통계이다. 또한 AI 평가에서는 형식 오류와 설명·점수 불일치가 관찰되었다. 이에 요청 해석의 정답 대조, 이미지의 목표 충족 판정, 얼굴 보존 지표를 구분하고 각각의 원자료와 판정 근거를 제시하였다.

## 7. 결론

본 연구는 반복 인물 이미지 편집에서 현재 유효한 편집 조건을 항목별로 저장하고, 언어 모델이 한 번 추출한 변경 사항에 지시 검사를 적용하는 방법을 제안하였다. 삭제는 대상의 부재로, 원본 복원은 최초 사진의 모습으로, 유지는 직전 값의 보존으로 구분하였다. 지시 구절의 분리와 부정·조건·인용 범위 검사로 각 동작의 적용 대상을 정하고, 갱신된 상태를 원본 사진에 적용할 프롬프트로 변환하였다.

새 합성 요청 96개에서 첫 응답 단순 적용과 제안 방법의 전체 상태 일치는 Qwen3 52/96과 96/96, Llama 27/96과 93/96이었다. 같은 추출 응답을 사용한 비교에서 지시 검사의 효과를 확인하였으며, 제안 방법은 상태 갱신에 요청당 한 번의 모델 호출을 사용하였다. Llama의 복원 표현 오류 세 개와 재검토 조건의 상태 누락은 코드의 어휘 처리와 응답 선택이 정확도에 영향을 주는 사례였다.

실제 인물 두 명의 생성 이미지 18장에서는 마지막 프롬프트 길이가 평균 204.00토큰에서 122.67토큰으로 감소하였고, 7B 평가의 목표 충족 수는 전체 이력 34/36에서 지시 검사 후 조건 36/36으로 높아졌다. 얼굴 보존 지표의 변화 방향은 측정 항목에 따라 달랐다. 이 결과는 원본 사진을 재사용하는 반복 편집에서, 변경 요청의 단순 축약과 함께 삭제·복원·유지의 의미를 보존하는 상태 갱신이 필요함을 보여준다.
