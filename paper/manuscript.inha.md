# 반복 인물 이미지 편집을 위한 유지 및 삭제 지시의 상태 갱신 제약

Explicit Preservation and Removal Constraints for State Updates in Iterative Portrait Editing

저자: 김미르, 장윤석

지도교수: 안남혁

## 초록

반복 이미지 편집에서는 변경할 내용과 유지하거나 삭제할 내용을 다음 프롬프트에 정확히 반영해야 한다. 본 연구는 언어 모델이 변경 사항을 추출하고 재검토한 뒤, 명시적인 유지·삭제 지시를 확인하는 후처리 규칙을 제안한다. 유지 규칙은 해당 항목의 이전 값을 보존하고 삭제 규칙은 값을 없음으로 설정한다. 적용 조건에 맞는 구절과 항목만 처리하고 근거 구절을 기록한다. 개발 후 별도로 구성하고 추론 전에 확정한 S 대화 8개 32턴에서 동일한 모델 응답에 네 방법을 적용했다. 여섯 항목이 모두 정확한 턴은 기준 방법 27, 유지 규칙만 27, 삭제 규칙만 28, 두 규칙 결합 29였다. 결합 시 마지막 상태가 정확한 대화는 6개에서 7개로 늘었고, 유지해야 할 항목을 잘못 변경한 횟수는 1건에서 0건으로 줄었다. 개선은 한 대화의 두 턴에서 나타났다. 추가 검증 T의 대화 8개 32턴에서도 정확한 턴이 28/32에서 29/32로 늘었으나, 변경을 항목별로 적용하는 처리를 더해도 결과는 같았다. 실제 인물 사진 2명의 이미지 평가에서 목표 충족 수는 3B 모델 기준 350/384에서 358/384로, 사후 7B 평가에서는 372/384에서 374/384로 늘었다. 다만 판단 불가 감소와 설명·점수 불일치가 포함되어 이미지 품질의 향상 여부는 판단하기 어렵다. 유지·삭제 규칙의 효과는 이번에 검사한 영어 문형과 합성 대화 범위에서 확인됐다.

주요어: 반복 이미지 편집, 요구 상태 관리, 명시적 유지, 명시적 삭제, 프롬프트 종합

## Abstract

Iterative portrait editing requires prompts to reflect requested changes while preserving or removing specified attributes. We implement preservation and removal rules after a language model extracts and reviews the requested changes. The rules process supported expressions and record the text that triggered each rule. We compare four methods using the same model responses on set S, eight synthetic English dialogues comprising 32 turns, finalized before inference. All six attributes were correct in 27/32 turns for the baseline, 27/32 for preservation alone, 28/32 for removal alone, and 29/32 for their combination. Correct final dialogue states increased from 6/8 to 7/8. The combination also reduced erroneous changes to previously correct attributes that should remain unchanged from one to zero. All gains occurred in two turns of one dialogue. On a further set T of eight dialogues and 32 turns, correct turns increased from 28/32 to 29/32 and correct final states from 7/8 to 8/8. Applying changes separately by attribute added no further gain. An image study with two portrait references produced 66 unique outputs for 128 conditions. The 3B evaluator scored 350/384 for the baseline and 358/384 for the combination, with six of the eight additional successes coming from previously unknown judgments. A post-hoc 7B evaluation scored 372/384 and 374/384. Both evaluators produced inconsistencies between explanations and scores, which limit conclusions about image quality. The rules reduced state errors in the tested English expressions and synthetic dialogues without additional model calls.

## 1. 서론

사용자가 인물 사진을 여러 번 편집하면 요청에는 추가, 변경, 유지, 삭제, 원본 복원이 섞인다. 예를 들어 배경은 그대로 두고 목걸이를 지우라는 요청을 전체 장면의 새 설명으로 바꾸면, 목걸이 삭제를 놓치거나 변경 대상이 아닌 배경까지 원본으로 되돌릴 수 있다. 원본 사진을 다시 참조하는 정책은 누적된 얼굴 변화를 줄이는 데 도움이 될 수 있지만, 잘못 정리한 목표까지 바로잡지는 않는다. 따라서 이미지 생성에 앞서 현재 요구 상태가 올바르게 갱신됐는지 확인해야 한다.

본 연구는 같은 언어 모델의 추출·재검토 결과에 유지·삭제 규칙을 적용했을 때 편집 상태의 오류가 줄어드는지 확인한다. 이를 위해 요청에 명시된 유지·삭제 지시를 검사하는 후처리 규칙을 구현했다. 각 규칙을 단독으로 적용한 결과와 함께 비교해 두 규칙이 각각 어떤 오류를 줄이는지 분석한다.

## 2. 관련 연구

ChatEdit는 대화에서 편집 상태를 추적하고 이를 이미지 편집에 사용하는 구조를 제시했다[1]. 본 연구도 이 구성을 따르며, 상태 갱신 뒤의 유지·삭제 검사에 초점을 맞춘다. SOM-DST는 상태 갱신 동작을 예측하고 필요한 값만 생성하는 접근을 제안했다[2]. 이러한 동작 기반 상태 갱신과 달리 본 연구는 동일한 모델 응답에 적용하는 제한 문형의 후처리 효과를 비교한다.

Self-Refine은 모델의 피드백과 수정을 반복하는 방법이다[3]. 본 연구의 기준 방법은 변경 사항 추출과 한 차례 재검토에 모델을 총 두 번 호출한다. 모든 비교 방법에 같은 두 응답을 사용해 후처리 규칙의 효과를 비교한다. 특히 유지 지시를 어기고 값을 변경하거나 삭제할 물체를 남기는 오류를 다룬다.

## 3. 방법

### 3.1 편집 상태와 기준 방법

현재 요구를 재킷, 상의, 핀, 목걸이, 배경, 소품의 여섯 항목으로 저장한다. 항목별로 허용된 속성 값과 원본을 사용하며 제거 가능한 재킷·핀·목걸이·소품에는 없음도 허용한다. 없음은 해당 대상을 제거하라는 요구이고 원본은 최초 사진의 상태를 복원하라는 요구이므로 서로 구별한다. 최초 상태는 모든 항목이 원본이다.

각 턴에서 Qwen3-4B-4bit[4]가 현재 요청의 변경을 JSON으로 추출하고, 같은 모델이 요청과 첫 응답을 받아 이를 재검토한다. 모델에는 정답 상태나 이전 정답을 제공하지 않는다. 이 실험의 추출기는 현재 요청만 읽으며 전체 대화나 방법별 이전 상태를 읽지 않는다. 따라서 두 호출의 원응답을 모든 방법에서 공유할 수 있다. 이전 상태의 적용과 검증은 이후 코드 단계에서 각 방법이 자기 상태를 대상으로 수행한다.

공통 코드는 허용 값 검사, 현재 값과 같은 변경의 생략, 명시적인 원본 복원을 처리한다. 그 다음 제안한 유지·삭제 제약을 적용한다. 정답은 모든 응답 저장 후 별도 채점에서만 사용한다. 완성된 상태는 동일한 문장 변환 함수를 거쳐 원본 사진에 대한 편집 프롬프트가 된다.

### 3.2 명시적 유지와 삭제

유지 규칙은 지원하는 항목 이름과 unchanged가 함께 있는 구절에서 해당 항목의 직전 값을 보존한다. keep만으로 유지 여부를 판단하면 keep the necklace off처럼 목걸이가 없는 상태를 요구하는 문장을 잘못 처리할 수 있다. 값 변경, 인용, 조건부 표현, 대명사, 같은 항목의 후속 언급, 지원 어휘 밖 표현에는 규칙을 적용하지 않고 모델의 추출·재검토 결과를 사용한다.

삭제 규칙은 명시적인 remove 구절에서 재킷, 핀, 목걸이, 소품의 값을 없음으로 설정한다. 상의와 배경은 삭제 대상에서 제외한다. 유지 규칙과 같은 적용 조건을 확인하고 항목, 적용 값, 근거 구절을 기록한다. 유지 규칙 다음에 삭제 규칙을 적용하며, 같은 항목이 뒤에서 다시 언급되면 앞의 유지 지시를 적용하지 않는다.

이 방법은 새 모델 학습이나 추가 추론 호출을 요구하지 않는다. 다만 제한 어휘와 문형에 의존한다. 과거 상태가 이미 틀렸다면 유지 규칙은 잘못된 값도 보존할 수 있으며, 지원하지 않는 표현의 의미 해석을 개선하지 못한다.

## 4. 실험 설계

### 4.1 개발 과정과 검증 대화

초기 개발 대화 P에서는 keep을 폭넓게 탐지하는 유지 규칙이 정확한 턴을 기준 30/32에서 32/32로 늘렸다. 그러나 후속 검사에서 off나 색 변경 요청을 유지 지시로 잘못 처리했다. 새 검증 대화 Q에서 이 규칙의 정확한 턴은 12/32였고, 적용 문형을 좁힌 유지 규칙은 기준과 같은 27/32였다. 문형을 좁혀도 마지막 상태가 정확한 대화는 6/8에서 5/8로 줄었다. 중간 턴의 잘못된 삭제는 막았지만 다음 턴의 실제 삭제 요청을 모델이 놓쳤기 때문이다.

Q 분석 후 유지·삭제 규칙을 결합하고 검증 대화 S를 새로 구성했다. S는 연구 보조 에이전트로 만든 영어 합성 대화 8개 32턴이다. 각 대화의 정답은 작성 시 지정한 항목별 변경을 순서대로 적용해 만들었다. 대화와 정답, 코드, 프롬프트, 모델 버전을 모두 추론 전에 확정했다. P·Q는 개발 자료이고 S는 후속 검증 자료이므로 결과를 따로 보고한다.

텍스트 모델 버전은 4dcb3d101c2a062e5c1d4bb173588c54ea6c4d25이며 온도 0, 최대 260토큰, 공통 예시 7개를 사용했다. 32턴에 두 번씩 총 64회 호출했다. 기준 방법, 유지 규칙만 적용, 삭제 규칙만 적용, 두 규칙 결합을 비교한다. 결합 방식의 채택 조건은 추론 전에 정했다. 기준보다 정확한 턴이 늘고, 마지막 상태가 정확한 대화가 줄지 않으며, 유지할 항목을 잘못 변경한 횟수가 늘지 않아야 한다. 두 단독 규칙보다 정확한 턴이 많을 때 결합의 추가 효과가 있는 것으로 판단한다.

### 4.2 평가 단위

각 요청에 따라 상태를 한 번 갱신하는 단위를 턴으로 부른다. ‘정확한 턴’은 여섯 항목이 모두 정답과 일치하는 턴 수, ‘정확한 항목’은 총 192항목 중 정답과 일치하는 수다. ‘최종 정답 대화’는 마지막 턴의 여섯 항목이 모두 맞는 대화 수다. ‘유지 오류’는 직전까지 정확했고 이번에도 유지해야 하는 항목을 잘못 변경한 횟수다. 같은 대화에 속한 턴들의 의존성을 고려해 유의성 검정 없이 건수와 비율을 비교한다.

이미지 실험은 S의 32턴, 실제 인물 사진 2명, 두 방법을 조합한 128조건이다. 원본 파일과 프롬프트가 같으면 한 번 생성한 이미지를 함께 사용해 총 66개 이미지를 생성했다. 방법 간 비교 64쌍 중 입력이 다른 경우는 두 턴과 두 인물을 조합한 4쌍이며, 나머지 60쌍은 같은 이미지를 사용한다. 내장 이미지 생성 도구의 첫 성공 출력을 사용했다. 이 도구는 내부 모델 버전과 시드를 공개하지 않아 동일 시드로 통제할 수 없었다. Qwen2.5-VL-3B-4bit[5]가 이미지와 목표를 받아 여섯 항목을 성공·실패·판단 불가로 평가했다. 평가 모델 버전은 46d4cf06a06ffc1a766c214174f9cbed2f45bcab이다. 평가 시 방법명과 생성 프롬프트는 제공하지 않았다. 얼굴 유사도는 InsightFace buffalo_l[6]의 코사인 유사도로 측정했다.

원본 사진은 Monstera Production의 Pexels 사진 6311573과 6311581이다[7,8]. 각각 512×336, 512×768 크기의 기존 실험 입력을 재사용했다. 그림의 의상·장신구·배경은 AI 편집 결과이며 사진 속 인물의 실제 행동이나 연구 참여를 나타내지 않는다.

### 4.3 재현 자료

S와 T의 요청, 정답, 모델 응답, 코드 해시를 저장했다. 이미지별로 입력 사진, 프롬프트, 첫 성공 출력, 평가 원문을 연결했다. 코드와 원자료는 연구 저장소의 request-contract-v3, isolated-contract-v1, contract-image-v3 폴더에 있다[9]. 개발 중 재계산한 결과는 별도 파일에 기록했다.

두 규칙을 결합했을 때 정확한 턴은 기준보다 2개 많아 사전 채택 조건을 충족했다. 유지 규칙만 적용한 경우보다 2개, 삭제 규칙만 적용한 경우보다 1개 많았다. 방법 간 차이는 S3의 3턴과 4턴에서 발생했다. S1, S2, S4, S5, S6, S8은 네 방법 모두 4턴이 정확했고, S7은 모든 방법에서 1/4였다.

### 5.2 유지와 삭제의 상호 보완 사례

S3의 3턴에서는 식물을 삭제하고 재킷은 유지하도록 요청했다. 기준 방법과 유지 규칙만 적용한 방법은 식물을 남겼고, 삭제 규칙은 식물의 값을 없음으로 바꾸었다. 이어진 4턴에서는 상의와 목걸이를 원본으로 돌리되 재킷과 연한 파란색 배경은 그대로 두도록 요청했다. 기준 방법과 삭제 규칙만 적용한 방법은 배경도 원본으로 바꾸었다. 유지 규칙은 배경을 보존했지만 이전 턴에서 남긴 식물까지 삭제하지는 못했다. 두 규칙을 결합했을 때만 두 턴 모두 정확했다.

삭제 규칙은 3턴의 식물 삭제 누락을, 유지 규칙은 4턴의 불필요한 배경 변경을 막았다. 두 규칙은 이 대화에서 서로 다른 오류를 처리했다.

### 5.3 항목별 적용을 결합한 추가 검증

항목별 적용은 한 항목의 오류 때문에 다른 유효한 변경까지 취소되는 것을 막는 처리다. S 결과를 본 뒤 이 처리를 유지·삭제 규칙에 추가해 재계산하자 정확한 턴이 32/32가 됐다. 추가 효과를 확인하기 위해 코드를 수정하지 않고 새 검증 대화 T의 8개 대화 32턴에 적용했다. 대화와 정답은 추론 전에 확정했다. 모든 방법이 같은 추출·재검토 응답 64개를 사용한 결과는 표 2와 같다.

| 방법 | 정확한 턴 | 정확한 항목 | 최종 정답 대화 | 유지 오류 |
| --- | --- | --- | --- | --- |
| 기준 방법 | 28/32 | 187/192 | 7/8 | 3 |
| 항목별 적용 | 28/32 | 187/192 | 7/8 | 3 |
| 유지·삭제 | 29/32 | 189/192 | 8/8 | 1 |
| 항목별 적용+유지·삭제 | 29/32 | 189/192 | 8/8 | 1 |

T에서도 유지·삭제 규칙은 정확한 턴과 최종 정답 대화를 각각 한 개 늘렸으며, 차이는 T7의 마지막 턴에서 발생했다. 항목별 적용을 추가한 결과는 유지·삭제 규칙만 사용한 결과와 같았다. 이에 따라 추가 처리 없이 유지·삭제 규칙을 사용하는 방법을 선택했다. S의 사후 재계산 결과와 새 대화 T의 검증 결과는 구분하며, 서로 다른 개발 단계에서 구성한 S와 T의 표본 수는 합산하지 않는다.

### 5.4 이미지 편집 결과

![그림 1 R01의 S3 비교에서 식물 삭제와 배경 유지에 따른 차이](figures/contract-R01.png)

![그림 2 R02의 동일한 네 조건 비교](figures/contract-R02.png)

그림 1과 2는 두 방법의 입력이 달랐던 네 쌍의 생성 이미지를 전체 영역으로 보여준다. 3턴에서 삭제 대상 식물이 기준 출력에는 남고 결합 출력에서는 사라진다. 4턴에서는 기준 출력에 식물과 원본 배경이 남아 있는 반면, 결합 출력에서는 식물이 사라지고 연한 파란 배경이 나타난다.

1차 AI 목표 충족은 기준 350/384와 결합 358/384였다. JSON 파싱 실패는 고유 평가 입력 68개 중 3개였다. 판독하지 못한 응답을 다시 채점하지 않고 판단 불가로 집계했다.

| 방법 | 목표 충족 | 판단 불가 | 6항목 모두 충족 | 얼굴 코사인 평균 |
| --- | --- | --- | --- | --- |
| 기준 방법 | 350/384 | 20 | 48/64 | 0.910458 |
| 유지·삭제 결합 | 358/384 | 13 | 50/64 | 0.910535 |

증가한 8개 성공 항목 중 6개는 판단 불가에서 성공으로 바뀌었고 실패에서 성공으로 바뀐 항목은 2개였다. R02 S3 3턴의 기준 평가가 JSON 대신 느낌표를 출력하여 6항목 모두 판단 불가가 된 영향이 크다. 또 같은 턴의 결합 출력에서는 소품이 없다는 설명과 ‘소품 없음’에 대한 실패 점수가 모순됐다. 따라서 증가분 전체를 실제 편집 오류의 해소로 해석하기 어렵다.

얼굴 코사인 유사도는 기준 평균 0.910458, 결합 평균 0.910535였다. 입력이 다른 네 쌍의 평균 차이는 +0.001237이지만 두 쌍은 증가하고 두 쌍은 감소했다. 나머지 60쌍은 같은 출력이므로 전체 평균 차이만으로 얼굴 보존의 개선 여부를 판단하기 어렵다.

1차 평가의 오류를 확인한 뒤, 평가 모델을 바꿔도 결과가 같은지 알아보기 위해 Qwen2.5-VL-7B-4bit로 전체 68개 이미지·목표 쌍을 다시 평가했다. 재평가 전에 대상과 설정을 확정했으며 목표 문구, 파서, 온도, 최대 토큰은 1차 평가와 같았다. 모델 버전은 fdcc572e8b05ba9daeaf71be8c9e4267c826ff9b이다. 3B와 7B 결과를 함께 보고한다. 같은 계열 모델을 사용한 사후 분석이므로 두 모델의 일치만으로 판정의 정확성을 확인할 수는 없다. 7B 평가에서 목표 충족 수는 기준 372/384, 결합 374/384였고 JSON 파싱 실패와 판단 불가는 없었다.

| 방법 | 목표 충족 | 판단 불가 | 6항목 모두 충족 |
| --- | --- | --- | --- |
| 기준 방법 | 372/384 | 0 | 56/64 |
| 유지·삭제 결합 | 374/384 | 0 | 58/64 |

| 인물·대화·턴 | 3B 기준 | 3B 결합 | 7B 기준 | 7B 결합 |
| --- | --- | --- | --- | --- |
| R01 S3 3턴 | 5/6 | 5/6 | 6/6 | 6/6 |
| R01 S3 4턴 | 5/6 | 6/6 | 5/6 | 6/6 |
| R02 S3 3턴 | 0/6 | 5/6 | 6/6 | 6/6 |
| R02 S3 4턴 | 4/6 | 6/6 | 5/6 | 6/6 |

7B에서 실패에서 성공으로 바뀐 두 항목은 R01 4턴의 소품과 R02 4턴의 배경이다. 3B의 두 항목은 R02 4턴의 소품과 배경으로, 두 평가가 공통으로 실패→성공으로 판정한 것은 R02의 배경 한 항목이다. 고유 평가 입력의 점수 일치는 판단 불가 포함 367/408, 두 모델 모두 판정 가능한 항목에서는 367/387이었다.

7B 모델에서도 설명과 점수가 일치하지 않는 경우가 있었다. 두 인물의 3턴 기준 출력에 식물이 보인다고 설명한 뒤 식물이 없다고도 설명하면서 모두 성공으로 채점했다. R02 4턴에서도 같은 소품 설명 모순이 나타났다. 표에는 평가 모델이 반환한 점수를 그대로 집계했다. 따라서 JSON 형식 오류의 감소와 실제 편집 정확도의 향상을 구분해야 한다.

앞선 개발 대화 P의 이미지 실험에서는 128조건에 대해 68개 이미지를 생성했다. 목표 충족 수는 기준 354/384, 유지 규칙 355/384였고 얼굴 코사인 평균은 각각 0.914851과 0.914108이었다. 입력이 다른 네 쌍 중 R01-P2-2의 소품 판정 하나만 판단 불가에서 성공으로 바뀌었다. 실패에서 성공으로 바뀐 항목은 없었으며 JSON 파싱 실패 4개와 설명·점수 불일치가 있었다.

## 6. 논의

Q에서는 keep을 폭넓게 탐지하는 규칙이 삭제나 값 변경 요청을 유지로 잘못 처리했다. 적용 문형을 좁히자 이 오류는 줄었지만 삭제 누락은 남았다. S3에서는 유지와 삭제를 각각 검사했을 때 배경의 불필요한 변경과 식물 삭제 누락을 함께 막았다. 이 결과는 유지 규칙의 적용 범위를 명확히 하고 삭제 지시를 별도로 확인할 필요성을 보여준다.

S와 T는 각각 8개의 연구용 합성 대화이며 개선은 S3와 T7에 집중됐다. 어휘와 문형이 제한되어 일반 사용자 대화에서의 평균 효과는 알 수 없다. 변경 사항 추출에 사용한 모델도 한 종류의 4B 모델이다. 추출기는 현재 요청만 읽으므로 대명사나 긴 대화의 맥락을 해석하는 성능은 이번 실험 범위에 포함되지 않는다.

이미지 실험은 인물 2명과 생성 도구 하나를 사용했고, 비교 64쌍 중 60쌍이 같은 출력을 공유했다. 두 AI 평가 모두 설명과 점수의 불일치가 있어 점수 증가를 전반적인 이미지 품질 향상으로 해석하기 어렵다. 얼굴 코사인 유사도는 특징 벡터의 유사성을 측정하므로 사람이 느끼는 인물의 동일성과 차이가 있을 수 있다.

## 7. 결론

언어 모델의 추출·재검토 뒤에 유지·삭제 규칙을 적용해 추가 모델 호출 없이 편집 상태의 오류를 줄였다. S에서는 삭제 누락과 불필요한 배경 변경을 함께 막았고, T에서는 정확한 턴과 최종 정답 대화가 각각 한 개 늘었다. 항목별 적용을 더해도 결과가 같아 유지·삭제 규칙만 사용하는 방법을 선택했다. 이 결과는 명시적인 영어 지시를 검사하는 후처리 규칙과 두 규칙이 각각 처리하는 오류를 보여준다. 일반 대화에서의 효과와 전반적인 이미지 품질 향상은 이번 실험으로 확인하지 못했다.
