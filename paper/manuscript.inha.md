# 반복 인물 이미지 편집을 위한 유지 및 삭제 지시의 상태 갱신 제약

Explicit Preservation and Removal Constraints for State Updates in Iterative Portrait Editing

저자: 김미르, 장윤석

지도교수: 안남혁

## 초록

반복 이미지 편집에서는 변경할 내용과 유지하거나 삭제할 내용을 다음 프롬프트에 정확히 반영해야 한다. 본 연구는 언어 모델이 변경 사항을 추출하고 재검토한 뒤 명시적인 유지·삭제 지시를 확인하는 후처리 규칙을 제안한다. 유지 규칙은 이전 값을 보존하고 삭제 규칙은 값을 없음으로 설정한다. 유지·삭제 규칙 비교 실험의 대화 8개 32턴에서 동일한 모델 응답에 네 방법을 적용하였다. 여섯 항목이 모두 정확한 턴은 기준 방법 27, 유지 규칙만 27, 삭제 규칙만 28, 두 규칙 결합 29였다. 새로운 대화 8개 32턴을 이용한 재검증에서도 정확한 턴이 28/32에서 29/32로 증가하였다. 포즈·표정을 포함한 복합 요청 실험의 12개 대화 48턴에서는 속성 지시를 혼합한 조건의 정확한 턴이 재검토 4/16에서 규칙 보정 16/16으로 증가하였다. 복합 요청 실험의 개선은 삭제를 원본 복원으로 잘못 해석한 오류를 삭제 규칙이 바로잡은 결과였다. 실제 인물 2명의 사진을 이용한 이미지 평가에서는 평가 모델의 설명과 점수가 일치하지 않는 사례가 나타났다. 정해진 영어 문형의 합성 대화에서 추가 모델 호출 없이 상태 갱신 오류를 감소시켰다.

주요어: 반복 이미지 편집, 요구 상태 관리, 명시적 유지, 명시적 삭제, 프롬프트 종합

## Abstract

Iterative portrait editing requires prompts to reflect requested changes while preserving or removing specified attributes. We apply explicit preservation and removal rules after a language model extracts and reviews the requested changes. Preservation retains the previous value, whereas removal sets an attribute to absent. In the preservation and removal rule comparison using eight synthetic English dialogues with 32 turns, all six attributes were correct in 27/32 turns for the baseline, 27/32 for preservation alone, 28/32 for removal alone, and 29/32 for their combination. In a replication using eight new dialogues and 32 turns, correct turns increased from 28/32 to 29/32. A separate complex-request experiment comprised 12 dialogues and 48 turns involving expressions and poses. For the condition combining these requests with attribute changes, preservation, removal, and restoration, correct turns increased from 4/16 after model review to 16/16 after rule correction. In this experiment, removal rules corrected confusion between removing an object and restoring its original state. An image study using two portrait references revealed inconsistencies between evaluator explanations and scores. The rules reduced state-update errors without additional model calls within the tested English patterns and synthetic dialogues.

## 1. 서론

반복 인물 이미지 편집에서는 속성의 추가·변경·유지·삭제와 원본 복원 요청을 편집 상태에 반영해야 한다. 예를 들어 배경은 그대로 두고 목걸이를 지우라는 요청을 전체 장면의 새 설명으로 바꾸면, 목걸이 삭제를 놓치거나 변경 대상이 아닌 배경까지 원본으로 되돌릴 수 있다. 원본 사진을 매번 편집 입력으로 사용하는 방식은 누적된 얼굴 변화를 줄이는 데 도움이 될 수 있지만, 편집 요청을 잘못 해석한 오류까지 바로잡지는 않는다. 따라서 이미지 생성에 앞서 편집 상태가 현재 요청을 정확히 반영하는지 확인해야 한다.

본 연구에서는 언어 모델이 추출하고 재검토한 변경 사항에 명시적 유지·삭제 제약을 적용하는 상태 갱신 방법을 제안한다. 유지 지시가 있는 항목은 직전 값을 보존하고, 삭제 지시가 있는 항목은 없음으로 설정한다. 동일한 모델 응답에 각 규칙을 단독 또는 결합하여 적용함으로써 유지 오류와 삭제 누락에 대한 각 규칙의 효과를 분석한다.

분석 대상은 이미지의 화질보다 생성 전에 작성되는 편집 상태이다. 상태의 정답은 요청에 명시한 변경을 누적하여 계산할 수 있으므로 이미지 평가 모델의 판단과 분리하여 검사한다. 본 연구의 기여는 유지와 삭제를 구분한 후처리의 구현, 동일 응답을 이용한 구성요소 비교, 포즈·표정을 포함하는 복합 요청에서의 오류 분석이다.

## 2. 관련 연구

ChatEdit는 대화에서 편집 상태를 추적하고 이를 이미지 편집에 사용하는 구조를 제시하였다[1]. 본 연구도 이 구성을 따르며, 상태 갱신 뒤의 유지·삭제 검사에 초점을 맞춘다. SOM-DST는 상태 갱신 동작을 예측하고 필요한 값만 생성하는 접근을 제안하였다[2]. 이러한 동작 기반 상태 갱신과 달리 본 연구는 동일한 모델 응답에 적용하는 제한 문형의 후처리 효과를 비교한다.

Self-Refine은 모델의 피드백과 수정을 반복하는 방법이다[3]. 본 연구의 기준 방법은 변경 사항 추출과 한 차례 재검토에 모델을 총 두 번 호출한다. 모든 비교 방법에 같은 두 응답을 사용해 후처리 규칙의 효과를 비교한다. 특히 유지 지시를 어기고 값을 변경하거나 삭제할 물체를 남기는 오류를 다룬다.

## 3. 방법

### 3.1 편집 상태와 기준 방법

편집 상태는 재킷, 상의, 핀, 목걸이, 배경, 소품의 여섯 항목으로 구성한다. 각 항목에는 지정된 속성 값 또는 ‘원본’을 저장한다. 제거 가능한 재킷·핀·목걸이·소품에는 ‘없음’도 사용할 수 있다. ‘원본’은 최초 사진의 상태로 복원하는 동작이며, ‘없음’은 대상을 제거하는 동작이다. 초기에는 모든 항목을 ‘원본’으로 설정한다.

각 턴에서 Qwen3-4B-4bit[4]가 현재 요청의 변경 사항을 JSON으로 추출한 뒤, 요청과 첫 응답을 입력받아 재검토한다. 추출기에는 현재 요청만 제공하며, 전체 대화와 방법별 이전 상태, 정답 상태는 입력하지 않는다. 이에 따라 모든 비교 방법에 동일한 두 모델 응답을 사용할 수 있다. 각 방법은 이 응답을 자신의 이전 편집 상태에 적용하고 검증한다.

모든 방법은 허용된 값인지 검사하고, 현재 상태와 같은 변경을 생략하며, 명시적인 원본 복원 요청을 처리한다. 제안 방법은 여기에 유지·삭제 제약을 적용한다. 정답은 평가에만 사용한다. 갱신한 상태는 공통 변환 함수로 편집 프롬프트를 작성하여 원본 사진과 함께 입력한다.

### 3.2 명시적 유지와 삭제

유지 규칙은 지원하는 항목 이름과 unchanged가 함께 있는 구절에서 해당 항목의 직전 값을 보존한다. keep만으로 유지 여부를 판단하면 keep the necklace off처럼 목걸이가 없는 상태를 요구하는 문장을 잘못 처리할 수 있다. 값 변경, 인용, 조건부 표현, 대명사, 같은 항목의 후속 언급, 지원 어휘 밖 표현에는 규칙을 적용하지 않고 모델의 추출·재검토 결과를 사용한다.

삭제 규칙은 명시적인 remove 구절에서 재킷, 핀, 목걸이, 소품의 값을 없음으로 설정한다. 상의와 배경은 삭제 대상에서 제외한다. 유지 규칙과 같은 적용 조건을 확인하고 항목, 적용 값, 근거 구절을 기록한다. 유지 규칙 다음에 삭제 규칙을 적용하며, 같은 항목이 뒤에서 다시 언급되면 앞의 유지 지시를 적용하지 않는다.

이 방법은 새 모델 학습이나 추가 추론 호출을 요구하지 않는다. 다만 제한 어휘와 문형에 의존한다. 과거 상태가 이미 틀렸다면 유지 규칙은 잘못된 값도 보존할 수 있으며, 지원하지 않는 표현의 의미 해석을 개선하지 못한다.

### 3.3 상태 갱신 절차

각 턴에서는 먼저 직전 상태를 복사하고 추출·재검토 응답에서 유효한 변경 사항을 선택한다. 이를 복사한 상태에 적용한 다음, 현재 요청에서 지원 문형에 해당하는 구절을 찾는다. 명시적인 유지 구절의 항목은 직전 값으로 되돌리고, 삭제 구절의 항목은 ‘없음’으로 설정한다. 따라서 유지 규칙이 참조하는 값은 모델 응답을 적용하기 전의 상태이다. 이 순서를 지키지 않으면 잘못 변경된 값을 다시 보존하게 된다. 최종 상태와 함께 적용 항목, 동작 및 근거 구절을 저장한다.

예를 들어 직전 배경이 파란색인 상태에서 배경 유지와 목걸이 삭제를 요청했다고 하자. 모델이 두 항목 모두 ‘원본’으로 추출하더라도 유지 규칙은 배경을 파란색으로, 삭제 규칙은 목걸이를 ‘없음’으로 보정한다. 구절의 의미를 확정할 수 없는 경우에는 규칙으로 값을 덮어쓰지 않는다. 이 처리는 정답 상태를 입력받지 않으며 현재 요청과 직전 상태만 사용한다.

## 4. 실험 설계

### 4.1 비교 방법과 검증 대화

초기 개발 대화에서는 keep을 폭넓게 탐지하는 유지 규칙이 정확한 턴 수를 기준 30/32에서 32/32로 증가시켰다. 그러나 후속 검사에서 off나 색 변경 요청을 유지 지시로 잘못 처리하였다. 후속 개발 대화에서 이 규칙의 정확한 턴은 12/32였고, 적용 문형을 좁힌 유지 규칙은 기준과 같은 27/32였다. 문형을 좁혀도 마지막 상태가 정확한 대화는 6/8에서 5/8로 감소하였다. 중간 턴의 잘못된 삭제는 막았지만 다음 턴의 실제 삭제 요청을 모델이 놓쳤기 때문이다.

후속 개발 결과를 분석한 뒤 유지·삭제 규칙 비교 실험을 설계하였다. 이 실험에는 연구 보조 에이전트로 만든 영어 합성 대화 8개 32턴을 사용하였다. 각 대화의 정답은 작성 시 지정한 항목별 변경을 순서대로 적용해 만들었다. 대화와 정답, 코드, 프롬프트, 모델 버전을 모두 추론 전에 확정하였다. 규칙 개발에 사용한 대화와 비교 실험에 사용한 대화의 결과는 따로 보고한다.

변경 사항 추출에는 Qwen3-4B의 4비트 양자화 모델을 사용하였다. 생성 온도는 0, 최대 출력 길이는 260토큰으로 설정하고 공통 예시 7개를 제공하였다. 32턴에 두 번씩 총 64회 호출하였다. 기준 방법, 유지 규칙만 적용, 삭제 규칙만 적용, 두 규칙 결합을 비교한다. 결합 방식의 채택 조건은 추론 전에 설정하였다. 기준보다 정확한 턴이 늘고, 마지막 상태가 정확한 대화가 줄지 않으며, 유지할 항목을 잘못 변경한 횟수가 늘지 않아야 한다. 두 단독 규칙보다 정확한 턴이 많을 때 결합의 추가 효과가 있는 것으로 판단한다.

### 4.2 평가 단위

각 요청에 따라 상태를 한 번 갱신하는 단위를 턴으로 부른다. ‘정확한 턴’은 여섯 항목이 모두 정답과 일치하는 턴 수, ‘정확한 항목’은 총 192항목 중 정답과 일치하는 수이다. ‘최종 정답 대화’는 마지막 턴의 여섯 항목이 모두 맞는 대화 수이다. ‘유지 오류’는 직전까지 정확했고 이번에도 유지해야 하는 항목을 잘못 변경한 횟수이다. 같은 대화에 속한 턴들의 의존성을 고려해 유의성 검정 없이 건수와 비율을 비교한다.

이미지 실험은 규칙 비교 실험의 32턴, 실제 인물 사진 2명, 두 방법을 조합한 128조건이다. 원본 파일과 프롬프트가 같으면 한 번 생성한 이미지를 함께 사용해 총 66개 이미지를 생성하였다. 방법 간 비교 64쌍 중 입력이 다른 경우는 두 턴과 두 인물을 조합한 4쌍이며, 나머지 60쌍은 같은 이미지를 사용한다. 내장 이미지 생성 도구의 첫 성공 출력을 사용하였다. 이 도구는 내부 모델 버전과 시드를 공개하지 않아 동일 시드로 통제할 수 없었다. 이미지 평가는 Qwen2.5-VL-3B의 4비트 양자화 모델[5]을 사용하였다. 이미지와 목표 상태를 입력하여 여섯 항목을 성공·실패·판단 불가로 판정하였다. 평가 시 방법명과 생성 프롬프트는 제공하지 않았다. 얼굴 유사도는 InsightFace buffalo_l[6]의 코사인 유사도로 측정하였다.

원본 사진은 Pexels에 공개된 Monstera Production의 인물 사진 2장이다[7,8]. 두 인물을 각각 R01, R02로 구분하고, 512×336, 512×768 크기로 입력하였다. 그림의 의상·장신구·배경은 AI 편집 결과이며 사진 속 인물의 실제 행동이나 연구 참여를 나타내지 않는다.

### 4.3 재현 자료

실험 코드와 대화, 정답, 모델 응답, 생성 이미지 및 평가 원문은 연구 저장소에 공개하였다[9]. 정확한 모델 버전과 실행 설정은 실험별 기록에 포함하였으며, 개발 중 재계산한 결과와 검증 결과를 구분하였다.

### 4.4 포즈와 표정을 포함한 복합 요청 실험

포즈·표정 요청과 속성 변경을 함께 처리하는 경우를 검사하기 위해 별도의 합성 대화를 구성하였다. 네 시나리오마다 단일·복합·혼합 조건의 4턴 대화를 작성하여 총 12개 대화 48턴을 사용하였다. 단일 조건은 표정만 변경하고, 복합 조건은 몸 방향과 손동작을 추가한다. 혼합 조건은 재킷·배경·식물·목걸이의 변경·유지·삭제·복원도 포함한다. 같은 시나리오의 표정 목표는 세 조건에서 같게 하였다.

복합 요청 실험은 기존 여섯 항목에 몸 방향·손동작·표정을 더한 아홉 항목을 사용한다. 어휘와 허용 값을 다시 정하고, 마침표로 구분한 유지·삭제·복원 구절을 검사하는 별도 구현을 사용하였다. 앞선 규칙 비교 및 재검증 실험과 달리 상태 항목과 규칙 구현을 확장하였다. 최초 추출만 사용하는 방법, 한 차례 재검토한 방법, 재검토 뒤 구절 규칙으로 보정한 방법을 비교하였다. 최초 추출은 턴당 한 번, 나머지 두 방법은 두 번 호출하며 규칙 보정에는 추가 호출이 없다.

Qwen3-4B-4bit의 온도를 0, 최대 출력을 320토큰으로 설정하고 공통 예시 두 개를 제공하였다. 전체 추론은 96회이며 방법 간 응답을 공유하였다. 코드·대화·정답·설정을 추론 전에 고정하였다. 모든 항목이 맞는 턴 수와 표정·몸 방향·손동작의 정확도를 따로 집계하였다. 조건 간에는 문장 길이와 지시 종류도 함께 달라지므로 결과 차이를 포즈 추가의 인과 효과로 해석하지 않는다.

생성 단계는 첫 번째 시나리오의 첫 턴을 세 조건에서 골라 두 원본 사진에 적용한 6장으로 따로 검사하였다. 선택 기준은 텍스트 결과 집계 전에 정하였다. 추출 모델의 출력 대신 정확한 요청을 직접 전달하고 첫 성공 이미지만 사용하였다. 단일·복합·혼합 조건의 시각적 목표는 각각 1·3·6개이며, Qwen2.5-VL-7B-4bit로 목표별 성공·실패·판단 불가와 설명을 받았다. 이는 방법 간 비교가 아닌 생성 단계의 예비 진단이다.

### 5.2 유지와 삭제의 상호 보완 사례

규칙 비교 실험의 세 번째 대화에서는 3턴에 식물을 삭제하고 재킷은 유지하도록 요청하였다. 기준 방법과 유지 규칙만 적용한 방법은 식물을 남겼고, 삭제 규칙은 식물의 값을 없음으로 바꾸었다. 이어진 4턴에서는 상의와 목걸이를 원본으로 돌리되 재킷과 연한 파란색 배경은 그대로 두도록 요청하였다. 기준 방법과 삭제 규칙만 적용한 방법은 배경도 원본으로 바꾸었다. 유지 규칙은 배경을 보존하였지만 이전 턴에서 남긴 식물까지 삭제하지는 못했다.

삭제 규칙은 식물 삭제 누락을, 유지 규칙은 배경 변경 오류를 각각 방지하였다. 두 규칙을 결합한 경우에만 두 턴의 여섯 항목이 모두 정답과 일치하였다.

### 5.3 새 대화에서의 재검증

항목별 적용은 각 항목의 변경을 개별적으로 검증하여 한 항목의 오류가 다른 유효한 변경까지 취소하는 것을 방지한다. 규칙 비교 실험의 사후 분석에서 이를 유지·삭제 규칙과 결합한 결과, 정확한 턴 수는 32/32였다. 추가 효과를 재검증하기 위해 새로운 대화 8개 32턴을 구성하였다. 대화와 정답은 추론 전에 확정하였으며, 앞선 사후 분석에 사용한 코드를 수정 없이 적용하였다. 모든 비교 방법에 동일한 추출·재검토 응답 64개를 사용한 결과를 표 2에 제시하였다.

| 기준 방법 | 28/32 | 187/192 | 7/8 | 3 |
| 항목별 적용 | 28/32 | 187/192 | 7/8 | 3 |

새 대화에서도 유지·삭제 규칙은 정확한 턴 수와 최종 정답 대화 수를 각각 한 개 증가시켰으며, 차이는 일곱 번째 대화의 마지막 턴에서 발생하였다. 항목별 적용을 추가한 결과는 유지·삭제 규칙만 사용한 결과와 같았다. 이에 따라 추가 처리 없이 유지·삭제 규칙을 사용하는 방법을 선택하였다. 규칙 비교 실험의 사후 분석과 새 대화에서의 재검증은 서로 다른 개발 단계에서 수행하였으므로 결과와 표본 수를 따로 집계하였다.

### 5.5 복합 요청에서의 삭제와 복원 혼동

| 요청 조건 | 최초 추출 | 재검토 | 규칙 보정 |
| --- | --- | --- | --- |
| 표정 | 16/16 | 16/16 | 16/16 |
| 표정·포즈 | 16/16 | 16/16 | 16/16 |
| 속성 지시 혼합 | 4/16 | 4/16 | 16/16 |

표 6은 아홉 항목이 모두 정확한 턴 수이다. 세 방법 모두 표정·몸 방향·손동작은 조건별 48항목을 정확히 처리하였다. 혼합 조건의 정확한 전체 항목 수는 최초 추출과 재검토가 각각 124/144, 규칙 보정이 144/144였다. 마지막 상태가 정확한 대화 수는 각각 0/4, 0/4, 4/4였다.

혼합 조건의 오류는 네 시나리오에서 같은 형태로 나타났다. 2턴의 식물 삭제와 3턴의 목걸이 삭제를 모델이 ‘원본’으로 추출하였고 재검토에서도 같은 값을 반환하였다. 식물 오류는 2~4턴, 목걸이 오류는 3~4턴에 남아 총 20개의 항목 오류로 집계되었다. 서로 다른 20종의 오류가 아니라 두 삭제 지시의 오류가 후속 상태에 누적된 결과이다. 사후에 삭제 규칙만 적용하여 재계산해도 48턴 모두 정확하였다. 복합 요청 실험에서는 유지·복원 규칙을 함께 적용한 추가 이점은 나타나지 않았다.

네 시나리오는 표정과 몸 방향이 다르지만 삭제·복원 문형은 공유한다. 따라서 16/16은 정해진 혼합 문형에 대한 결과이다. 이번 검사에서 포즈 자체의 추출 오류는 없었으며, 확인된 문제는 대상을 없애는 동작과 최초 사진으로 복원하는 동작의 혼동이었다.

이 오류를 분석한 뒤 포즈를 제외한 짧은 대조 요청 8개를 고정하고 같은 설정으로 16회 추가 추론하였다. 최초 추출과 재검토는 각각 7/8이 정확하였다. 식물·목걸이의 삭제·복원을 단독으로 요청한 네 경우는 모두 맞았다. 그러나 “Remove the plant. Restore the necklace to the original.”에서는 식물도 ‘원본’으로 추출하였다. 두 문장의 순서만 바꾼 경우는 정확하였다. 이는 사후 진단이며 복합 요청 실험의 48턴에 합산하지 않는다. 이 사례에서는 포즈가 없어도 삭제와 복원을 함께 요청하면 오류가 발생하였다.

### 5.6 복합 요청 이미지의 평가 오류

정확한 요청을 직접 입력한 이미지 6장의 AI 평가에서 두 인물 모두 복합 조건은 2/3, 혼합 조건은 5/6의 목표를 충족한 것으로 집계되었다. 실패 점수는 몸 방향에 부여되었으나 설명에서는 요청한 방향으로 회전했다고 서술하였다. 또한 설명이 각 목표 문장을 그대로 반복하였다. 단일 조건의 두 응답은 목표 하나에 점수 세 개를 반환하고 예시 설명을 복사하여 판독할 수 없었다. 두 응답은 모두 판단 불가로 처리하였다.

이 결과는 점수만으로 몸 방향의 성공 여부를 확정할 수 없음을 보여준다. 이미지와 평가에는 각각 첫 성공 출력과 최초 평가 응답을 사용하였다. 조건마다 목표 수가 다르고 각 인물·조건에서 한 장만 생성했으므로 2/3과 5/6을 생성 성공률이나 복잡도별 성능 차이로 해석하지 않는다.

## 6. 논의

유지와 삭제는 서로 다른 상태 갱신 동작을 요구한다. 유지 규칙은 직전 값을 보존하므로, 이전 턴에 남은 삭제 대상까지 제거하지는 않는다. 반대로 삭제 규칙은 명시된 대상을 제거하지만 다른 항목의 불필요한 변경을 방지하지는 않는다. 규칙 비교 실험의 세 번째 대화에서 두 규칙을 결합한 경우에만 식물 삭제와 배경 유지가 모두 정확했던 결과는 이러한 차이에 따른 것이다. 후속 개발 대화에서는 keep만으로 유지 여부를 판단하여 삭제·변경 요청을 오인하였다. 이에 따라 제안 규칙은 항목 이름과 명시적 유지·삭제 표현이 함께 있는 구절에 적용한다.

규칙 비교와 재검증에는 각각 정해진 영어 문형의 합성 대화 8개를 사용하였으며, 개선은 각 실험의 세 번째와 일곱 번째 대화에 집중되었다. 변경 사항 추출에는 한 종류의 4B 모델을 사용하였고, 매 턴 현재 요청만 입력하였다.

복합 요청 실험에서는 삭제를 원본 복원으로 해석한 오류가 재검토 뒤에도 남았다. 명시적인 동작에 값을 직접 대응시키는 규칙은 이 오류를 제거하였다. 규칙 비교 실험에서 나타난 유지·삭제의 상호 보완과 달리 복합 요청 실험의 개선은 삭제 규칙만으로 설명된다. 두 결과를 구분하면 어떤 규칙이 어떤 오류를 줄였는지 확인할 수 있다. 복합 요청 실험은 앞선 두 실험과 어휘·예시·구현이 달라 정확도와 표본 수를 별도로 집계하였다.

이미지 실험은 인물 2명과 생성 도구 하나를 사용하였고, 비교 64쌍 중 60쌍이 같은 출력을 공유하였다. 두 AI 평가 모두 설명과 점수의 불일치가 있어 점수 증가를 전반적인 이미지 품질 향상으로 해석하기 어렵다. 얼굴 특징 벡터의 코사인 유사도는 입력이 다른 네 쌍 중 두 쌍에서 상승하고 두 쌍에서 하락하였다.

## 7. 결론

본 연구에서는 언어 모델의 추출·재검토 결과에 명시적 유지·삭제 제약을 적용하는 상태 갱신 방법을 제안하였다. 정해진 영어 문형의 합성 대화를 이용한 규칙 비교 실험에서 유지 규칙은 불필요한 배경 변경을, 삭제 규칙은 식물 삭제 누락을 방지하였다. 두 규칙의 결합으로 정확한 턴 수는 27/32에서 29/32로 증가하였다. 새 대화에서의 재검증에서도 정확한 턴 수는 28/32에서 29/32로 증가하였으며, 항목별 적용을 결합한 경우와 동일한 결과를 보였다. 제안 방법은 추가 모델 호출 없이 유지 오류와 삭제 누락을 감소시켰다.

포즈·표정을 포함한 복합 요청 실험의 혼합 조건에서는 정확한 턴이 재검토 4/16에서 규칙 보정 16/16으로 증가하였다. 모델은 포즈와 표정을 정확히 추출했으나 삭제를 원본 복원으로 해석하였고, 삭제 규칙이 이를 바로잡았다. 정해진 동작의 상태 갱신을 명시적으로 검사하는 것이 동일 모델의 재검토 뒤에도 남은 오류를 줄였다.
