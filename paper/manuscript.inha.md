# 반복 인물 이미지 편집에서 지시 검사를 이용한 상태 갱신

State Updates Using Instruction Validation in Iterative Portrait Editing

저자: 김미르, 장윤석

지도교수: 안남혁

## 초록

반복 이미지 편집에서 원본 사진을 재사용하려면 누적된 요청을 현재 편집 조건으로 정리해야 한다. 본 연구는 언어 모델이 한 번 추출한 변경 사항에 삭제·복원·유지 및 실행 대상 검사를 적용하는 방법을 제안한다. 합성 인물 6명의 10단계 편집에서 위치 보정 MAE·SSIM·LPIPS는 최종 6쌍 모두 원본 기반 재생성에 유리하였다. 새 합성 영어 요청 96개에서 Qwen3-4B의 전체 상태 일치는 첫 응답 단순 적용 52/96, 제안 방법 96/96이었고, Llama-3.2-3B-Instruct는 각각 27/96과 93/96이었다. 실제 인물 두 명에게 세 대화를 적용한 이미지 18장에서는 전체 요청 이력을 현재 조건으로 바꾸어 평균 프롬프트 길이를 204.00토큰에서 122.67토큰으로 39.87% 줄였다. 7B AI 평가의 목표 충족 수는 전체 이력 34/36, 지시 검사 후 조건 36/36이었다. 얼굴 보존 지표의 변화 방향은 측정 항목에 따라 달랐다. 상태 갱신 평가는 여섯 편집 항목과 지정한 영어 문형의 합성 대화를 대상으로 하였다.

주요어: 반복 인물 이미지 편집, 상태 갱신, 지시 검사, 프롬프트 작성

## Abstract

Original-referenced portrait editing requires compiling accumulated requests into current editing conditions. We propose a method that extracts changes once and checks removal, restoration, preservation, and instruction eligibility. In an initial ten-step experiment on six synthetic people, original-referenced regeneration was closer to the source on all six final pairs using registered MAE, SSIM, and LPIPS. On 96 new synthetic English requests in twelve eight-request dialogues, direct application and the proposed method matched 52/96 and 96/96 full reference states for Qwen3-4B, and 27/96 and 93/96 for Llama-3.2-3B-Instruct, respectively. The implementation was frozen before evaluation. A follow-up comparison generated eighteen images from two real-person photographs and three dialogues. Compiling checked current conditions reduced the mean final prompt length from 204.00 to 122.67 tokens, a 39.87% reduction. A post-hoc Qwen2.5-VL-7B evaluator scored 34/36 target attributes for full request histories and 36/36 for checked conditions. Facial preservation metrics showed mixed directions across input forms. State-update evaluation used six editing attributes and supported English instruction forms in AI-generated synthetic dialogues.

## 1. 서론

사진을 여러 번 편집할 때는 새 변경 사항을 반영하면서 앞서 정한 조건도 유지해야 한다. 예를 들어 목걸이를 삭제하고 배경을 유지하라는 요청에서는 목걸이만 없어져야 한다. 삭제를 원본 복원으로 잘못 처리하거나 배경까지 바꾸면 사용자가 다시 수정해야 한다.

초기 이미지 실험에서는 합성 인물 6명에게 장신구·의상·배경을 10단계에 걸쳐 편집하였다. 최종 요구가 같은 순차 편집과 원본 기반 재생성을 비교하자, 얼굴 위치를 보정한 세 지표 모두 6쌍에서 원본 기반 방식에 유리하였다. 이에 따라 원본 사진에 현재 편집 조건을 적용하는 구성을 사용하였다.

원본을 재사용하려면 대화에 남은 요청을 정리해야 한다. 은색 목걸이 추가, 금색으로 변경, 목걸이 삭제를 차례로 요청했다면 최종 조건에는 ‘목걸이 없음’만 남아야 한다. 본 연구는 이 과정을 항목별 상태 갱신과 프롬프트 작성으로 나눈다. 언어 모델이 추출한 값을 적용하기 전에 지시의 대상과 범위를 검사하고, 저장한 현재 조건으로 편집 프롬프트를 작성한다. 상태 정확도, 모델 호출 수, 프롬프트 길이와 생성 이미지의 지표를 각각 비교한다.

## 2. 관련 연구

ChatEdit는 대화에서 편집 상태를 추적하고 이를 얼굴 이미지 편집에 사용하는 구조를 제시하였다[1]. SOM-DST는 상태 갱신 동작을 예측하고 필요한 값만 생성한다[2]. 본 연구도 항목별 상태를 저장하며, 모델이 추출한 값에 지시 검사를 적용하여 삭제·복원·유지의 혼동을 줄인다.

Self-Refine은 모델의 피드백으로 응답을 반복 수정하는 방법이다[3]. 본 연구에서는 한 차례 재검토한 응답과 첫 응답에 같은 지시 검사를 적용하여, 재검토에 따른 정확도와 호출 수의 차이를 비교한다.

## 3. 방법

### 3.1 편집 상태와 처리 절차

편집 상태에는 재킷·상의·핀·목걸이·배경·소품의 여섯 항목을 저장한다. 각 값은 지정된 속성, ‘원본’ 또는 제거 가능한 항목의 ‘없음’이다. ‘원본’은 최초 사진의 모습이며, ‘없음’은 대상을 제거한 상태이다. 처음에는 모든 항목을 ‘원본’으로 설정한다.

요청을 받으면 언어 모델이 변경할 항목과 값을 JSON으로 한 번 추출한다. 프로그램은 허용된 값을 항목별로 검사하고, 직전 상태를 복사한 뒤 변경 사항을 반영한다. 이어서 현재 요청의 삭제·복원·유지 대상과 실행할 지시를 확인한다. 최종 상태와 적용 근거를 저장하고, 현재 조건을 문장으로 바꾸어 원본 사진과 함께 이미지 생성 도구에 전달한다.

### 3.2 삭제·복원·유지 검사

삭제는 대상을 ‘없음’으로 바꾸고, 복원은 ‘원본’으로 바꾼다. 유지는 모델 응답을 적용하기 전의 값을 보존한다. 직전 배경이 파란색인 상태에서 배경 유지와 목걸이 삭제를 요청했다면, 모델이 두 항목을 모두 ‘원본’으로 추출해도 배경은 파란색, 목걸이는 ‘없음’으로 보정한다.

지시 동사와 항목 이름을 확인하여 적용 범위를 나눈다. 원본 복원 뒤의 leaving·preserving 구절은 유지 지시로 분리하고, bring back이나 source photo를 포함한 지원 표현은 표준 복원 지시로 바꾼다. 이 처리를 구절 정규화라 한다. keep the necklace off처럼 값 변경을 뜻하는 구절은 단순 유지로 처리하지 않는다. 검사에는 지정한 어휘와 문형을 사용하고, 나머지 변경은 모델의 추출 결과를 따른다.

### 3.3 현재 실행할 지시의 구분

부정 동작, if가 포함된 조건문, 캡션이나 인용문이라고 명시한 문장의 인용 범위를 검사한다. 항목의 마지막 언급이 이 범위 안에 있으면 직전 값을 보존한다. 같은 항목에 대한 직접 지시가 뒤에 나오면 그 지시를 적용한다. 부정 구절의 범위는 다음 동작 지시가 시작되는 곳에서 끝난다.

예를 들어 캡션 속 “Remove the pin”은 핀 삭제로 적용하지 않지만, 뒤에서 실제로 핀을 삭제하라고 요청하면 삭제한다. 다른 항목의 직접 변경도 함께 반영한다. 검사 결과에는 적용 항목과 근거 구절을 남긴다.

### 3.4 비교 방법과 프롬프트 작성

기준 방법은 변경 사항 추출과 한 차례 재검토에 모델을 두 번 호출한다. 비교 조건은 첫 응답만 단순 적용하는 방법, 유효한 재검토 응답을 우선 적용하는 방법, 두 응답에 지시 검사를 결합하는 방법, 첫 응답에만 검사를 결합하는 제안 방법이다. 같은 요청에서 얻은 응답을 공유하여 응답 선택과 후처리의 차이를 비교한다.

프롬프트에는 저장된 현재 조건만 적는다. 변경된 이전 값과 취소한 조건을 지우고, 얼굴·표정·자세·인물 조명·카메라 구도에 대한 공통 보존 문구를 붙인다. 원본 사진에서 생성하므로 ‘원본’인 항목은 최초 사진의 모습을 유지하도록 기술한다. 지시 검사는 코드로 수행하며 제안 방법의 모델 호출은 요청당 한 번이다.

## 4. 실험 설계

### 4.1 자료와 비교 구성

초기 이미지 실험은 합성 인물 6명에게 동일한 순서의 편집 10단계를 적용한 자료이다. 순차 편집은 직전 출력에, 원본 기반 재생성은 최초 사진에 같은 최종 요구를 적용한다. 얼굴·표정·자세와 인물 조명은 유지하도록 요청하였다. 출력 크기는 1024×1536이며 순차 출력 60장과 원본 기반 최종 출력 6장을 분석하였다.

상태 갱신 실험에는 AI를 이용해 작성한 합성 영어 대화를 사용하였다. 정답은 대화 작성 시 정한 항목별 변경을 초기 상태에 순서대로 적용하여 계산하였다. 개발 자료로 규칙을 수정한 뒤, 코드·요청·정답·모델 설정을 고정하고 별도의 대화로 검증하였다. 앞선 비교는 세 대화의 서로 다른 요청 12개이며 Qwen3-4B와 Llama-3.2-3B-Instruct[4,9]에 같은 요청을 입력하였다. 모두 4비트 양자화 모델이고 온도 0, 최대 출력 260토큰, 공통 예시 7개를 사용하였다. 비교용 추출·재검토 응답은 모델별 24개, 총 48개를 저장하였다.

추가 검증은 코드와 모델 설정을 그대로 고정한 뒤 새 대화 12개에 요청을 여덟 개씩 적용한 96개이다. 네 가지 표현 틀에 세 가지 속성 조합을 배정하고 삭제·복원·유지·부정·인용·조건·뒤 직접 지시를 조합하였다. 조건문·명시된 인용문·부정 지시는 즉시 실행하지 않고, 뒤에 나온 직접 지시를 적용하는 정책으로 정답을 구성하였다. 중간 요청의 순서를 바꾸어 오류가 후속 상태에 미치는 영향도 관찰하였다. 모든 문장은 기존 검증 자료와 중복되지 않으며 정답은 채점에만 사용하였다. 두 모델에 동일한 96개를 각각 입력하여 최초 추출·재검토 응답 총 384개를 저장하였다.

구성요소 검증은 유지·삭제, 지시 구절의 분리, 복원 표현, 부정·조건·인용 지시를 차례로 다룬다. 각 검증에는 그 단계에서 고정한 구현을 적용하였다. 문장 구조 대조의 요청 36개는 서로 다른 문장 18개, 표현·순서 변경의 요청 48개는 서로 다른 문장 32개로 구성하였다. 같은 초기 설정과 후속 요청을 반복한 경우를 독립된 문장으로 세지 않았다. 복합 요청 실험은 별도 구현으로 여섯 항목에 몸 방향·손동작·표정을 더한 아홉 항목을 평가하였다. 요청 조건 세 종류와 목표 구성 네 개의 요청 네 개씩, 총 48개를 사용하였다. Qwen3-4B에 온도 0, 최대 출력 320토큰, 공통 예시 두 개를 적용하였다.

실제 인물 원본은 Pexels에 공개된 Monstera Production의 사진 두 장이다[7,8]. R01과 R02를 각각 512×336, 512×768 크기로 입력하였다. 앞선 유지·삭제 이미지 실험은 요청 32개·인물 두 명·두 방법의 128조건이다. 같은 원본과 프롬프트는 이미지를 공유하여 실제 출력은 66장이며, 방법 간 64쌍 중 입력이 다른 경우는 4쌍이다.

최종 방법의 이미지 비교에는 기존 세 대화의 마지막 요청을 사용하였다. 전체 요청 이력, Qwen3의 첫 응답을 단순 적용한 현재 조건, 같은 응답에 지시 검사를 적용한 현재 조건을 두 인물에게 각각 적용해 18장을 생성하였다. 모든 조건은 최초 원본에서 생성하고 첫 성공 출력을 보존하였다. 이미지 도구의 내부 모델 버전과 시드는 비공개이다. 정답 상태는 평가에만 사용하였다.

### 4.2 평가 지표

전체 상태 일치율은 요청 처리 후 모든 항목이 정답과 일치한 요청의 비율이다. 항목별 일치율은 전체 평가 항목 중 정답과 일치한 비율이며, 최종 상태 일치율은 마지막 요청에서 모든 항목이 맞은 대화의 비율이다. 유지 위반은 직전까지 맞았고 현재 요청에서도 보존해야 하는 값을 잘못 바꾼 횟수이다. 결과는 일치 건수/평가 건수로 표기하고, 같은 대화에 속한 요청의 의존성을 고려하여 건수와 비율을 비교하였다.

추가 96개 검증에서는 요청의 대화 내 의존성을 고려하여 대화 12개를 단위로 20000회 복원 추출한 정확도 차이의 95% 백분위 구간을 계산하였다. 첫 응답 단순 적용과 제안 방법의 주 비교는 대화별 차이에 대한 4096개 부호 조합의 양측 무작위화 검정으로 분석하고, 두 모델의 p값에 Holm 보정을 적용하였다. 표현 틀을 공유하는 합성 자료 안에서의 변동을 측정하였다.

초기 얼굴 지표는 인물별 원본에서 정한 320×360 영역의 MAE·SSIM·LPIPS[10]이다. 원본과 출력의 위치 차이는 NCC로 ±64픽셀 안에서 찾고, 평활화 sigma 3을 주 분석으로 사용하였다. MAE와 LPIPS는 작을수록, SSIM은 클수록 원본에 가깝다. sigma 1과 6도 함께 비교하였다. 원본·출력 해시를 대조하고 저장 지표를 재계산하였다.

실제 인물의 얼굴 코사인 유사도는 InsightFace buffalo_l[6]로 측정하였다. 후속 이미지 18장은 랜드마크로 원본과 출력을 각각 112×112로 정렬한 뒤 MAE·SSIM·LPIPS도 계산하였다. 이 수치는 초기 실험의 320×360 영역과 전처리가 다르다.

편집 목표는 Qwen2.5-VL-3B의 4비트 모델[5]이 성공·실패·판단 불가로 한 번 평가하였다. 입력은 이미지와 여섯 목표이며 생성 방식과 프롬프트는 제공하지 않았다. 형식 오류와 판독 불가는 분모에 남기고 성공에서 제외하였다. 3B 응답의 오류를 관찰한 뒤 같은 이미지·목표 전체를 Qwen2.5-VL-7B로 사후 평가하였다. 두 평가의 원문과 점수를 각각 보존하였다.

프롬프트 길이는 공통 보존 문구를 포함한 문자열의 문자 수·단어 수·고정 Qwen3 토크나이저의 토큰 수이다. 세 대화에서 요청이 추가될 때마다 총 12개 묶음을 측정하였다. 모델 호출 수는 상태 갱신에 필요한 횟수이며, 시간과 요금은 측정하지 않았다.

그림 2는 조건부 지시와 인용문을 포함한 대화를 R02에 적용한 예이다. 목표는 녹색 재킷, 원래 흰 상의, 파란 핀, 목걸이 없음, 도서관과 돌 벤치이다. 검사 전 조건에는 인용문의 재킷 복원과 조건부 벤치 삭제가 남아 있었다. 검사 후에는 직접 지시만 반영하였다. 표 8–10의 집계는 이 예와 나머지 두 대화를 모두 포함한다.

## 6. 논의

초기 실험은 원본을 재사용하는 구성을 선택한 근거이며, 후속 실험은 원본에 전달할 조건을 정리하는 방법의 비교이다. 현재 조건만 전달하면 취소된 값을 지우고 요청 이력의 증가에 따른 입력 길이를 줄일 수 있다. 이번 세 대화에서는 마지막 프롬프트를 39.87% 줄이면서 7B 평가의 목표 충족 수가 34/36에서 36/36으로 증가하였다.

상태 오류는 모델의 추출과 후처리 양쪽에서 발생하였다. 유지 지시를 넓게 적용하면 잘못된 이전 값도 보존할 수 있고, 복원 지시의 범위를 넓게 잡으면 유지할 항목까지 원본으로 바꾼다. 지시의 동작과 적용 대상을 함께 검사해야 하는 이유이다. 또한 재검토가 정확한 첫 응답을 바꾼 사례는 호출을 추가하는 것만으로 오류를 줄일 수 없음을 보여준다.

요청 충족과 얼굴 보존은 다른 평가 항목이다. 프롬프트가 짧아진 후 코사인 평균은 높았지만 MAE·SSIM·LPIPS는 전체 이력보다 불리하였다. 이 이미지 비교는 인물 두 명, 대화 세 개, 시드가 노출되지 않는 도구의 첫 출력에 대한 기술통계이다. AI 평가도 형식 오류와 설명·점수 모순을 보였으므로 점수와 원문을 함께 제시하였다.

추가 96개 검증은 요청 수를 늘리고 대화 길이를 여덟 개로 확장하여 같은 구현을 다시 평가한 결과이다. 네 가지 표현 틀에 속성 조합을 바꾼 자료이며, 대화 단위 구간도 이 구성 안에서의 변동을 나타낸다. 상태 갱신 결과는 지정한 영어 표현과 편집 항목에서 얻었다. 복원 표현 확장 전의 0/8과 Llama의 0/16은 어휘 처리와 응답 선택에 따른 적용 범위를 보여준다. 오류가 시작된 요청과 후속 상태를 함께 보면 구현의 적용 범위가 드러난다.

## 7. 결론

반복 인물 이미지 편집에서 누적 요청을 현재 조건으로 정리하고, 한 번 추출한 변경 사항에 지시 검사를 적용하는 방법을 구현하였다. 초기 6인물 실험의 원본 기반 재생성 결과를 출발점으로 삭제·복원·유지를 구분하고, 부정·조건·인용 지시와 뒤의 직접 지시를 처리하였다.

추가 요청 96개에서 첫 응답 단순 적용과 제안 방법의 전체 상태 일치는 Qwen3 52/96과 96/96, Llama 27/96과 93/96이었다. 제안 방법의 모델 호출은 요청당 한 번이며, 대화 길이를 여덟 개로 늘린 조건에서도 같은 구현을 비교하였다.

실제 인물 두 명의 생성 이미지 18장에서 최종 프롬프트 길이는 평균 204.00토큰에서 122.67토큰으로 줄었다. 7B 평가의 목표 충족 수는 전체 이력 34/36, 지시 검사 후 조건 36/36이었다. 얼굴 지표는 측정 항목에 따라 방향이 달랐다.
