Iterative portrait editing requires updating stored editing conditions while respecting preservation, removal, and restoration instructions. We propose a state update method that combines a single extraction by a language model with instruction normalization and checks on which instructions should execute. The method separates restoration from preservation targets, handles explicitly supported negative, conditional, and quoted instructions, and respects later direct instructions about the same attribute. We compared 4-bit versions of Qwen3-4B and Llama-3.2-3B-Instruct on the same synthetic English requests. On twelve new requests, applying the initial response as a schema-only JSON patch matched 3/12 full reference states for each model; the proposed method matched 12/12 for both. Combining extraction, model review, and the instruction checks matched 12/12 and 4/12, respectively. The proposed method required one model call per request and achieved equal or higher accuracy than the method requiring two calls in this comparison. Separate component studies identified restoration errors and cases in which review corrupted a correct initial response. Evaluation used AI-generated synthetic dialogues within the specified English vocabulary and instruction forms. An accompanying image analysis recorded inconsistencies between AI evaluator explanations and scores.
