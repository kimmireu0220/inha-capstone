# 동작 분리와 명시적 복원 제약의 추가 고정 검증

2026-10-06. N 결과로 개발한 복원 제약을 고정하고 새 M1–M6 6대화·24턴에 적용한다. 전체 동작 분리 방법, 예시와 모델은 v2 그대로다. 일반 재검토에도 동일한 복원 제약을 적용한 강한 대조를 포함한다. 부정 복원, 나중에 다시 지정한 값, 인용문 무시를 포함해 제약의 과도한 강제도 검사한다. 개발자 작성 제한 어휘 대화이며 외부 사용자 표본이 아니다.

각 추론 방법은 같은 Qwen3-4B-4bit 리비전·온도0·260토큰×2회다. 전체 실제 호출은 96회이며 제약/거부 대조는 같은 출력을 재사용한다. 생성 전 코드·대화·예시·규칙 해시를 고정하고 완료된 출력은 수정하지 않는다. 추론 중 정답을 모델에 주지 않고 완료 후 채점한다.

주 지표는 전체 상태 정확 턴 수, 보조 지표는 최종 대화·항목 정확도와 미변경 훼손이다. 동작 분리+복원 제약이 일반 재검토+무변경 값 생략+동일 복원 제약보다 주 지표에서 높고 최종 대화·미변경 훼손에서 악화되지 않아야 이미지 단계로 진행한다. 같은 평가 대화에 맞춰 수정한 뒤 성공으로 재분류하지 않는다.

이미지 단계로 진행할 경우 M1–M6의 2턴과 4턴, 원본 R01/R02, 두 제약 적용 방법을 모두 비교한다. 같은 원본·프롬프트·생성 설정은 공유할 수 있으나 독립 생성으로 중복 계수하지 않는다. 총 48조건의 목표와 원본 얼굴 유사도를 분리해 평가한다. 실행 모델 경로는 별도 사용자 확인에 따른다. 이미지 생성 전 이미지 프로토콜에 조건·평가기준을 고정한다. 사람 평가 작업은 없다.
