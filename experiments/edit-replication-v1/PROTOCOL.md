# 타 인물 일괄/순차 재현 — 실행 전 계획

2026-09-09. P04 순서 실험 결과를 본 뒤 기존 P05/P06에서 재현을 확인한다. 두 원본은 출력 생성 전에 확인했다. 새로운 미관찰 인물이 아니며 기존 연구 인물의 새 조건 실험이다.

두 인물×두 반복×(batch 1회+SBP 순차 3회)=16회. P04에서 가장 좋은 순서를 고르지 않고 최초 예비 설계의 S→B→P를 유지한다. 원본에서 일괄 적용과 직전 입력에서 누적 적용을 비교하며 정확한 프롬프트는 edit-order-v1에서 복사한다. 모든 최종 요구는 같다. 두 반복은 출력을 공유하지 않고 새로 시작한다.

실행 순서는 seed20260910으로 블록별 경로를 섞는다. seed는 스케줄 전용이며 생성 seed/model version은 노출되지 않는다. 최대 3개의 독립 호출을 병행할 수 있다. 16회 상한, 첫 출력 보존, 품질 재시도 없음, 도구 실패 시 해당 경로만 중단하고 대체 API를 쓰지 않는다. 모든 출력1024×1536을 요구한다.

주 지표는 기존 인물별 얼굴 ROI의 원본/직전 대비 MAE·SSIM·LPIPS이다. 고정 ROI 주 분석, NCCsigma3 보조, sigma1/6 민감도. 피부 내부 3영역은 두 원본만 보고 plan.json에 고정하며 출력에 맞춰 조절하지 않는다. 피부 RGB MAE·SSIM·고주파MAE와 평균색/잔차 분리를 처음부터 함께 계산한다. 원본에서 고정한 영역은 출력의 큰 변형에 따라 피부 밖을 포함할 수 있으므로 영역 안에 유지되는지 별도 확인하되 점수를 이유로 영역을 바꾸지 않는다.

인물별 두 반복 값·평균·범위를 우선 보고한다. P04 결과와 동질적 독립 표본으로 단순 합산하지 않는다. 사람 등급·독립AI평가·동일인 정답·피부 열화 정답을 만들지 않는다. 두 인물로 모집단 일반화를 주장하지 않는다. 반복 간 우열이나 지표의 방향이 갈리면 모두 보고한다.
