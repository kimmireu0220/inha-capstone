# 편집 순서 6종 비교 — 실행 전 계획

2026-09-09. 기존 14회 예비 실험을 본 뒤 설계한 새로운 실험이다. 본 실험 출력은 아직 보지 않았다.

P04 기존 원본과 기존 얼굴 ROI [352,88,672,448]를 사용한다. 셔츠 남색(S), 배경 옅은 파랑(B), 오른쪽 가슴 은색 원형 핀(P)의 모든 6순열을 각각 두 번 실행한다. 매 단계 직전 이미지를 입력으로 쓰며 현재까지의 요구를 S/B/P 정규 순서로 나열한다. 최종 프롬프트는 모든 순열에서 같고 순서에 따른 프롬프트 문장 배열 차이를 없앤다. 모든 경로는 원본부터 새로 시작하며 같은 첫 편집이어도 출력을 공유하지 않는다. 각 반복 블록에 원본에서 세 요구를 한 번에 적용하는 batch 경로를 하나 포함한다.

38호출: 6순열×3단계×2반복=36, batch×2=2. 반복 블록마다 경로 순서를 실행 전에 seed 20260909로 섞고 각 단계의 경로를 그 순서로 실행한다. 이 seed는 실행 순서용이며 생성 seed는 노출되지 않는다. 독립 경로는 최대 3개를 동시에 실행할 수 있다. 호출 순서는 블록/단계/고정 경로 순서로 로그에 보존하고 실제 시작·종료 시각도 남긴다. 배치 동시성은 완전한 시간효과 통제가 아니다.

첫 단일 출력만 보존한다. 품질을 이유로 재시도하거나 선택하지 않는다. 크기는 1024×1536을 요구한다. 도구 실패는 기록하고 해당 경로를 중단하며 다른 API로 바꾸지 않는다. 총 38회 상한은 실패도 포함한다.

주 분석은 기존 얼굴 직사각형의 원본 대비 MAE/SSIM/LPIPS와 직전 입력 대비 같은 지표다. 직사각형이 배경을 일부 포함하므로 기존 이마·양 볼 세 영역의 MAE/SSIM/고주파 MAE도 처음부터 함께 보고한다. 고정 영역을 주 분석, NCC sigma3를 보조, sigma1/6을 민감도 분석으로 보존한다. 세 영역을 독립 표본으로 세지 않는다.

순서별 최종 2회 값·평균·범위를 보고한다. 첫 단계에서 같은 편집의 4회 출력을 함께 기술할 수 있으나 후속 단계 간 독립성을 주장하지 않는다. 단계×현재 추가 편집별 값은 각 4관측의 기술 통계로만 제시하며, 앞서 누적된 편집 집합이 달라 순수 주효과의 추정이라고 부르지 않는다. 동일 완료 요구 집합과 호출 횟수를 가진 S→B/B→S 등의 2단계 비교, 같은 마지막 편집을 가진 최종 경로 비교를 별도로 보고한다. 순서 간 모든 차이를 보존하고 가장 좋은 결과만 고르지 않는다.

P04 한 인물의 탐색 실험이며 유의성·모집단 일반화·검증된 열화 임계값을 주장하지 않는다. 내부 모델 버전과 생성 seed는 노출되지 않는다. 결과는 과거 날짜의 예비 실험과 별도로 분석하며 단순 합산하지 않는다. 인간 평가·독립 AI 평가·동일인 판정·피부 열화 정답을 생성하지 않는다.
