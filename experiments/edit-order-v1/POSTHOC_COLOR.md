# 피부 평균색과 잔차 분리 — 추가 진단

2026-09-09. 순서 실험의 첫 단계 12장 수치를 본 뒤 설계했다. 주 분석을 변경하지 않는 사후 탐색 분석이다. 배경 단독 변경의 피부 MAE가 다른 두 단독 편집보다 큰 이유를 점검한다.

기존 이마·양 볼의 각 RGB 영역에 대해 d=출력−원본, 채널별 평균 b=mean(d), 잔차 e=d−b를 계산한다. 원시 MAE, 평균색 오프셋의 절댓값 평균, 평균색 제거 잔차 MAE를 기록한다. MSE는 정확히 mean(d²)=mean(b²)+mean(e²)로 나뉘므로 이 항등식을 검사하고 평균색 항의 MSE 비율을 보고한다. 이는 수학적 성분 분리이며 조명이나 피부 열화의 인과적 비중이 아니다. 영역별로 평균을 제거하므로 실제 변화를 흡수할 수 있다.

이미지를 수정하거나 저장하지 않고 수치 배열만 분석한다. 고정 및 기존 NCC sigma1/3/6 좌표를 모두 사용한다. 원본 및 직전 입력 기준을 보존한다. 각 영역 값을 픽셀 수로 가중하며, 그룹의 비율은 평균 bias-MSE/평균 raw-MSE로 구한다. 선택한 일부 결과만 분석하지 않고 38장 모두 포함한다.

원본 자체와 원본 배열에 일정 RGB 오프셋을 가한 수치 제어에서 잔차가 0에 가까운지 확인한다. 오프셋 제어는 clipping 없이 수식의 성질만 검사한다. 사람 등급·독립 AI 평가·수정된 이미지 파일을 만들지 않는다.
