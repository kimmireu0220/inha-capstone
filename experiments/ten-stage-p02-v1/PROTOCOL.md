# P02 10단계 반복 실험

P02 공용 가상 인물 원본을 재사용한다. 기존 폐기 실험의 관찰 이력이 있어 완전히 미관찰 인물로 주장하지 않는다. 새 10단계 출력 1회이며 P01 프롬프트와 순서를 그대로 유지한다. 매 단계 직전 출력 1장만 입력한다. 각 단계 첫 성공 결과를 사용하고 품질 재시도 없이 10단계를 완료한다.

원본만 보고 얼굴 ROI를 정한 뒤 동일 좌표를 모든 출력·평가에 적용한다. 지표는 MAE·SSIM·LPIPS. 정상/열화 판정은 지표와 단계 번호를 가린 독립 에이전트의 자연스러움 0~3 등급으로 별도 수행한다. 2 이상인 첫 단계를 에이전트 기준 개입 후보로 삼고 직전 0~1 단계를 rollback 입력으로 사용한다. 이는 사람 확인된 정상 이미지가 아니다. 해당 단계가 없으면 개입을 억지로 생성하지 않는다.

자동 감지 후보는 P01의 2·3단계 점수 중간값으로 개발하고 P02 결과를 보기 전에 고정한다. MAE≥0.0288375, SSIM≤0.842874, LPIPS≥0.0555075 각각을 비교하고 LPIPS를 사전 지정 주 기준으로 삼는다. 임계값은 단일 개발 인물에 과적합될 수 있으며 P02 역시 최종 독립 검증군이 아닌 전이 가능성 탐색이다. 얼굴 크기·정렬의 영향과 에이전트 정답의 한계를 명시한다. 지표 기준 첫 경보와 에이전트 후보가 다르면 양쪽 시점을 보고하며 개입 후보 선택을 자동 감지 성공으로 바꾸지 않는다.

개입은 후보 단계 수정·직전 허용 단계 재편집·최초 원본 기반 현재 요구 일괄 적용 각 1회다. 요구 충족과 얼굴 보존을 별도 비교한다. 추가 사람 응답은 만들지 않는다.
