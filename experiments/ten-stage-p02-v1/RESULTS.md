# P02 10단계 반복 실험

P01과 같은 원문 프롬프트·순서로 P02의 10단계 순차 출력을 새로 생성했다. 공용 원본 재사용이며 폐기 실험의 관찰 이력이 있어 완전히 미관찰 인물의 독립 검증으로 주장하지 않는다. 각 단계 첫 성공 출력만 유지했다. 입력 연결·프롬프트 일치·1024×1536 크기·생성 원본과의 해시 일치를 verify.mjs로 검증했다.

## 얼굴 지표와 독립 평가

원본만 보고 고정한 ROI [352,160,672,520]의 320×360 RGB crop을 지표·에이전트에 동일하게 제공했다. 정렬·크기 변경 없음. 알고리즘은 P01과 같고 좌표만 인물에 맞춰 이동했다. 위치·색·광원 변화도 점수에 포함된다.

독립 에이전트는 단계·지표·기존 판단을 모르는 상태에서 무작위 순서의 crop을 평가했다. 1단계 자연스러움 1, 2단계 2(1/2 경계 불확실), 3~4단계 2, 5~10단계 3이었다. 따라서 최초 후보는 2단계이나 확실한 첫 양성은 3단계다. 전체 응답은 agent-review/blind-review.json에 보존했다.

## 고정 감지 후보의 전이

P02 생성 전에 P01의 2·3단계 중간값을 기준으로 MAE≥0.0288375, SSIM≤0.842874, LPIPS≥0.0555075를 고정했다. LPIPS가 사전 주 기준이다. 생성 완료 뒤 규칙을 재생한 오프라인 비교이며 실시간 자동 개입 시스템은 아니다.

| 규칙 | 첫 경보 | 에이전트 등급≥2와 비교 TP/TN/FP/FN |
|---|---:|---|
| MAE | 2단계 | 9 / 1 / 0 / 0 |
| SSIM | 1단계 | 9 / 0 / 1 / 0 |
| LPIPS | 2단계 | 9 / 1 / 0 / 0 |

불확실한 2단계를 제외하면 MAE·LPIPS는 8/1/0/0, SSIM은 8/0/1/0이다. 음성은 1단계 하나뿐이고 10단계가 같은 인물의 종속 출력이다. 이 표를 일반적인 감지 정확도 100%로 해석하지 않는다. 사람 확인된 정답도 아니다. 임계값을 P02 점수에 맞춰 변경하지 않았다.

## 사람 얼굴 평가와 고정 기준 대조

전달된 단계별 응답은 1단계 약함, 2~3단계 뚜렷함, 4~10단계 심함이다. 마지막 최초 시점 칸은 비어 있었으며 단계별 응답에서 도출한 최초 뚜렷함 이상 시점은 2단계다. 실제 평가자 신원·사전 정보 노출 여부는 이번 응답에서 확인되지 않아 추정하지 않는다. 단계 번호와 순서는 제시됐다.

사전 정의한 뚜렷함 이상(등급≥2)을 양성으로 비교하면 MAE·LPIPS는 TP9/TN1/FP0/FN0, SSIM은 TP9/TN0/FP1/FN0이다. SSIM은 약한 변화인 1단계부터 경보를 내어 이 기준에서는 한 단계 이른 경보다. 약함도 변화이므로 '1단계에 변화가 전혀 없다'는 뜻은 아니다. 어떤 지표의 임계값도 이 응답에 맞춰 수정하지 않았다.

독립 에이전트와 사람은 양성/음성 분류가 일치하지만 세부 등급은 4단계에서 다르다(사람 3, 에이전트 2). 에이전트의 2단계 판단은 불확실 표시가 있었으나 사람 응답은 뚜렷함이다. 원문 등급·계산 코드·대조 결과는 human-face-review에 보존했다. 단일 인물의 종속된 10개 출력과 응답 1세트로 일반적인 정확도 100%를 주장하지 않는다.

## 대응 비교

사전 기준에 따라 경계 사례인 2단계에서 피부 수정·1단계에서 재편집·원본 기반 1~2단계 일괄 적용을 각각 한 번 생성했다. 귀걸이와 목걸이가 현재 요구이며 핀은 아직 포함하지 않는다. 과거 대응 후보 선택형 사람 평가는 형식 불일치로 삭제했다. 상세 결과는 interventions/RESULTS.md에 둔다. 이후 얼굴 단계별 사람 응답에서도 최초 뚜렷한 변화가 2단계로 도출됐다. 이는 개입 후 확보한 별도 응답이며 개입 당시 사람 판정이 있었던 것으로 바꾸지 않는다.
