# 동일한 편집 목표의 표현 변화 검사

기존 재검증 대화 여덟 개의 목표를 유지하고 요청 32개의 표현을 바꾸었다. 추출·재검토 응답 64개에 기존 규칙을 수정 없이 적용하였다. 인간 평가는 사용하지 않았다.

| 방법 | 전체 상태 일치율 | 항목별 일치율 | 최종 상태 일치율 | 규칙 적용 후 새 오류 |
| --- | --- | --- | --- | --- |
| 기준 방법 | 25/32 | 181/192 | 5/8 | 0 |
| 유지 규칙만 | 25/32 | 181/192 | 5/8 | 0 |
| 삭제 규칙만 | 25/32 | 181/192 | 5/8 | 0 |
| 유지·삭제 결합 | 25/32 | 181/192 | 5/8 | 0 |

새 오류는 기준 방법의 전체 상태가 정답이었으나 해당 규칙을 적용한 뒤 틀린 요청 수다.

## 측정 범위

표현 변화 전후는 동일한 정답을 공유하는 대응 검사다. 기존 T와 표본 수를 따로 집계한다. 개발자가 작성한 영어 요청과 한 종류의 추출 모델을 사용하였다. 이 검사는 편집 상태 기록을 측정하며 이미지를 새로 생성하지 않았다.
