# 3단계 개입 비교

사용자 육안 보고: 3단계부터 열화 발생. 2단계를 사용자 기준 마지막 정상 입력으로 사용한다. 이는 정식 설문 응답이나 자동 감지 결과가 아니다.

사전 고정: repair는 3단계 이미지 하나만 입력해 얼굴·목 무늬 수정, rollback은 2단계에 기존 3단계 프롬프트 그대로 재실행, rebase는 원본에 1~3단계 요구 일괄 적용. 각 방법 1회, 첫 성공 결과를 유지한다. 원본을 repair에 추가 참조로 제공하지 않는다. 요구는 작은 은색 링 귀걸이, 얇은 은색 목걸이와 원형 은색 펜던트, 화면 오른쪽 가슴의 버건디 원형 핀이다.

얼굴 개선과 요구 충족을 분리 평가하고 원래 3단계를 무개입 기준으로 둔다. 호출 1회씩 비교이며 입력 정보와 프롬프트 목적이 다른 전략 비교다. 자동 감지에 따른 개입이나 통계적 우월성 검증으로 해석하지 않는다.
