# 10단계 순차 편집 예비 실험

생성 전 고정: 기존 결과·평가를 폐기하고 공용 가상 인물 P01 원본만 재사용한다. P02는 입력 자산으로 보존하되 이번 실행에는 사용하지 않는다. P01은 이미 관찰한 인물이므로 미관찰 검증 인물로 취급하지 않는다.

인물 1명 × 1회 × 10단계. 총 10개 신규 출력이며 길이의 최적성을 주장하지 않는다. 순차 입력은 직전 출력 1장, 1단계는 원본 1장이다. 새 요구와 갱신된 전체 요구를 매번 제공한다. 변경된 핀 색·펜던트·의상·배경의 이전 값은 현재 요구에서 제거한다. 얼굴·표정·포즈·인물 조명을 유지하도록 요청한다.

1. 양쪽 귀에 작은 은색 링 귀걸이
2. 얇은 은색 목걸이와 작은 원형 은색 펜던트
3. 화면 오른쪽 가슴에 작은 버건디 원형 핀 하나
4. 남색 재킷과 아이보리 라운드넥 셔츠
5. 현대적 사무실 배경
6. 기존 핀을 코발트 파란색으로 변경
7. 기존 펜던트를 작은 은색 물방울 모양으로 변경
8. 기존 재킷을 차콜 회색으로 변경
9. 핀 반대편인 화면 왼쪽 가슴 주머니에 버건디 포켓스퀘어
10. 사무실을 나무 책장이 있는 조용한 도서관으로 변경

요청된 변경이 부수적으로 미치는 영향과 호출 횟수는 분리 통제되지 않는다. 내장 image_gen 도구의 모델 버전·시드는 노출되지 않는다. 요청 크기와 실제 출력 크기를 별도로 기록한다. 첫 성공 출력만 사용하며 품질을 보고 재생성·중단·단계 추가하지 않는다. 전송 실패만 기록 후 재시도할 수 있다. 열화가 없더라도 10단계에서 종료한다.

현재 목표는 실패와 정상 후보를 모두 포함하는 새 과정 자료 확보다. 사람 R01의 얼굴 보존·자연스러움, 동일 얼굴 입력 지표를 별도 평가한다. 과거 응답·임계값은 재사용하지 않는다. 현재 자동 감지기는 없으며 사후 첫 변화 판단을 자동 감지 성공으로 부르지 않는다.

개입 비교는 감지/평가 기준을 정한 뒤 같은 시점에서 현재 이미지 수정·직전 정상 이미지 재편집·원본 기반 현재 요구 일괄 적용으로 분기한다. 기존 실패 이미지를 무개입 기준으로 둔다. 얼굴 개선과 현재 요구 유지가 함께 충족되어야 한다. 이번 10단계 생성만으로 감지·개입 효과가 검증되는 것은 아니다.
