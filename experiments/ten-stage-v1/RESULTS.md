# 10단계 생성 기록

P01 한 명, 1회, 10단계 생성 완료. 모든 출력은 첫 성공 결과이며 1024×1536이다. 원본→1단계→…→10단계 입력 연결, 사전 프롬프트와 실제 호출의 일치, 생성 원본과 저장·화면용 복사본의 SHA256 일치를 verify.mjs로 확인했다. 결과는 verification.json에 저장했다.

육안 사전 관찰: 후반 결과에서 원본에 없던 얼굴·목의 인위적 무늬가 두드러진다. 9단계 포켓스퀘어는 요청한 화면 왼쪽이 아니라 핀과 같은 화면 오른쪽에 나타났다. 이는 생성 담당자의 관찰이며 독립 평가 결과가 아니다. 정확한 첫 열화 단계는 미확정이다.

사용자는 대화에서 3단계부터 열화가 보인다고 보고했다. 이는 정식 설문 응답이 아니라 비블라인드 육안 보고다. 독립 에이전트 1회는 순서를 가린 동일 얼굴 crop에서 1단계 자연스러움 0, 2단계 1(약한 인위성), 3~8단계 2(뚜렷한 인위성), 9단계 3, 10단계 2로 평가했다. 사용자와 '뚜렷한 변화' 시점은 일치하지만 2단계에도 경미한 변화가 있다고 보았다. 원문과 해독 결과는 agent-review에 보존했다.

고정 얼굴 영역 (340,120,660,480)에서 MAE·SSIM·LPIPS를 계산했다. 정렬·크기 변경 없이 동일 320×360 RGB crop을 계산과 에이전트에 사용했다. MAE·LPIPS는 단계마다 증가하고 SSIM은 감소했다. 위치·조명 변화도 점수에 포함되며 자동 감지 임계값은 설정하지 않았다. 코드·설정·가중치 해시는 metrics에 기록했다.

3단계 개입 이미지 3개를 각 1회 생성했다. 같은 얼굴 지표에서 원본 기반 일괄 적용이 기존 3단계보다 원본에 가까웠다. 상세 결과는 interventions/RESULTS.md. 이번 단일 사례로 감지 정확도나 일반적인 재생성 우월성을 주장하지 않는다.
