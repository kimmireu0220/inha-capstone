# 후속 평가의 해석

68개 고유 출력·목표 입력 전체를 한 번 평가했다. JSON 파싱 실패와 기술적 실행 실패는 모두0건이다. 7B 목표 충족은 기준372/384, 유지·삭제374/384이고 6항목 모두 성공은56/64와58/64다. 실제 입력이 다른 네 쌍에서 두 쌍은 동률이고 두 쌍은 한 항목씩 높았다. 판단 불가 감소로 생긴 차이는 없다.

7B의0→1은 R01 S3 4턴의 소품, R02 S3 4턴의 배경이다. 3B의0→1은 R02 S3 4턴의 배경과 소품이었다. 두 평가에서 공통으로0→1인 항목은 R02 S3 4턴의 배경 한 항목이다. 같은 ‘2개 증가’가 동일한 두 판정을 뜻하지 않는다.

고유 입력408항목 중367항목에서 점수가 같았다. 두 모델 모두 판단 가능한387항목에서는367항목이 같았다. 반복 조건을 포함하면697/768, 둘 다 판단 가능할 때697/735다. 이 비율은 설명적 수치이며 공유 이미지와 대화 내 반복을 독립 표본으로 검정하지 않는다.

## 남아 있는 모순

- R01·R02 S3 3턴의 기준 응답은 식물이 보인다고 설명한 뒤 식물이 없다고도 설명하며 여섯 목표에 모두1점을 줬다.
- R01 S3 4턴의 기준 응답은 소품 오류를0으로 채점했지만 원본의 밝은 중성 배경을 파란 배경이라고 설명했다.
- R02 S3 4턴의 기준 응답은 식물이 있다고 했다가 없다고 했으며 소품 없음에1점을 줬다. 배경 설명은 파란 배경이라고 했지만 배경 점수는0이다.

원점수와 설명을 수정하지 않았다. 더 큰 모델에서 형식 실패는 없어졌지만 의미 판정의 모순까지 해결되지는 않았다. 따라서 두 AI 점수의 증가 방향만으로 전반적인 이미지 품질 개선을 확정하지 않는다. 논문의 주된 근거는 고정한 S·T 대화의 상태 정확도와 S의 구성요소별 비교이며, 이미지 단계는 입력이 다른 네 쌍 전체와 평가 불일치를 함께 보여주는 사례 분석으로 다룬다.
