# S 이미지 평가의 대형 모델 민감도 분석

2026-10-06. 1차 Qwen2.5-VL-3B 평가에서 설명–점수 모순과 JSON 대신 느낌표를 출력하는 실패를 관찰하여 추가 평가를 명세한다. 1차 결과를 본 뒤 정한 사후 강건성 분석이며 새로운 이미지 실험이나 독립적인 확인 검증으로 부르지 않는다. 1차 원응답·점수·집계를 수정하거나 대체하지 않는다.

S의 128조건과 66개 고유 이미지 전체를 그대로 사용한다. 원본과 목표가 같은 평가 입력을 묶은 68개 출력·목표 쌍을 모두 한 번 평가한다. 실패 사례나 방법 간 차이가 있는 네 쌍만 골라 평가하지 않는다. 생성 프롬프트·방법명·기존 점수·얼굴 지표는 평가 모델에 제공하지 않는다. 같은 목표 문구·채팅 변환·JSON 파서·온도0·최대400토큰을 유지한다.

추가 모델은 mlx-community/Qwen2.5-VL-7B-Instruct-4bit, 고정 리비전 fdcc572e8b05ba9daeaf71be8c9e4267c826ff9b이다. 원 모델과 같은 계열의 큰 모델이므로 두 평가의 일치도 독립적 정답 확인을 뜻하지 않는다. 기존 mlx-vlm0.7.4·mlx0.32.3·transformers5.18.0 환경을 사용한다. 공개 가중치를 로컬에서 실행하고 사진을 추가 외부 서비스에 업로드하지 않는다.

실행 전에 코드·명세·1차 집계·평가 계획의 해시를 frozen.json에 저장한다. 각 입력의 첫 성공 응답을 보존하며 점수나 JSON 실패 때문에 재시도하지 않는다. JSON 실패와null은 모두 판단 불가이고 성공으로 세지 않는다. 기술적 실행 실패는 원인을 기록한 뒤 같은 입력으로 재개할 수 있다.

두 평가 모델의 방법별 목표 충족·판단 불가·6항목 전체 충족, 전체 조건 및 고유 평가 입력의 일치도를 보고한다. 실제 입력이 다른 네 쌍은 두 평가의 점수 변화와0→1·null→1·1→0 등을 구별한다. 얼굴 측정은 기존 값을 재사용한다. 공유 이미지·같은 대화의 턴을 독립 표본으로 검정하지 않는다. 평가 간 차이가 크거나 개선이 판단 불가 감소에 좌우되면 강한 이미지 개선 결론을 유보한다. 사람 평가 작업은 추가하지 않는다.
