# 항목별 적용과 명시적 유지·삭제의 결합 검증

2026-10-06. S의 유지·삭제 결합은 29/32였고 S7에서는 잘못된 소품 변경 때문에 올바른 상의·배경 변경까지 일괄 거부됐다. 이미 고정된 항목별 적용 코드와 유지·삭제 코드를 수정 없이 결합한 S 사후 재계산은 32/32였다. 이 점수는 개발 결과이며 새 검증으로 취급하지 않는다. 진행 중인 P·S 이미지 실험은 변경하지 않고 완료한다.

채택 기준은 결합의 정확 턴이 기준보다 높고, 최종 대화 정확 수가 낮아지지 않으며, 새 미변경 훼손이 늘지 않는 것이다. 결합이 두 단일 구성요소 각각보다 정확 턴이 높지 않으면 결합의 추가 이점을 주장하지 않는다. 코드 변경 없이 재계산 가능한 집계·근거·모든 실패를 보존한다. T는 개발자가 작성한 제한 어휘 검사이며 외부 사용자나 모델 일반화 검증은 아니다. 같은 대화의 턴을 독립 표본으로 검정하지 않는다.
