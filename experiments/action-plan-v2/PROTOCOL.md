# 동일한 개발 예시를 사용한 동작 분리

2026-10-06. action-plan-v1의 7/16 실패 뒤 만든 개발 버전이다. 기존 V1–V4를 다시 사용하므로 고정 검증 성능으로 주장하지 않는다. 같은 모델·리비전·온도·260토큰×2회 예산과 항목별 컴파일 규칙을 유지한다.

첫 버전과의 차이는 일반 재검토 기준 방법에서도 쓰던 EXAMPLES 7개를 동작 계획 및 set 값 예시로 변환해 두 호출에 제공하는 것과 값 추출 단계에 항목 별칭을 명시하는 것이다. 새로운 평가 정답을 예시로 추가하지 않는다. 동작 분리 원리 자체는 SOM-DST 등 기존 연구에 있다.

V1–V4에서 일반 재검토+무변경 값 생략의 전체 상태 정확도 13/16을 넘고 새 미변경 항목 훼손이 없어야 새 N 대화 검증으로 진행한다. 결과를 보기 전에 코드·프로토콜·기존 대화 해시를 고정한다. 실패와 원문을 모두 보존하며 이미지 효과는 별도 검증한다.
