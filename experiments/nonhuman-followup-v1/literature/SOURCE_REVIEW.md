# 순차 이미지 편집 문헌 검토

검토일: 2026-09-06 (Asia/Seoul). 문헌 원문과 기존 실험의 문서만 읽은 독립 심사 보조 작업이다. 이 작업은 이미지를 독립 평가한 작업이 아니며, 사람 평가·이미지 생성·정책 재실행을 수행하지 않았다. 논문 본문과 기존 실험 파일은 수정하지 않았다.

검토 범위는 누적 열화, 원본 참조와 일괄 편집, VLM 평가, 유사도 지표의 혼동 요인이다. 아래 8개 일차 연구를 선정했다. 검색 결과의 요약문이나 제3자 해설은 근거로 채택하지 않았다. 날짜는 최초 공개일과 실제 읽은 버전의 날짜를 구분했다. 이 목록은 체계적 문헌고찰의 완전성을 보장하지 않으며, 미발견을 근거로 최초성을 주장하지 않는다.

## 문헌별 확인 기록

### S01. MagicBrush: A Manually Annotated Dataset for Instruction-Guided Image Editing

- 저자: Kai Zhang 외. NeurIPS 2023. 최초 공개 2023-06-16, 열람 버전 v3 2024-05-15.
- 실제 열람: [원문 HTML](https://arxiv.org/html/2306.10012), [버전 이력](https://arxiv.org/abs/2306.10012). 열람일 2026-09-06.
- 확인 위치: §3의 편집 세션 정의, §4.2·표 2–3, §4.4의 사람 평가.
- 원문 확인: 순차 편집 세션을 평가하며, 시험한 방법들이 여러 턴에서 누적 오차로 어려움을 겪는다고 보고한다. 낮은 L1/L2가 요구를 잘 수행했다는 뜻은 아니고, 직접 최적화한 CLIP 점수도 다른 보존 지표와 충돌하는 사례를 제시한다.
- 우리 설정과 차이: 다양한 장면·편집 요구와 목표 편집 이미지가 있는 데이터셋이다. 비얼굴 편집 도중 얼굴 영역을 감시하는 임계값 기반 재생성 정책의 검증은 아니다.
- 설계 함의(본 검토의 판단): 누적 열화 관찰 자체를 새 발견으로 주장하기 어렵다. 요구 충족을 보존 점수와 분리해야 한다.

### S02. Multi-turn Consistent Image Editing

- 저자: Zijun Zhou 외. ICCV 2025. 열람 arXiv v1 2025-05-07.
- 실제 열람: [원문 HTML](https://arxiv.org/html/2505.04320). 열람일 2026-09-06. 학회 원문 PDF도 열기를 시도했으나 브라우저 내부 오류가 발생해, 상세 방법 검토는 실제 읽힌 arXiv HTML 기준이다.
- 확인 위치: §4, §5.1·식 9, §6.3–6.4·그림 7.
- 원문 확인: 원본과 직전 출력을 동시에 참조하는 dual-objective LQR, 높은 차수의 역변환, attention 제어를 결합한다. 원본만 참조하는 경우의 편집성 제한과 직전 출력만 참조하는 경우의 누적 오차를 대조한다.
- 우리 설정과 차이: 모델 내부 샘플링을 제어하는 방법이며, 원본에 현재 요구 전체를 다시 적용하는 외부 블랙박스 호출 정책과 구현·비용 구조가 다르다.
- 설계 함의(본 검토의 판단): 원본을 기준점으로 사용한다는 아이디어의 최초성은 주장하지 않는다. 가능한 경우 원본을 매번 쓰는 정책과 원본+직전 출력 참조를 비교 후보에 포함한다. 해당 논문의 내부 방법을 API 프롬프트로 재현했다고 표현하지 않는다.

### S03. GIE-Bench: Towards Grounded Evaluation for Text-Guided Image Editing

- 저자: Yusu Qian 외. 최초 공개 2025-05-16, 열람 v3 2025-07-25.
- 실제 열람: [원문 HTML](https://arxiv.org/html/2505.11493), [버전 이력](https://arxiv.org/abs/2505.11493). 열람일 2026-09-06.
- 확인 위치: §3.2–3.5, §4.3.
- 원문 확인: 편집 요구를 확인하는 객관식 VQA와 비편집 영역 보존을 분리한다. 보존 평가에는 마스크와 SIFT/FLANN/affine 정합 후 MSE 등을 사용한다. 사람 상관 검증은 100개 예시에서 모델별 평균 순위를 비교하며, 당시 GPT-Image-1 API 출력은 그 사람 연구에 포함되지 않았다.
- 우리 설정과 차이: 얼굴 피부 인위성 전용 평가나 10단계 개입 정책이 아니다. 논문의 모델 수준 순위 상관을 우리 개별 이미지의 경보 정확도로 옮길 수 없다.
- 설계 함의(본 검토의 판단): 고정 ROI와 정합·마스킹 결과를 함께 보고하되 서로 다른 측정 대상을 명시해야 한다. 정합으로 낮아진 점수를 곧바로 제거된 피부 열화량으로 해석하지 않는다.

### S04. EdiVal-Agent: An Object-Centric Framework for Automated, Fine-Grained Evaluation of Multi-Turn Editing

- 저자: Tianyu Chen 외. 최초 공개 2025-09-16, 열람 v3 2026-03-17.
- 실제 열람: [원문 HTML](https://arxiv.org/html/2509.13399), [버전 이력](https://arxiv.org/abs/2509.13399), [저자 프로젝트 페이지](https://tianyucodings.github.io/EdiVAL-page/). 열람일 2026-09-06. 결과 해석은 갱신 상태가 다른 프로젝트 표 대신 원문 v3 기준이다.
- 확인 위치: §2.2, §2.4–2.5, §3.4, 부록 J.
- 원문 확인: 객체 검출·국소 crop VLM 평가, 변경되지 않은 객체의 보존, 시각적 품질을 나눠 측정한다. 3턴 순차 편집과 요구를 합친 단일 호출을 비교하며 모델에 따라 상대 성능이 달랐다. 미화가 보존과 충돌할 수 있어 품질 점수를 별도 보고한다. 객체 상태에 인물의 정체성은 기록하지 않는다.
- 우리 설정과 차이: 얼굴 피부 보호를 위한 재생성 시점 결정·비용 비교를 시험한 것은 아니다. 학습된 품질 모델도 자동 보조 관측이며 사람 판단을 대신하는 정답이 아니다.
- 설계 함의(본 검토의 판단): 현재 요구 상태와 얼굴 보존을 분리하고, 모든 유효 요구의 유지 여부를 평가한다. 일괄 편집이 보편적으로 우수하다는 결론은 피한다.

### S05. Banana100: Breaking NR-IQA Metrics by 100 Iterative Image Replications with Nano Banana Pro

- 저자: Kenan Tang 외. 열람 v1 2026-04-03.
- 실제 열람: [원문 HTML](https://arxiv.org/html/2604.03400), [서지 페이지](https://arxiv.org/abs/2604.03400). 열람일 2026-09-06.
- 확인 위치: §2.1–2.3, §3.2–3.3, §4 도입·§4.1.
- 원문 확인: 주로 내용을 바꾸지 않는 100회 복제와 일부 다른 편집을 시험한다. 단순 재구성이 잡음을 줄여도 내용 보존에 실패하는 사례를 구별한다. 많은 NR-IQA 점수가 반복 열화에 적절히 반응하지 않는다고 분석한다. 개별 이미지 MOS를 수집하지 않았으며, 선별한 AI 생성 원본에서 실제 사진으로의 일반화 한계를 명시한다.
- 우리 설정과 차이: 복제 중심의 100턴·주로 Nano Banana Pro 실험이다. 비얼굴 속성의 10턴 편집이나 얼굴 LPIPS 임계값 정책과 동일하지 않다. 본문은 LPIPS/SSIM을 해당 NR-IQA 비교에서 제외하므로, 이 논문이 우리 LPIPS 실패를 입증했다고 인용하면 안 된다.
- 설계 함의(본 검토의 판단): 무변경 반복 호출은 요청 내용과 반복 호출 효과를 분리하는 후보 대조군이다. 다른 NR-IQA 하나를 추가하는 것만으로 평가 문제가 해결되지는 않는다.

### S06. The Unreasonable Effectiveness of Deep Features as a Perceptual Metric

- 저자: Richard Zhang 외. CVPR 2018. 열람 arXiv v2 2018-04-10.
- 실제 열람: [원문 HTML](https://arxiv.org/html/1801.03924). 열람일 2026-09-06.
- 확인 위치: §1, §2·표 1–3, §2.2.
- 원문 확인: BAPPS의 왜곡 패치에 대해 기준에 더 가까운 것을 고르는 2AFC와 차이의 식별 가능성인 JND 판단을 수집한다. 밝기·색·흐림·공간 이동 등 여러 변형을 포함한다. 연구는 지각적 유사성과 단일 이미지 품질 평가의 차이를 명시한다.
- 우리 설정과 차이: 얼굴 피부의 인위적 패턴 여부, 보존된 인물의 자연스러움, 편집 결과의 사용 가능성을 직접 학습·검증한 얼굴 감지기가 아니다.
- 설계 함의(본 검토의 판단): LPIPS는 원본 대비 차이의 보조 신호로 사용한다. 0.0555075 같은 작업별 임계값을 LPIPS 논문의 지각 기준으로 정당화할 수 없다. 통제 변형 반응과 실제 생성물의 인위성 판별은 별개 검증이다.

### S07. Image Quality Assessment: From Error Visibility to Structural Similarity

- 저자: Zhou Wang, Alan C. Bovik, Hamid R. Sheikh, Eero P. Simoncelli. IEEE TIP 13(4), 2004-04. DOI 10.1109/TIP.2003.819861.
- 실제 열람: [저자 연구실의 원문 PDF](https://www.cns.nyu.edu/pub/lcv/wang03-reprint.pdf). 열람일 2026-09-06.
- 확인 위치: pp. 600–604, §I, §III·그림 2–3.
- 원문 확인: 같은 MSE를 갖는 밝기·대비·압축·흐림·잡음 영상이 서로 다른 지각적 품질을 가질 수 있음을 예시한다. SSIM은 휘도·대비·구조의 비교를 결합하는 full-reference 평가로 제안되었고 JPEG/JPEG2000 자료에서 검증됐다.
- 우리 설정과 차이: 생성 편집에서 얼굴의 조명·위치·형상 변화와 피부 무늬를 분류하는 지표가 아니다. SSIM이 밝기나 구조 변화에 완전히 불변이라고 주장할 수도 없다.
- 설계 함의(본 검토의 판단): MAE와 SSIM의 불일치는 어느 한쪽이 자동으로 정답이라는 뜻이 아니다. 변형 유형별 반응을 확인하고 동일 전처리·범위·구현으로 비교해야 한다.

### S08. MT-EditFlow: Reinforcement Learning for Multi-Turn Image Editing with Flow Matching

- 저자: Jiahui Huang 외. 열람 arXiv v1 2026-06-01. Apple 공식 연구 페이지의 게시월은 2026-07로, 논문 버전 날짜와 구분한다.
- 실제 열람: [원문 HTML v1](https://arxiv.org/html/2606.01985v1), [Apple 공식 연구 페이지](https://machinelearning.apple.com/research/mt-editflow-image-editing). 열람일 2026-09-06.
- 확인 위치: §1, §4.1–4.2.
- 원문 확인: 순차 경로에서 요구 충족과 내용 보존 보상을 결합하는 RL을 제안한다. 현재 단계의 요구 성공, 경로 전체의 성공, 평균 성공을 구별한다. 보존은 원본 기준으로 측정하며, 이미 변한 직전 출력과의 작은 차이가 원본 보존을 보장하지 않는다고 설명한다.
- 우리 설정과 차이: 공개 편집 모델을 후학습하는 접근이다. 모델 내부를 수정하지 않고 외부 지표로 원본 재생성 호출을 결정하는 정책과는 접근 조건이 다르다.
- 설계 함의(본 검토의 판단): 원본 대비 누적 차이와 직전 단계 대비 변화를 함께 기록하되 의미를 구분한다. 경로 평균만으로 모든 요구가 유지되는 성공을 대체하지 않는다.

## 문헌으로 제한되는 주장

선행 연구는 순차 편집의 누적 문제, 원본 참조, 일괄 편집 비교, 다축 자동 평가를 이미 다룬다. 현재 연구에서 방어 가능한 차별점 후보는 특정 블랙박스 편집 흐름에서 **비편집 얼굴 신호로 재생성 시점을 결정했을 때 얻는 이득·실패·비용을 함께 추적하는 실증 연구**다. 이는 기여 후보에 대한 본 검토의 판단이며, 새로움이나 정책의 효능이 입증됐다는 판정이 아니다.

현재는 6인물·7개 순차 경로와 P04 한 인물의 정책 예비 비교라는 범위에 맞춰 주장해야 한다. 사람 평가가 없는 현 단계에서는 계산 재현성, 신호의 민감도, 보조 평가의 불일치, 실행 비용을 연구 결과로 다룰 수 있다. 지각적 인위성 감지 정확도와 사용자 선호는 별도 자료가 필요한 결과다. 후속 대조군과 최소 실험 제안은 [EXPERIMENT_GAPS.md](./EXPERIMENT_GAPS.md)에 기록했다.
