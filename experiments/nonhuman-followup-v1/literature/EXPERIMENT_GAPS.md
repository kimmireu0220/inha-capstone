# 실험 대조군과 주장 범위에 대한 검토

작성일: 2026-09-06. 신규 실험을 실행한 결과가 아니라, 일차 연구 검토와 기존 정책 실험 문서를 바탕으로 만든 후속 설계안이다. 문헌의 사실과 아래 설계 판단을 구분한다. 원문과 버전은 [SOURCE_REVIEW.md](./SOURCE_REVIEW.md)에 기록했다.

## 현재 자료로 확인한 출발점

읽은 로컬 근거는 `experiments/policy-pilot-v1/PROTOCOL.md`, `RESULTS.md`, `alignment-diagnostic/RESULTS.md`, `skin-diagnostic/INTERPRETATION.md`다. 이 검토에서는 이미지 원본을 독립 심사하지 않았다.

- P04 동일 10단계에서 순차/고정3/감지의 논리 호출은 10/13/18회, 재생성은 0/3/8회다. 감지는 3–10단계에 연속 개입했다.
- 최종 고정/감지 LPIPS 순위는 위치 보정 여부에 따라 달라진다. 이 사실은 전처리 민감도이며 어느 쪽이 지각적으로 우수하다는 판정은 아니다.
- 기존 정합과 피부 내부 대조는 이미 수행됐다. 후속 연구는 이 작업을 새 성과처럼 반복하기보다 일반화 범위·실패 조건을 확장해야 한다.
- 기존 문서에 최종 포켓스퀘어 위치 미충족이 기록돼 있다. 이는 담당자의 비블라인드 관찰이며 이 검토가 새롭게 확인한 이미지 평가가 아니다.

## 독자에게 줄 수 있는 세 가지 통찰 후보

### 1. 얼굴 차이 경보는 무엇에 반응하며 무엇을 구분하지 못하는가

질문은 “LPIPS가 좋다”보다 “같은 경보가 공간 이동, 조명, 피부 패턴에 어느 정도 반응하는가”다. [LPIPS](https://arxiv.org/html/1801.03924)와 [SSIM](https://www.cns.nyu.edu/pub/lcv/wang03-reprint.pdf)의 측정 대상은 우리 과제의 인위성 판정과 다르다. [GIE-Bench](https://arxiv.org/html/2505.11493)의 마스크·정합은 보존 대상의 분리가 필요한 이유를 제공한다.

지금 가능한 최소 확장:

1. 기존 고유 출력과 원본의 해시를 고정하고, 6개 원본에 같은 통제 변형을 적용해 기존 P04 위주 대조를 넓힌다. 밝기·색·평행이동과 더불어 작은 스케일·회전·국소 조명·조합 변형을 포함한다. 변형 강도와 보간 방식은 결과를 보기 전에 고정한다.
2. 알려진 합성 패턴·흐림을 별도 축으로 두고 고정 얼굴 ROI, 정합 얼굴 ROI, 피부 내부 ROI의 반응 곡선을 나란히 기록한다. 점수가 목표 변형에 반응해도 다른 변형에 더 크게 반응하는 반례를 빠뜨리지 않는다.
3. 이동·정합 실패율, 순위 변화, 임계값 초과 여부를 보고한다. 기존 임계값을 전처리 변경 후 다시 최적화하지 않는다. 합성 대조에서는 알려진 변형 유무를 평가할 수 있지만 실제 얼굴의 “피부 인위성 정확도”로 명명하지 않는다.

이 실험이 줄 수 있는 것은 측정 신호의 작동 범위와 반례다. 자연스러운 피부인지에 대한 정답, 허용 가능한 조명 변화의 기준, 최적 감지기 성능은 주지 못한다. 정합 전후 차이를 공간 이동의 인과적 기여율로 계산하지 않는다.

### 2. 재생성 직후 이득이 다음 편집에서도 남는가

원본 참조의 존재 자체는 [Multi-turn Consistent Image Editing](https://arxiv.org/html/2505.04320)과 겹친다. 본 연구의 관찰 가치는 외부 재생성 이후에도 편집을 계속할 때 경보와 요구 보존이 어떻게 변하는지에 있다.

지금 가능한 최소 분석:

1. 모든 개입에 대해 개입 직전 후보, 재생성 출력, 다음 단계의 개입 전 후보를 연결한다. 원본 대비 거리 `d`에 대해 즉시 이득 `d(후보_t)-d(재생성_t)`과 다음 편집 변화 `d(후보_t+1)-d(재생성_t)`를 기록한다. 마지막 단계처럼 다음 후보가 없는 경우는 결측 사유를 명시한다.
2. 다음 턴 재경보, 경로 평균·최대·최종 거리, 재생성 후에도 남는 경보, 논리 호출 수를 함께 보고한다. 10단계를 독립 표본으로 유의성 검정하지 않는다. 반복 개입 사건도 같은 경로에 종속된다.
3. 현재 유효 요구를 항목별로 읽는 보조 VLM 평가를 붙이되 얼굴 패턴 평가와 분리한다. 새 요구뿐 아니라 이전에 충족한 요구의 소실·대체된 요구의 부활을 확인한다. 평가 자료에는 정책명·지표·단계명을 숨기고, 미확인/판단 불가를 허용한다.

해석 한계: 높은 점수로 선택된 개입 후보에는 선택 편향이 있고 같은 경로의 무개입 반사실이 없다. 사건 전후 감소를 재생성의 일반적 인과 효과나 최적 시점의 증거로 표현하지 않는다. 자동 평가자 여러 개의 일치는 사람 정답이 아니며, 같은 모델의 여러 에이전트는 독립된 사람 평가자가 아니다.

### 3. 감지가 단순한 원본 일괄 생성보다 어떤 추가 가치를 주는가

[EdiVal-Agent](https://arxiv.org/html/2509.13399)는 순차와 일괄 편집의 상대 성능이 모델에 따라 다름을 보고한다. 우리 설정에서도 얼굴 거리·요구 유지·비용의 관계를 직접 비교해야 한다. “일괄 생성은 더 낫다”와 “감지가 필요한 개입만 골랐다”는 서로 다른 주장이다.

새 이미지 실험을 수행할 때 가장 먼저 추가할 대조군:

| 대조군 | 단계 t의 입력과 요구 | 무엇을 구분하는가 | 10단계 논리 호출 |
|---|---|---|---:|
| 기존 순차 | 직전 출력 + 새 요구 | 일반 순차 흐름 | 10 |
| 매번 원본에서 현재 상태 생성 | 원본 I0 + 현재 유효 요구 전체 S_t | 감지 없이 원본 일괄 생성만 써도 되는가 | 10 |
| 같은 횟수의 고정 개입 | 순차 후보 생성 후 사전 고정한 3회 재생성 | 추가 호출 수를 맞췄을 때 시점 선택의 가치 | 13 |
| 예산 제한 감지 | 순차 후보 생성 후 사전 고정 규칙, 최대 3회 재생성 | 고정 방식과 같은 최대 예산에서 감지가 유용한가 | 최대 13 |

“매번 원본” 대조군은 순차 후보를 먼저 만들지 않는다. 현재 방식대로 순차 후보를 만들고 매번 재생성하면 20호출이며, 위 10호출 대조군과 다르다. 원본+현재 상태는 경로와 독립된 입력이므로 동일 입력·동일 프롬프트의 기존 재생성 출력을 일부 재사용할 수 있지만, 독립 반복으로 세면 안 된다. 재사용 대조는 탐색적 비교로 표시하고 신규 검증에서는 동일 수집 기간에 정책들을 교차 실행한다.

최소 실행 단위 제안은 사전에 잠근 동일 10단계 요구, 새로운 인물 3명, 인물별 독립 경로 반복 2회다. 이는 실행 가능성과 방향을 보는 작은 후속 실험이며 검정력 확보나 모집단 일반화를 뜻하지 않는다. 정책의 결과를 보고 인물·시드·임계값·요구를 교체하지 않는다. 시드가 노출되지 않으면 각 호출이 재현 가능한 난수 반복이라고 주장하지 말고 실행 시각과 제공 모델 정보의 한계를 기록한다.

세부 혼동을 구분해야 할 경우 다음 비교를 후순위로 추가한다:

- 동일 단계의 같은 이전 출력에서 `이전 출력 + S_t`와 `원본 + S_t`를 비교하면 입력 이미지 기준점의 차이를 본다. `이전 출력 + 새 요구`와의 차이는 요구 포장 방식까지 포함한다. 이 둘을 섞어 원본 효과만의 크기로 보고하지 않는다.
- 입력 이미지 두 장을 지원하면 `원본 + 이전 출력 + S_t`도 후보가 된다. 이는 S02 내부 LQR 방법의 재현이 아닌 별도 API 프롬프트 대조다.
- [Banana100](https://arxiv.org/html/2604.03400)와 같은 무변경 반복 호출, 또는 동일한 최종 상태로 끝나는 길이가 다른 경로를 추가하면 반복 호출과 요구 복잡도를 더 구분할 수 있다. 다만 무변경 요청은 실제 비얼굴 편집 요청과 다른 과제이므로 대체 본 실험으로 쓰지 않는다.

## 주장별 필수 증거와 보류할 주장

| 주장 | 필요한 증거 / 현재 허용 범위 |
|---|---|
| 순차 편집 누적 열화의 최초 발견 | 선행 연구와 중복하므로 버린다. 특정 설정에서 재현된 사례로 기술한다. |
| 원본 참조·재생성 개념의 최초 제안 | 현재 검토로 방어할 수 없다. 블랙박스 정책의 구현과 평가 범위로 좁힌다. |
| LPIPS 임계값이 피부 인위성을 정확히 감지 | 실제 과제에 대한 별도 정답 자료가 없다. 경보 발생 규칙으로 기술한다. |
| 감지 정책이 비용을 절감 | P04는 고정3보다 호출이 많다. 현재는 관찰되지 않았다고 기록한다. |
| 감지가 필요한 개입만 골라냄 | P04에서 3–10단계 연속 개입했다. 매번 원본 대조와 같은 예산 대조가 필요하다. |
| 재생성이 완전히 복원하고 품질을 지속 보장 | 재생성 후 잔여 경보·다음 편집·요구 보존을 함께 검증해야 한다. |
| 얼굴 거리 감소가 편집 성공·자연스러움 향상 | 요구 충족과 품질을 별도 측정해야 한다. 자동 보조평가의 일치도 사람 선호의 증거가 아니다. |
| 70단계 또는 10단계가 독립 표본 | 경로·인물·공유 출력의 의존성을 무시하므로 버린다. 인물/독립 경로 단위로 기술한다. |
| 한 API 실험이 모든 생성 모델의 보편 법칙을 입증 | 모델·버전·인물·요구 경로를 넓히기 전에는 설정 한정 관찰이다. |

## 지금 실행할 수 있는 우선순위

1. 기존 자료의 사건 연결과 요구 상태 보존에 대한 보조평가로 통찰 2를 구체화한다.
2. 기존 P04 진단에 없는 변형과 6개 원본으로 통찰 1의 측정 범위를 넓힌다. 동일 분석을 반복해 산출물 수만 늘리지 않는다.
3. 통찰 3의 대조군, 예산, 평가 단위, 중단·실패 기록을 고정한 뒤 신규 생성 실험을 별도로 수행한다. 이 문헌 검토에서는 새 이미지를 생성하지 않았다.

현 단계에서 사람 평가를 뒤로 미루면서도 신호의 오작동 조건, 정책의 호출 낭비 가능성, 요구 유지 실패, 데이터 연결의 타당성을 연구할 수 있다. 그 결과를 사람의 지각 판단이나 사용자 선호를 확보한 것처럼 보고하지 않는다.
