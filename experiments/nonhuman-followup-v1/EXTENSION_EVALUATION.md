# 추가 출력 평가 규칙

2026-09-06, 신규 27회 생성 진행 중이며 추가 출력의 독립 평가 전에 고정했다. 생성 담당자는 일부 출력과 기존 평가를 보았으므로 전체 연구의 사전등록을 의미하지 않는다. 최초 PROTOCOL.md의 개념을 구체화한다.

얼굴: 새 27개 출력에 고정 320×360 원본/후보 crop을 적용한다. 원본-원본 대조 4개와 숨긴 반복 4개를 추가하여 35항목을 무작위화한다. 기존 두 평가 세션에 방법·단계·지표·기존 평가 해독 결과를 주지 않고 같은 등급 0/1/2/3/null을 적용한다. 기존 원문은 수정하지 않는다. 반복 항목은 고유 표본으로 세지 않는다.

최종 요구: 최종 출력의 동일 바이트는 한 번만 평가한다. 독립 새 세션 두 개에 원본과 익명 최종 후보를 전달한다. 아래 조건을 각각 0 미충족 / 1 일부 충족 / 2 충족 / null 시각적으로 판단 어려움으로 기록한다. 명확한 관찰 근거를 붙인다.

1. 양쪽 귀에 작은 은색 링 귀걸이.
2. 가는 은색 목걸이와 작은 은색 물방울 모양 펜던트 하나.
3. 인물의 왼쪽 가슴(이미지를 보는 사람 기준 오른쪽)에 코발트 파란색 원형 핀 정확히 하나.
4. 차콜 회색 재킷.
5. 버건디색 라운드넥 셔츠.
6. 나무 책장이 있는 조용한 도서관 배경.
7. 글자·로고·워터마크 없음. 작은 책등의 판독 가능한 글자도 관찰하되, 불명확한 모양을 글자라고 추측하지 않는다.
8. 인물에 비치는 조명 유지: 원본과 주광 방향·그림자 분포·전체적인 밝기/색조를 시각적으로 비교. 픽셀 동일성을 요구하지 않으며 배경 자체의 밝기 변화는 제외한다.

얼굴의 인위적 무늬가 심하다는 이유로 귀걸이/옷/배경 조건을 미충족 처리하지 않는다. 반대로 요구가 모두 있어도 자연스럽다고 판정하지 않는다. 전체 이미지의 시각적 부자연스러움은 별도 0 없음 / 1 약함 / 2 뚜렷함 / 3 심함 / null로 기록한다. 동일인 식별은 하지 않는다.

집계: 각 항목 분포와 엄격한 전체 충족(8개 모두2)을 분리한다. 관찰 불가/null을 미충족과 합치지 않는다. AI 두 세션을 합의 정답으로 합치지 않는다. 최종 품질·요구 충족은 이 최종 평가로만 주장하며 중간 단계의 모든 요구가 보존됐다고 확장하지 않는다. 같은 모델의 독립 세션이므로 모델 다양성·사람 판단·맹검 사용자 선호 검증을 대신하지 않는다.

## 생성 실패에 따른 결측 처리

추가 평가 전 P05-once-triggered 9단계가 도구 moderation_blocked(other)로 실패했다. 재시도·프롬프트 변경을 하지 않고 10단계도 미실행한다. 따라서 수집 상한 27 중 실제 시도26, 성공25, 실패1이며 신규 얼굴 패킷은 25+4+4=33항목이다. 실패 경로의 최종/10단계 평균은 결측으로 남기고 8단계까지 자료는 유지한다. 성공한 다른 방법의 결과를 대입하거나 8단계를 최종10으로 세지 않는다. 도구 차단을 시각적 품질 또는 요구 미충족으로 채점하지 않는다.

## 재사용 출력의 평가 누락 확인

정책 자료의 해시를 두 얼굴 패킷과 대조한 결과, 추가 생성이 아닌 재사용 출력 3개(P04 once 6단계, P05/P06 초기 재생성)가 얼굴 패킷에 없었다. 평가 결과가 아닌 해시 포함 여부로 선택했으며 같은 기준의 별도 익명 패킷으로 보충한다. 기존 33항목 패킷과 응답을 변경하지 않는다. 최종적으로 83+25+3=111개 고유 정책 출력의 얼굴 관찰을 확보하며 경로별 공유 출력은 한 번만 평가한다. 순차 감지 성능의 기존 70단계 분모는 확대하지 않는다.
