# 비인간 후속 검증

## 목적과 중단 기준
사람 평가는 추후 수집한다. 이번 작업은 (1) 현행 결과 독립 AI 보조 평가, (2) 고정/정합 지표의 민감도, (3) 재생성 후 효과의 지속성과 비용, (4) 관련 연구 대비 기여 범위를 확인한다. 성공적인 결론이 나올 때까지 재생성하지 않는다. 아래 비교와 감사가 완료되면 이번 탐색 묶음을 종료한다. 결과를 본 뒤 추가 설계가 필요하면 별도 프로토콜로 구분한다.

## 동결된 현행 자료
revised-tail-v1 inputs/progress/curves가 기준이다. 포켓스퀘어 조건의 폐기 출력·평가를 재사용하지 않는다. 1~8단계와 조기 경보 대응 자료는 보존한다. 사후 수정과 기존 자료 재사용이 있으므로 독립 본 실험이 아니다.

## 독립 AI 보조 평가
- 생성 담당자와 다른 새 에이전트에 대화 이력 없이 전달한다. 동일 기반 모델의 독립 세션이며 다른 모델/사람 평가자가 아니다.
- 얼굴: 방법/단계/지표를 감춘 동일 320×360 고정 crop 쌍. 원본 주름과 귀걸이는 열화로 세지 않는다. 인위적 무늬/변형 0 없음, 1 약함, 2 뚜렷함, 3 심함, null 판단 어려움. 외관 변화와 관찰 근거를 별도 기록한다. 동일인 식별은 평가하지 않는다.
- 원본-원본 음성 대조 6개와 숨긴 반복 8개를 포함한다. 순서 무작위화. 결과를 본 뒤 채점 기준을 바꾸지 않는다. 동일인 여부 식별은 수행하지 않으며 인위적 무늬/형태와 외관 변화만 평가한다.
- 두 새 평가 세션의 원문을 보존한다. 불일치 사례를 없애거나 합의 정답으로 강제하지 않는다. 감지 성능을 계산하더라도 AI 판단과의 일치이지 사람 기준 정확도가 아니다.
- 요구 반영은 전체 이미지와 최종 현재 요구로 별도 평가한다. 자연스러움 때문에 요구 충족을 높이거나 낮추지 않는다.

## 추가 생성: 단일 개입과 마지막 개입
- end-only: 각 원본에 최종 10단계 현재 요구를 일괄 적용. P04는 현행 10단계 재생성과 동일 입력/프롬프트면 재사용. P03 두 경로도 같은 원본/최종 요구이므로 한 결과 공유. 최종 결과 비교에서 단일-shot 비용 1회, 순차 제작 후 재생성 workflow 비용 11회를 구분한다.
- once-triggered: P04~P06에서 기존 처음 LPIPS 경보 시점 재생성을 사용하고 이후에는 개입 없이 10단계까지 편집한다. 첫 경보는 기존 규칙에서 정한 P04 3단계, P05/P06 2단계다. 후속 프롬프트는 현행 순차와 동일하다.
- P04의 no intervention/fixed3/every-triggered는 기존 현행 경로를 재사용한다. 모든 방법의 현재 요구 동일, 같은 단계 같은 입력 바이트+프롬프트는 출력 공유. 공유를 독립 반복으로 세지 않는다.
- 추가 생성 전 선행 연구 검토에 따라 P04 always-original 대조를 추가한다. 매 단계 최초 원본에 현재 요구를 직접 적용하며 순차 후보를 먼저 생성하지 않는다. 논리 비용 10회다. 3~10단계는 동일 입력/동일 프롬프트의 현행 재생성을 재사용하고 1~2단계만 추가한다.
- 추가 생성 상한은 end-only 5회 + once-triggered 최대20회 + always-original 2회 = 27회다. 품질 재시도/최선 선택 없음. 호출 실패는 따로 기록한다.
- 원본 ROI/MAE/SSIM/LPIPS/기존 임계값은 고정. 재생성 다음 편집에서 다시 경보가 나는 시점, 최종 차이, 전체 단계 평균, 개입 횟수/논리 비용을 함께 본다. 감지 기준으로 선택된 LPIPS 하나만으로 방법 우월성 주장 금지.

## 지표 비교와 연구 해석
고정 얼굴 영역과 NCC 정수 정합(sigma 1/3/6) 후 점수, P04 피부 내부 영역, 이동/밝기 대조. 기존 감지 정책을 정합 후 수치로 사후 재작성하지 않는다. 새 신호의 threshold tuning이 필요하면 인물 단위 분리하며 학습/검증 자료를 분리한다. 이 묶음에서는 기존 임계값의 전이와 지표-평가 불일치를 우선 확인한다.

## 자료 경로
metrics/: 별도 지표 담당. literature/: 별도 선행 연구 담당. generation/: 새 생성 및 호출 기록. blind-face/: 평가자용 자료. private/: 해독표. reviews/: 원문 응답. 사람 응답은 생성하거나 복제하지 않는다.
