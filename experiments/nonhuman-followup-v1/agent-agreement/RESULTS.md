# 초기 6인물 AI 평가 일치도

합성 인물 6명의 순차 편집 6경로와 P04 정책 경로를 대상으로, 같은 기반 모델의 두 독립 세션이 인위적 얼굴 변화를 0~3등급으로 평가했다.

## 평가 자료

- 고유 출력 73개, 원본 대조 6개, 숨긴 반복 6개를 포함해 세션당 85개를 평가했다.
- 초기 순차 경로는 6개이며 단계 기록은 60개다. P01을 제외한 보조 분석은 50개다.
- 전체 현행 정책 단계 기록은 80개다.

## 세션 간 일치

| 항목 | 결과 |
|---|---:|
| 등급 정확 일치 | 67/73 = 91.78% |
| 선형 가중 Cohen κ | 0.922064 |
| severity≥2 이진 일치 | 70/73 = 95.89% |

## 분석 범위

- 동일 인물의 단계는 종속된 관측값이다.
- 얼굴 영역에는 피부 외 구조와 위치 변화가 함께 반영된다.
