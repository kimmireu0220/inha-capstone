# 최신 최종 출력 사람 평가

현재 최종 고유 이미지 16개를 전수 포함한다. 방법별로 동일한 출력은 한 번만 평가하며, 최종 출력이 생성되지 않은 P05 once 경로는 제외한다. AI 평가값·방법명·해독표는 웹에 내보내지 않는다. 제출 ID는 `private/requirements-key.json`으로 해독한다.

- face: 16문항. AI 평가와 동일한 320×360 얼굴 영역을 사용하고 피부 인위성을 0~3 또는 판단 어려움으로 평가한다.
- requirements: 16문항. 모든 후보에서 편집 요소가 충족된 것이 선행 평가로 확인되어, 원본과 같은 사람으로 보이는지와 얼굴형·이목구비·표정·시선이 유지됐는지를 0~2 또는 판단 어려움으로 평가한다. 내부 URL과 mode 이름은 호환을 위해 `requirements`를 유지하지만 화면 명칭은 `인물 얼굴 보존`이다.

공개 설문 `/survey`는 `public-final-human-v2` 형식으로 얼굴 열화 16문항과 얼굴 보존 16문항을 한 번에 제출하며 서버에 저장한다. 참여자별 후보 순서는 무작위이고 두 부문에는 같은 순서를 사용한다. 최종 출력 평가이므로 중간 단계의 감지 정확도나 재발 시점을 검증하지 않는다.

아래 R01 예비 응답은 동일 문항·척도·이미지를 고정 순서로 보여준 `/current-review`에서 부문별로 제출한 것이다. 얼굴 열화는 `current-final-human-v1`, 얼굴 보존은 `current-final-human-v2`이며 공개 모집 결과와 구분한다. 기존 결과 노출 여부는 예비 응답에서 미상이고 공개 설문에서는 수집하지 않는다.

형식이 다른 과거 후보 선택·사용 가능·복합 문항은 [평가 정리 기록](../../EVALUATION_CLEANUP.md)에 따라 제거했다. 같은 얼굴 열화 척도의 과거 단계별 평가는 별도 이력으로 유지하며 현행 최종 결과와 합산하지 않는다.

## 예비 응답 R01

2026-09-06에 얼굴 평가 16문항을 모두 응답했다. 평가자의 기존 결과 노출 여부는 제출 파일에 기록되지 않아 미상이다. 따라서 아래 값은 예비 기술 통계이며 본 실험의 일반화 근거로 사용하지 않는다.

- 전체: 없음 3, 약함 4, 뚜렷함 0, 심함 9.
- 순차 편집 최종 출력 7개: 모두 심함.
- 종료 시 일괄 재생성 최종 출력 6개: 없음 3, 약함 3. 이 가운데 P04 결과 하나는 매 경보 재생성 및 매 단계 원본 재생성과 동일한 바이트를 공유한다.
- 최초 경보에서 한 번만 재생성한 최종 출력 2개: 모두 심함.
- 3단계 간격 재생성 최종 출력 1개: 약함.
- 뚜렷함 이상 이진 판정에서 사람과 독립 AI 평가 A·B의 일치율은 각각 15/16(93.75%)였다. 등급 완전 일치는 A 12/16(75.00%), B 14/16(87.50%)였다.

해독된 행은 `human-analysis/decoded-face.csv`, 집계는 `human-analysis/summary.json`에 저장한다. 원본 제출은 `human-responses/`에 보존한다.

## 얼굴 보존 예비 응답 R01

같은 R01이 2026-09-06에 얼굴 보존 16문항을 모두 응답했다. 얼굴 열화 평가와 마찬가지로 기존 결과 노출 여부는 미상이다.

- 전체: 유지 6, 일부 유지 1, 미유지 9.
- 순차 편집 최종 출력 7개: 모두 미유지.
- 종료 시 일괄 재생성 최종 출력 6개: 모두 유지. 이 가운데 P04 결과 하나는 여러 원본 재생성 정책이 공유하는 동일 출력이다.
- 최초 경보에서 한 번만 재생성한 최종 출력 2개: 모두 미유지.
- 3단계 간격 재생성 최종 출력 1개: 일부 유지.
- 같은 R01의 두 평가에서 `뚜렷한 얼굴 열화`와 `얼굴 미유지`의 이진 판정이 16/16 일치했다. 동일 평가자의 관련 문항이므로 독립 검증이 아니라 짝지어진 기술 결과로만 해석한다.

해독된 행은 `human-analysis/decoded-preservation.csv`, 집계는 `human-analysis/summary-preservation.json`에 저장한다. 이 연구 질문에서는 얼굴 변화와 얼굴 보존으로 사람 평가를 제한하며, 전체 이미지 자연스러움은 현재 예비 실험에서 수집하지 않는다.
