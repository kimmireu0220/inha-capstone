# 위치 민감도 진단

정책 비교 결과를 본 뒤 수행하는 사후 진단이다. 기존 이미지·정책·경보 기록·임계값을 변경하지 않는다. 이미지 재생성 없음.

대상은 policy-pilot-v1에서 사용한 고유 출력 29장 전부다. 원본 P04와 동일 320×360 영역을 비교한다. 원본 ROI [352,88,672,448] 주변 ±64픽셀에서 정수 평행이동만 추정한다. RGB를 회색조로 바꾸고 sigma=3 Gaussian으로 저주파 구조를 구한 뒤 normalized cross-correlation 최대 위치를 선택한다. LPIPS 점수를 최소화하는 위치를 직접 탐색하지 않는다. 경계 도달 여부·상관계수·이동량을 함께 저장한다.

추정 위치에서 원본 크기 그대로 crop하여 기존 MAE·SSIM·LPIPS를 계산한다. 점수 계산 입력에는 블러·보간·스케일·회전·색보정·피부 수정이 없다. 블러는 이동 추정에만 사용한다. 동일 이미지의 고정 crop과 이동 crop의 점수 차이는 위치 민감도이며 피부 열화의 분해 비율로 해석하지 않는다. 회전·크기·조명·표정·얼굴 형상 차이는 잔여 점수에 남는다.

구현 확인: 원본의 0이동, (+24,+35), (-31,-20) 합성 이동을 회복하는지 확인하고 위치만 다른 경우 보정 후 원본 crop과 같아지는지 검사한다. 원본에 일괄 밝기 +0.03을 준 대조군은 색을 보정하지 않으므로 잔여 차이가 남아야 한다. 대조군은 코드 테스트이며 사람의 열화 정답 자료가 아니다.

기존 LPIPS 0.0555075 통과 여부는 민감도 참고치로만 표시한다. 보정 후 점수에 유효한 임계값으로 검증된 것이 아니다. 현재 경로를 재계산해 새 정책 실행·비용 절감으로 주장하지 않는다. 보정이 개입 결정을 바꾸면 뒤의 입력 이미지도 달라져야 하므로 별도 생성 실험이 필요하다.

보정된 crop의 시각 검토는 실행 담당자의 비블라인드 관찰로 표시한다. 사람 평가·독립 에이전트 평가를 대신하지 않는다.
