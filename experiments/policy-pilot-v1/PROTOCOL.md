# 재생성 후 후속 편집: 정책 예비 비교

2026-09-05, 신규 분기 이미지 생성 전 고정.

## 범위
기존 trigger-validation-v1의 첫 인물 P04, 같은 10단계 요구를 사용한다. 기존 결과를 본 뒤 설계한 탐색적 후속 실험이며 독립 본 실험이 아니다. 인물·임계값·간격을 결과에 따라 바꾸지 않는다. 기존 자료를 삭제하지 않는다.

## 정책
- sequential: 기존 10단계 순차 출력. 개입 없음.
- fixed3: 매 단계 직전 확정 출력에 새 편집을 수행한 뒤 3·6·9단계에서 원본에 현재 요구 전체를 일괄 적용한다.
- triggered: 매 단계 직전 확정 출력에 새 편집을 수행하고 LPIPS >= 0.0555075이면 원본에 현재 요구 전체를 일괄 적용한다.

재생성 출력이 다음 단계의 입력이다. 재생성도 기준을 넘으면 실패로 기록하되 같은 단계에서 반복 재생성하지 않는다. 다음 편집 단계에서는 다시 판단한다. 재생성 품질을 보고 원래 후보로 되돌리지 않는다. 10단계에서도 감지 규칙을 동일 적용한다.

동일 입력 바이트와 동일 프롬프트의 호출은 한 결과를 공유한다. 기존 순차 10장과 3단계 재생성도 재사용한다. 이 공유는 초기 차이를 통제하기 위한 것으로 반복 표본이 아니다. 공유했더라도 각 정책의 논리적 비용은 순차 호출 10회 + 해당 정책 재생성 횟수다. 신규 실제 호출 수와 구분한다.

## 고정 조건
기존 calls.json P04의 10개 프롬프트·current state를 그대로 사용한다. 재생성은 기존 rebase-template.json prefix와 해당 단계 state 값의 순서 있는 열거다. 사라진 과거 속성을 다시 추가하지 않는다. ROI [352,88,672,448], RGB 320x360, 정렬·리사이즈·색보정 없음. MAE·SSIM·LPIPS 구현/가중치는 이전과 동일. MAE 0.0288375, SSIM 0.842874는 보조 기준이며 결정은 LPIPS만 사용한다.

## 비교 항목
1. 단계별 개입 전·후 지표, 확정 출력의 10단계 평균·최대·최종 LPIPS와 경보 단계 수.
2. 재생성 횟수, 정책별 논리적 이미지 호출 수, 실제 신규 호출 수.
3. 각 단계 현재 요구 충족과 비요청 얼굴 변화·자연스러움은 이미지와 요구를 함께 평가해야 한다. 지표만으로 충족·자연스러움·사용 가능을 확정하지 않는다. 사람 평가는 별도 미수집으로 표시한다.

10개 단계를 독립 표본으로 검정하지 않는다. LPIPS를 낮추도록 선택하는 정책을 LPIPS로만 평가하므로 순환 평가의 한계가 있다. MAE·SSIM도 독립 지각 정답이 아니다. 간격 3은 시험할 단일 비교 기준이며 최적 간격이라고 주장하지 않는다. 품질별 재시도·프롬프트 수정·경보 억제 없음. 실패 호출은 기록하며 완료되지 않으면 결과를 미완료로 보고한다.
