# 피부 내부 영역 및 정합 안정성 진단

기존 정책 실험 29장 전부를 사용하는 사후 민감도 분석이다. 기존 자료·임계값·정책은 바꾸지 않는다. 신규 생성·사람 평가·정답 학습 없음.

원본 P04를 보고 피부 내부 사각형을 고정한다: forehead=[452,144,568,178], cheek_viewer_left=[412,264,448,306], cheek_viewer_right=[572,264,604,306]. 머리카락·눈·입·귀걸이·배경을 피하기 위한 수동 표본 영역이며 피부 전체 분할이 아니다. 다른 인물에 자동 일반화하지 않는다. 출력마다 좋은 부위를 다시 고르지 않는다. 평행이동 추정값만 좌표에 더한다. 변형 때문에 영역이 다른 조직에 걸치면 한계로 남긴다.

피부 지표: RGB MAE, 각 사각형 SSIM(win7, RGB, data_range1)의 유효 중심 픽셀 수 가중평균, 회색조 고주파 잔차 차이의 MAE. 고주파 잔차=gray-Gaussian(gray,sigma2)이며 전체 이미지에서 계산 후 영역을 취한다. 원본의 정상 주름도 기준에 포함한다. 고주파 지표는 제안된 진단량이지 검증된 피부 열화 점수가 아니다. 낮은 값이 자연스러움이나 요구 충족을 보장하지 않는다. 기존 LPIPS 임계값을 피부 지표에 적용하지 않는다.

정합: 기존 ±64 정수 NCC를 sigma1/3/6으로 비교한다. sigma3가 주 분석이다. 추정 이동의 축별 최대 범위가 3px를 넘으면 설정 민감으로 표시한다. 3px는 보고용 휴리스틱이지 검증된 신뢰도 기준이 아니다. sigma3 위치 추정이 이전 진단과 일치하는지 검사한다.

코드 대조군: 원본 그대로, 알려진 평행이동 2개, 균일 밝기 +0.03/+0.10, 얼굴에서 떨어진 좌우 주변 교체, 피부 영역 주변 합성 사인 무늬 진폭0.01/0.03/0.06, Gaussian blur sigma1/2. 모두 분석용 배열 대조이며 실제 생성 결과나 자연 피부 열화 정답으로 세지 않는다. 알려진 이동과 배경 대조에서 피부 점수가 정상적으로 불변인지, 추가 무늬에 반응하는지, 밝기와 흐림에는 어떤 반응을 보이는지 확인한다.

피부 내부 지표는 외형 보존의 일부만 측정한다. 인물 정체성·표정·기하·전체 요구 충족·제작 가능은 별도 평가 대상이다. 현재 경로의 지표를 다시 계산해 자동 개입 정책이 검증됐다고 주장하지 않는다.
