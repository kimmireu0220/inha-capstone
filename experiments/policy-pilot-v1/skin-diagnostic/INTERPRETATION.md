# 비인간 검증 정리

## 완료 범위

- 동일 요구·실제 입력 연결·첫 출력 사용·18개 신규 호출 기록 검증.
- 고유 출력 29장의 고정 영역과 위치 보정 MAE·SSIM·LPIPS 비교.
- 같은 29장의 피부 내부 세 영역 MAE·SSIM·고주파 잔차 오차 비교.
- 정합 sigma1/3/6 민감도 분석, 최대 이동 추정 차이 2px.
- 동일성·평행이동·밝기·먼 주변 교체·합성 무늬·흐림의 배열 대조 11개.
- 실행 담당자가 29장 전체 영역 표시 시트를 육안 점검. 세 표본이 피부에 놓이는 것을 확인했으나 정합 정답이나 블라인드 평가는 아니다.
- 세 방식의 최종 전체 이미지를 실제 최종 프롬프트와 대조했다. 포켓스퀘어 위치 요구 위반을 세 결과 모두에서 확인했다. final-inspection.json에 비블라인드 실행 담당자 관찰로 기록했다.
- 원본 파일 해시, 데이터 누락, 지표 범위, 집계 단위, 대조군 반응, 평가 미수집 상태를 확인하는 읽기 전용 회귀검사 14개.

## 확인된 내용

1. 고정 얼굴 영역 점수에는 위치 변화가 섞였다. 피부 내부 영역으로 좁혀도 순차 편집의 차이는 남았다. 위치 영향만이 전부는 아니다.
2. 피부 내부 평균 MAE는 순차 0.04084, 고정 간격 0.02257, 감지 0.02020이었다. SSIM도 같은 상대 순서였고 sigma1/3/6 모두 이 순서가 유지됐다. 해당 인물·해당 피부 표본의 수치 비교이며 일반적 품질 우열은 아니다.
3. 감지 방식은 8회, 고정 간격은 3회 재생성했다. 보정한 점수가 좋아져도 비용 절감이 확인된 것은 아니다. 기존 정책의 재생성 횟수를 보정 후 점수로 다시 써서는 안 된다.
4. 원본에 밝기만 +0.10을 준 대조의 피부 MAE는 0.09909였다. 실제 순차 최종 이미지의 0.08331보다 높다. MAE를 피부 무늬 심각도로 바로 해석할 수 없다는 반례다. 대조의 밝기 변화가 실제 제작에서 허용된다는 뜻은 아니다.
5. 고주파 잔차 오차는 합성 사인 무늬 진폭 증가에 반응하고 작은 균일 밝기 변화에는 거의 반응하지 않았다. 그러나 실제 이미지에서 순차/고정 간격 평균은 0.01550/0.01541로 매우 가까웠다. 자연 피부 구조·정합 오차도 반영하므로 새 감지기로 채택하지 않는다. sigma6에서는 이 둘의 최종 상대 순서도 달랐다.
6. 통제된 대조에서 성립한 불변성은 실제 생성 이미지 전부에 대한 감지 정확도가 아니다. 특히 부위별 조명 변화·스케일·회전·형상 변화에는 별도 검증이 필요하다.
7. 최종 요구는 버건디 포켓스퀘어가 화면 왼쪽, 파란 핀 반대편에 있어야 한다. 세 최종 출력 모두 화면 오른쪽 핀과 같은 쪽에 놓였다. 존재·색은 반영돼도 위치는 미충족이다. 따라서 이번 최종 결과를 모든 요구 충족으로 간주하지 않는다. 다른 속성의 정확한 색·원본 인물 조명 보존도 이 육안 확인만으로 확정하지 않는다.

## 지금 남길 것

주 결과는 재생성 후에도 이어지는 10단계 정책 비교와 비용이다. 고정 영역의 위치 민감도, 피부 내부 비교, 대조군은 그 결과를 과장하지 않기 위한 검증 자료로 둔다. 새로운 피부 지표의 성능 주장·최적 임계값·최적 개입 시점·완전 복원 주장은 넣지 않는다.

현재 자료는 계산과 실행의 정합성을 점검했지만, 실제 인위성 정답이 없다. 이번에 사람 평가나 독립 평가자를 수행한 것으로 기록하지 않았다. 사람이 필요 없는 추가 계산만으로 이 간격을 메울 수는 없다. 평가를 나중에 받더라도 그 평가로 기준을 맞춘 자료와 기준을 검증할 자료는 분리해야 한다.

## 재현

프로젝트 루트에서 `.venv-metrics/bin/python experiments/policy-pilot-v1/skin-diagnostic/analyze.py`로 수치를 재계산한다. 이후 `.venv-metrics/bin/python experiments/policy-pilot-v1/skin-diagnostic/test_integrity.py`로 읽기 전용 검사를 실행한다. 테스트는 이미지 재생성·정책 변경·사람 응답 수정을 하지 않는다.
