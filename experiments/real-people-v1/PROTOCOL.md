# 실제 인물 2명 예비 비교

선정한 Pexels 사진 2장(남성 6311573, 여성 6311581)을 사용한다. 로컬 웹 편집기에서 기존 6인물 확대 비교와 같은 요청(남색 셔츠 → 옅은 파란 배경 → 은색 핀)을 적용한다. 인물당 고정 시드 42로 순차 생성 3회와 원본 기반 일괄 재생성 1회를 실행한다. 총 신규 출력 8개, 최종 비교 2쌍이다. 두 방식의 최종 설정·프롬프트·시드는 일치시킨다. 생성 결과의 품질을 보고 재시도하거나 선별하지 않는다. 오류가 발생한 호출만 기록 후 다시 시도한다.

원본 및 출력의 얼굴을 동일한 InsightFace `buffalo_l` 검출·정렬·인식 모형으로 비교한다. 검출 크기 640×640, 임계값 0.5로 설정하고 원본 대비 코사인 유사도를 기록한다. 모든 입력 계보와 해시를 확인하고, 최종 이미지를 나란히 놓아 요청 반영도 별도로 관찰한다. 얼굴이 검출되지 않으면 그 사실을 기록하며 임의로 다른 출력으로 대체하지 않는다.

실제 인물 2명, 각 1회인 탐색적 실험이다. 기존 합성 인물 6명 결과와 직접 합쳐 통계를 내거나 일반화하지 않는다. 사진은 로컬 모델에만 입력한다. 공개 발표·논문 사용 전에는 사진 라이선스와 인물 관련 사용 조건을 별도 확인한다.
