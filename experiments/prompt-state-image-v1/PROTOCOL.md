# 누적 요청과 현재 편집 조건의 이미지 비교

2026-10-25. 기존 single-extraction-validation-v1의 합성 영어 대화 S1–S3 전체를 사용한다. 대화마다 요청 네 개를 처리한 마지막 상태를 대상으로 실제 인물 원본 R01·R02에 적용한다. 이 실험은 이미 관측한 텍스트 결과를 이미지 단계로 연결하는 후속 실험이다. 새로운 독립 언어 검증으로 세지 않는다.

세 조건은 (1) 시간 순서대로 나열한 요청 전체, (2) Qwen3 최초 응답을 단순 적용하여 저장한 현재 상태, (3) 같은 최초 응답에 지시 검사를 적용한 현재 상태이다. 상태 조건은 기존 render_prompt로 변환한다. 전체 요청 조건에는 뒤 지시가 우선하며 원본 사진에서 현재 최종 모습을 만들도록 명시한다. 보존 조건은 동일하다. 상태 정답은 평가에만 사용한다. 세 대화와 두 인물을 모두 사용하고 개선 사례만 고르지 않는다. 18조건의 순서는 인물·대화별로 순환하며 생성 전에 고정한다.

내장 image_gen, 원본 사진 하나, 불투명 배경으로 생성한다. 내부 모델 버전과 시드는 노출되지 않는다. 각 조건의 첫 성공 결과를 보존하고 출력·평가 결과에 따라 교체하지 않는다. 동일 입력 바이트·동일 프롬프트 조건은 한 결과를 공유한다. 기술 실패는 기록하고 다른 조건을 계속 진행한다. 각 조건은 원본에서 한 번 생성하며 이전 생성 이미지를 재편집하지 않는다. 따라서 본 실험은 누적 이미지 재편집 자체의 비교와 구분된다.

프롬프트 길이는 공통 보존 문구를 포함한 전체 문자열의 문자 수·공백 기준 단어 수·고정 Qwen3 토크나이저 토큰 수로 측정한다. 기존 대화 12개 접두 요청 모두에서 계산하며, 생성은 마지막 요청의 18조건에서 수행한다. 짧아졌다고 가정하지 않고 길이가 증가한 경우도 보고한다. 토큰 수는 입력 표현량이며 이미지 도구의 내부 토큰·요금과 다르다. 새 언어 모델 호출은 없다.

이미지 지표는 원본 대비 InsightFace buffalo_l 얼굴 코사인 유사도와 얼굴 검출 수이다. 얼굴 위치를 원본에 정렬한 112×112 얼굴에서 MAE·SSIM·LPIPS도 별도로 계산한다. 초기 합성 인물 실험의 320×360 ROI 수치와 합산하지 않는다. 얼굴이 정확히 하나 검출되지 않으면 지표는 결측이다. 얼굴 지표만으로 편집 요구 충족을 판단하지 않는다.

여섯 편집 목표는 기존 Qwen2.5-VL-3B의 고정 설정으로 한 번 채점한다. 생성 방식·프롬프트·얼굴 점수는 제공하지 않는다. 원문과 JSON 오류, 설명·점수 불일치를 보존한다. 모델 평가의 불확실성 때문에 이 점수와 얼굴 지표를 분리하여 보고한다. 사람 평가 작업은 없다. 세 대화·두 인물·한 생성 도구·조건당 한 출력의 기술통계이며 공유 이미지와 대화별 조건을 독립 반복으로 세지 않는다.
