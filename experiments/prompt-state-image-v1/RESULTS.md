# 누적 요청과 현재 편집 조건의 이미지 비교

세 합성 영어 대화의 마지막 요청을 실제 인물 두 명에 적용한 후속 이미지 실험이다. 각 조건은 원본에서 생성했다. 프롬프트 길이·요청 충족·얼굴 유사도를 분리한다.

| 입력 방식 | AI 목표 충족 | 판단 불가 | 여섯 항목 모두 충족 | 얼굴 코사인 평균 | 정렬 얼굴 LPIPS 평균 |
|---|---:|---:|---:|---:|---:|
| 전체 요청 이력 | 29/36 | 6 | 4/6 | 0.919842 | 0.095158 |
| 검사 전 현재 조건 | 18/36 | 18 | 3/6 | 0.901997 | 0.109213 |
| 지시 검사 후 현재 조건 | 30/36 | 6 | 5/6 | 0.923318 | 0.106698 |

전체 프롬프트 평균 토큰 수: 전체 요청 이력 204.00, 검사 전 현재 조건 133.33, 지시 검사 후 현재 조건 122.67.

공통 보존 문구를 포함한 고정 Qwen3 토크나이저의 길이다. 이미지 도구의 내부 입력 토큰·요금 측정값과 구분한다. 이미지 생성 도구의 시드와 내부 버전은 노출되지 않는다. 조건당 첫 출력 한 장의 기술통계이며, 기존 텍스트 검증과 같은 요청을 사용했다. AI 설명과 점수의 일치 여부는 ai-ratings.json 원문과 함께 검토한다. 얼굴 지표는 요청 충족 점수와 별개이다.

| 입력 방식 | 7B 목표 충족 | 판단 불가 | 여섯 항목 모두 충족 |
|---|---:|---:|---:|
| 전체 요청 이력 | 34/36 | 0 | 4/6 |
| 검사 전 현재 조건 | 24/36 | 2 | 0/6 |
| 지시 검사 후 현재 조건 | 36/36 | 0 | 6/6 |

7B는 3B의 형식 오류를 관찰한 뒤 전체 18개 입력에 적용한 사후 대조다. 전체 점수 일치는 75/108, 양쪽 모두 성공·실패를 반환한 항목의 일치는 73/78였다.

최종 프롬프트는 전체 이력보다 평균 39.87% 짧았다. 7B 평가의 목표 충족 수는 전체 이력 34/36, 검사 전 조건 24/36, 검사 후 조건 36/36이었다. 검사 후 얼굴 코사인 평균은 전체 이력보다 높았고 정렬 MAE·SSIM·LPIPS는 불리했다. 입력 길이 감소와 모든 얼굴 지표의 개선을 같은 성과로 묶지 않는다.

7B 실행 중단과 재개를 기록하고 이미 저장한 응답을 보존했다. 완료된 평가 응답은 두 모델을 합쳐 36개이며 정확한 전체 추론 시도 수는 미관측이다.
