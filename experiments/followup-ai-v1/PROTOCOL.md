# 후속12개 출력 AI 얼굴 열화 평가

2026-09-09. 사용자 요청으로 AI 평가를 보충한다. 사용자 지시에 따라 대화 이력을 전달하지 않은 별도 에이전트 한 세션이 평가한다. 이미지 비교판과 아래 채점 기준만 제공하고 사람 답·연구 결론·방법명·지표·비공개 매핑은 제공하지 않는다. 현재 대화에서 작성 중이던 점수는 분석에 사용하지 않는다.

기존과 같은 인물별320×360 얼굴 ROI, 왼쪽 원본/오른쪽 후보를 사용한다. 0없음/1약함/2뚜렷함/3심함/null판단어려움으로 원본에 없던 인위적 피부 무늬·주름/모공의 비정상적 뭉침·얼굴 형태 왜곡을 관찰한다. 원래 주름·모공·귀걸이와 단순 색조·밝기·정수 이동은 제외한다. 같은 사람인지 판정하지 않는다. 이유와 확신도를 함께 남긴다.

12개 고유 후보와 원본 대 원본3대조를 직접 관찰한다. 대조는 본 표본 수에 더하지 않는다. 기존 prepare_face.py처럼 무보간 crop과 비교판 배치만 수행하고 픽셀 보정·재생성을 하지 않는다. 점수를 저장한 뒤 해시로 재평가 반영 사람 등급·자동 지표에 연결한다. 얼굴 보존은 별도 항목으로 유지한다. 임계값을 맞추거나 AI 평가를 두 번 했다고 주장하지 않는다. 일치율·상관은 별도 AI 한 세션과 결과 노출이 있는 사람 한 명 사이의 기술 통계다. 평가자 입력을 분리한 것이며 다른 모델 간 검증은 아니다.

비교판 생성 뒤 평가자 배정만 변경했다. packet-verification.json의 protocol_sha256은 변경 전 초안의 해시이며 비교판·평가 기준은 그대로다. 최종 프로토콜은 별도 검증 파일에서 해시로 기록한다.
