# 9~10단계 교체

- 기존 포켓스퀘어 조건과 관련 9~10단계 출력·평가·전체 10단계 요약은 현행 분석에서 폐기한다. 원본 파일은 변경하지 않고 이력으로 보존한다. 별도 pocket-* 위치 실험도 현행 분석에서 제외한다.
- 1~8단계 출력과 그 이전 대응 실험은 유지한다. 신규 인물이나 독립 반복으로 세지 않는다.
- 9단계: 기존 아이보리 크루넥 셔츠만 버건디색으로 변경. 재킷·핀·목걸이·귀걸이·배경 유지.
- 10단계: 사무실 배경을 나무 책장이 있는 조용한 도서관으로 변경. 버건디 셔츠 포함 현재 요구 전체 유지.
- 포켓스퀘어 요구는 새 편집·재생성 프롬프트 어디에도 넣지 않는다.
- P01, P02, P03의 두 반복, P04~P06의 순차 7경로 및 P04 fixed3/triggered 정책 분기를 각각 기존 8단계 확정 출력부터 잇는다.
- fixed3는 9단계 원본 기반 재생성, triggered는 기존 LPIPS >= 0.0555075 규칙을 유지한다. 재생성도 경보이면 기록 후 다음 단계 진행, 품질 재시도 없음.
- 동일 원본과 동일 현재 요구 재생성은 한 결과를 공유한다. 실제 생성 수와 정책 논리 호출 수를 구분한다.
- 기존 얼굴 ROI와 MAE·SSIM·LPIPS 구현·임계값 유지. 원본 지표의 위치/조명 민감성 한계도 유지한다.
- 모든 첫 출력 보존. 새 사람 평가와 독립 에이전트 평가는 미수집으로 시작한다. 기존 9~10단계 응답을 새 이미지에 사용하지 않는다.
- 요구 오류를 관찰한 뒤 편집 항목을 바꾼 탐색적 수정이다. 좌우 관계/장신구 추가에 대한 일반화는 주장하지 않는다. 셔츠 색 변경은 포켓스퀘어 추가와 난도가 동일하다고 가정하지 않는다.
