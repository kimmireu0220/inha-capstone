# 긴 대화와 표현 변화에 대한 고정 코드 검증

2026-10-25. 이전 최종 비교의 요청 12개를 보완하기 위해 새 합성 영어 대화 12개, 대화당 요청 8개, 총 96개를 구성한다. 네 가지 표현 틀에 각각 세 가지 속성 조합을 배정한다. 모든 문장은 앞선 benchmark.json 및 모델 공통 예시와 중복되지 않도록 검사한다. 사람이 작성한 실제 대화나 독립적인 자연어 표본으로 해석하지 않는다.

요청 유형은 초기 여섯 항목 설정, 두 항목 변경, 삭제와 유지, 원본 복원과 유지, 부정 지시, 명시된 인용문, 조건문, 뒤 직접 지시 우선의 여덟 가지다. 대화마다 유형 순서를 바꾸어 특정 유형의 오류가 항상 같은 위치에서만 발생하지 않도록 한다. 정답 상태는 명시한 변경을 순서대로 적용하며 결과 채점에만 사용한다.

기존 single-extraction-validation-v1의 채점과 instruction-eligibility-v1의 검사 구현을 그대로 사용한다. Qwen3-4B와 Llama-3.2-3B의 고정된 4비트 배포 버전, 온도 0, 최대 260토큰, 공통 예시 일곱 개도 유지한다. 모델별 최초 추출 96회와 재검토 96회, 총 384회 호출을 계획한다. 최초 추출과 재검토를 각각 즉시 저장하여 중단 후 저장 응답을 재사용한다. 실제 호출 시도와 완료 응답을 구별해 기록한다.

주 비교는 첫 응답 단순 적용, 재검토 응답 우선, 추출·재검토와 검사 결합, 한 번 추출과 검사 결합이다. 요청별·항목별·최종 상태 일치율, 요청 유형별 결과, 대화별 일치율을 모두 보고한다. 같은 응답을 공유하는 대응 비교이며 두 모델에 같은 96개 요청을 입력한다. 192개 독립 요청으로 합산하지 않는다.

불확실성은 대화를 단위로 20000회 복원 추출한 95% 백분위 구간으로 기술한다. 같은 표현 틀을 공유하므로 이 구간은 일반 사용자 언어 분포에 대한 보장이 아니다. 요청별 정확도 차이의 대화 단위 대응 부호 무작위화 검정은 모든 4096개 부호 조합으로 계산한다. 두 모델별 검정은 Holm 방법으로 보정한다. 별도의 이미지 품질 향상 주장은 추가하지 않는다.

추론 전에 자료·정답·실행기·채점기·방법·모델·프로토콜을 해시로 고정한다. 결과에 맞춰 방법, 문장, 정답을 바꾸지 않으며 실패한 요청도 모두 보고한다.
