# 명시적 원본 복원 제약: 개발 및 대조

2026-10-06. N 대화의 오류를 확인한 뒤 설계한 보완이며 같은 자료에서의 개선은 사후 개발 결과로만 보고한다. 복원 동작과 original이 함께 나타나는 국소 구간의 명시적 항목만 원본 상태로 설정한다. 인용·조건부·부정 문장은 강제하지 않으며, 뒤에 같은 항목이 다시 언급되면 보류한다. 범용 자연어 의미 해석이나 새로운 알고리즘 원리로 주장하지 않는다.

고정 출력의 상태를 턴별로 재적용할 때 일반 재검토+무변경 값 생략과 동작 분리에 동일한 복원 제약을 추가한다. 정답을 의사결정에 쓰지 않으며 모델 호출을 추가하지 않는다. 기존 모델의 동작 오류와 코드의 실행 오류를 구분한다. 개발 N 결과에서 보완이 작동하면 규칙을 고정하고 별도 새 대화에서 양쪽 보완 방법을 비교한다. 부정·조건부·뒤따르는 변경이 있는 경우의 과도한 강제도 검증한다.
