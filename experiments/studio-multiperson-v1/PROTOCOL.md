# 사이트 다인물 생성 모드 비교

기존 가상 인물 P01–P06, 시드 42·314·2026을 모두 사용한다. 기존 결과를 선별하거나 재사용하지 않고 사이트 HTTP API에서 새로 생성한다.

각 인물·시드에서 순차 생성 3회와 원본 기반 일괄 재생성 1회를 비교한다. 총 72개 출력, 최종 비교 18쌍이다. 실행 순서는 인물·시드별로 두 모드를 번갈아 먼저 실행한다.

누적 요청: 남색 셔츠 → 옅은 파란 배경 → 은색 핀. 두 모드의 최종 상태와 프롬프트, 시드를 일치시킨다. 순차 입력은 직전 출력, 일괄 입력은 최초 원본이다. 모델과 설정은 현재 사이트와 동일하다.

얼굴 ROI는 기존 실험에서 원본만 보고 고정한 좌표를 사이트 해상도에 맞춰 1/2로 변환한다. MAE·SSIM·AlexNet LPIPS를 모든 출력에 계산하고 최종 18쌍의 인물별 평균과 전체 평균, 쌍별 승수를 보고한다. 원본 자기 대조 및 입력 계보를 검증한다. 생성 시간은 순차 3회 합계와 일괄 1회를 구분한다. 시드는 같은 인물 안의 반복이며 독립 인물 수는 6명이다.

원본·최종 출력 비교판을 전수 작성하여 요청 반영과 얼굴 변화를 확인한다. 얼굴 유사도 지표와 요청 반영은 구분해서 해석한다. 실패는 기록하며 성공한 출력을 재추출하지 않는다.
