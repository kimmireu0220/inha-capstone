# 추가 검증의 판단과 실패 원인

## 판단

누락 검사 후보를 채택하지 않는다. 개발 파일럿에서는 일반 재검토 대비 전체 상태 정확도가 15/16에서 16/16으로 증가했지만, 고정한 별도 대화에서는 13/16에서 12/16으로 감소했다. 최종 대화 정확도도 4/4에서 3/4로 감소했다. 누락 검사가 일반 재검토보다 우수하다는 근거가 되지 않는다.

무변경 값 생략은 추가 모델 호출 없이 항목 정확도를 91/96에서 93/96으로 높였다. 하지만 전체 상태 정확도는 13/16으로 같았고, 일반 재검토 없이 첫 출력에만 적용해도 같은 점수였다. 반복 재검토의 추가 비용을 정당화하는 효과는 이 자료에서 확인되지 않았다.

## 원문에서 확인한 오류

1. V1-2: 핀은 유지하고 재킷은 베이지에서 초록으로 교체하라고 했지만, 세 모델 출력 모두 재킷을 keep으로 반환했다. 핀의 기존 값을 그대로 쓴 출력이 어휘 검사에 걸리면서 정상적인 배경·소품 변경까지 거부됐다. 무변경 값 생략은 배경·소품의 부수적 실패를 막았으나 잘못된 재킷 keep을 고치지는 못했다. 재킷 오류는 V1-3에도 남았다.
2. V1-4: 첫 출력과 일반 재검토는 재킷을 original로 올바르게 복원했지만, 누락 검사 재검토는 이를 keep으로 바꿨다. 형식과 항목 포함 여부가 맞아도 요청 의미가 틀릴 수 있다.
3. V4-3: 원래 셔츠로 복원하라는 요청을 모든 모델 출력이 top=keep으로 반환했다. 같은 요청의 제거·유지 동작과 복원 동작을 구분하지 못한 출력이다. 모델 내부 원인이 확인된 것은 아니다.

따라서 다음 후보의 초점은 항목이 있는지 확인하는 것보다 **각 항목에 연결된 동작(변경·제거·유지·복원)을 정확히 구분하는 것**이어야 한다. 명시적 동작과 출력이 충돌할 때만 국소적으로 다시 묻는 방법을 설계할 수 있지만, 아직 구현·검증된 해결책은 아니다. 같은 결과를 보고 규칙을 고쳐 이 검증 세트의 점수만 높이는 방식으로 효과를 주장하지 않는다.

## 보존 및 재현

`transcripts.json`은 첫 출력 및 두 재검토 응답 전체, `method-freeze.json`은 추론 전 방법 해시, `verification.json`은 저장된 출력을 재적용한 검산 기록이다. `results.json`과 `ablation-results.json`을 기존 이미지 실험과 합산하지 않는다. 같은 캐시 모델·환경에서 `run.py`를 재실행하면 완료된 턴은 재사용하며 `report.py`는 모델 호출 없이 검산한다.

이 단계의 총 실제 추론은 파일럿 48회와 추가 검증 48회다. 중단된 이전 시도의 부분 추론은 저장된 완료 호출에 포함하지 않으며, 모든 실행 시도의 실제 계산 비용으로 96회를 해석하지 않는다.
