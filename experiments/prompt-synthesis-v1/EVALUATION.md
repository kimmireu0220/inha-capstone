# 가림 평가 기준

원본과 방법명을 숨긴 `IMAGE A/B/C`를 나란히 보고, 각 이미지에 다음 최종 목표를 독립적으로 채점한다. 보이면 1, 명백히 없거나 틀리면 0, 판단하기 어려우면 `null`이다. 방법 매핑과 얼굴 지표는 점수 저장 전 열지 않는다. 한 평가자의 육안 점수이므로 독립 합의나 객관적 정답이라고 부르지 않는다.

1. `charcoal_blazer`: 차콜 회색 재킷에 옷깃이 보이는가? 남색 재킷이면 0.
2. `ivory_crew_shirt`: 재킷 안에 아이보리색 라운드넥 셔츠가 보이는가?
3. `gold_square_pin`: 화면 오른쪽 옷깃에 작은 **금색 정사각** 핀 정확히 하나가 보이고 옛 은색 핀은 없는가?
4. `no_necklace`: 목걸이와 펜던트가 모두 없는가?
5. `library_bookshelves`: 도서관으로 읽히는 나무 책장이 배경에 보이는가? 사무실만 보이면 0.
6. `warm_lamp`: 배경에 따뜻한 램프 하나가 보이는가?

요청하지 않은 얼굴·헤어·포즈·체형·구도·인물 조명 변화는 점수에 섞지 않고 별도 메모로 남긴다. 얼굴 정체성은 ArcFace로 따로 계산한다.
