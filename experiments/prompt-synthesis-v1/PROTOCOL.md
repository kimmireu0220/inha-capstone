# 편집 대화의 최종 요구 종합 실험

## 질문

8개 편집 요청 중 이전 조건이 4번 바뀌거나 취소될 때, 최종 이미지용 프롬프트를 어떻게 합치는 것이 좋은가? 복합 프롬프트 한 문장을 다듬은 직전 실험과 구분해, 이번에는 **요청 이력에서 최신 상태를 추출**하는 과정 자체를 시험한다.

## 자료와 세 조건

`history.json`의 영어 요청 8개를 고정한다. 모든 요청에는 구조화된 상태 변경을 함께 기록해 정답을 명시한다. 마지막 상태는 차콜 회색 재킷·아이보리 라운드넥 셔츠·화면 오른쪽 옷깃의 작은 금색 정사각 핀 정확히 하나·목걸이 없음·나무 책장과 따뜻한 램프 하나가 있는 조용한 도서관이다. 얼굴·표정·시선·머리카락·피부 질감·자세·체형·인물 조명·구도는 유지한다.

- `history`: 요청 8개를 시간순으로 모두 제공하고 최신 요청이 이전 조건을 대체한다고 명시한다. 이미지 모델이 직접 이력을 해석한다.
- `state`: 기록된 구조화된 변경을 코드로 순서대로 적용해 최종 상태만 프롬프트에 넣는다. 사람이 각 요청을 완벽하게 구조화해 준 **상한 기준**이며, 실제 자연어 파싱 성능을 나타내지 않는다.
- `agent`: 로컬 Qwen3 4B가 8개 자연어 요청만 읽고 초안 작성·원문 대조 두 단계를 거쳐 최종 프롬프트를 만든다. 구조화된 변경이나 정답은 주지 않는다. 원문에 없는 성별 지칭은 고정된 자동 치환 규칙으로만 중립화하고 전후를 기록한다. 그 밖의 결과는 사람이 고치거나 선별하지 않는다.

프롬프트 3개를 이미지 생성 전에 고정한다. 실제 인물 R01·R02의 기존 로컬 입력 이미지와 고정 시드 42·314를 사용한다. 각 인물·시드에서 세 조건을 교차 순서로 실행하여 총 2명 × 2시드 × 3조건 = 12개 신규 출력을 만든다. 세 조건 모두 같은 로컬 FLUX.2 Klein 4B 4bit, MFLUX, 4 스텝, 같은 입력 크기를 사용한다. 각 호출의 첫 성공 출력을 유지한다. 실패 시 같은 조건의 재시도만 허용하고 기록한다. 이미지 생성 후 프롬프트나 정답을 바꾸지 않는다.

## 평가

생성 전에 각 프롬프트가 최종 상태를 올바르게 담고 과거 조건을 버렸는지 6개 항목과 이전 조건 잔존 여부를 기록한다. 생성 후 방법명을 숨긴 이미지에서 최종 목표 6개(차콜 재킷·아이보리 셔츠·금색 정사각 핀 하나·목걸이 없음·도서관 책장·따뜻한 램프 하나)를 각 0/1/판단 어려움으로 채점한다. 요청하지 않은 얼굴·자세·구도 변화는 별도 메모다. 원본 대비 얼굴 유사도는 기존 InsightFace `buffalo_l` 640×640, 검출 임계값 0.5, ArcFace 코사인 유사도로 별도 계산한다. 검출 실패를 숨기거나 출력을 교체하지 않는다.

사람 2명과 시드 반복 2개는 독립 인물 4명이 아니다. `state`는 완벽한 구조화 입력을 받는 기준이며 다른 두 조건과 구현 비용이 같지 않다. 한 명의 가림 육안 평가는 탐색적 자료다. 이 실험으로 일반적 우월성이나 통계적 유의성을 주장하지 않는다.
