# 동작 분리 후보의 고정 검증

2026-10-06. N1–N6의 6개 대화·24턴을 새로 작성했다. 이전 V1–V4의 동작 분리 개발 실험 추론 중에 대화를 작성했으며, N1–N6 모델 출력은 방법·코드·대화 해시 고정 후에만 생성한다. 개발자가 작성한 제한 어휘 자료이며 독립 외부 사용자 평가가 아니다.

## 비교

- 일반 재검토: 기존 flat patch 추출 1회 + 같은 요청을 사용한 일반 재검토 1회.
- 일반 재검토 + 무변경 값 생략: 같은 출력을 재사용하며 추가 호출이 없다.
- 동작 분리: 6항목 동작 분류 1회 + set 항목 값 추출 1회. action-plan-v2/method.py를 그대로 사용한다. 일반 재검토와 같은 개발 예시 7개를 각 단계의 동작/값 형식으로 변환해 제공한다. v1은 개발 7/16으로 탈락했고, v2가 개발 14/16으로 사전 진행 기준을 충족해 검증 대상으로 고정됐다. v2의 개발 최종 대화 정확도는 3/4로 일반 재검토의 4/4보다 낮았으며 이 약점도 추가 검증에서 확인한다.
- 동작 분리의 일괄 거부 대조: 같은 모델 출력을 재사용하되 한 항목이라도 거부되면 그 턴의 전체 상태를 유지한다. 항목별 거부가 효과의 원인인지 분리한다.
- 첫 출력 단독도 추가 추론 없이 기록한다.

두 추론 방법 모두 같은 캐시 Qwen3-4B-4bit 리비전, 온도 0, 호출당 최대 260토큰, 턴당 2회 호출이다. 실제 호출은 24턴×4회=96회다. 대화와 턴에 따라 방법 실행 순서를 교대한다. 두 방법 모두 이전 상태와 정답을 모델에 주지 않는다. 원문은 모두 저장하고 완료된 조건을 재사용한다. 해시가 바뀌면 재개하지 않는다.

## 평가와 후속 진행

추론을 전부 저장한 뒤 정답 updates를 누적하여 평가한다. 주 지표는 턴 후 전체 6항목 상태의 정확도다. 항목 정확도, 최종 대화 정확도, 변경/복원/삭제 종류별 오류, 새로 훼손한 미변경 항목, 대화별 결과와 호출 비용을 함께 보고한다. 턴을 독립 표본으로 다루지 않고 6개 대화별 결과를 제시한다.

동작 분리가 두 일반 재검토 대조보다 전체 상태 정확도가 높고, 최종 대화 정확도와 미변경 항목 훼손에서 악화되지 않으면 이미지 단계로 진행한다. 실패하면 오류를 분석하고 새로운 후보를 별도로 개발한다. 같은 N 대화의 결과를 보고 방법을 바꾼 뒤 고정 검증 성공으로 주장하지 않는다.

이미지 단계에서는 결과를 보고 좋은 대화/턴만 고르지 않도록 N1–N6의 2턴과 4턴을 모두 대상으로 한다. 원본 R01·R02, 시드 42, 일반 재검토+무변경 값 생략과 동작 분리의 프롬프트를 동일한 원본·생성 조건에서 비교한다(최대 48장). 프롬프트가 완전히 같은 쌍은 동일 조건임을 기록하며 별도 독립 출력으로 과장하지 않는다. AI 목표 판정과 ArcFace를 분리해 평가하고 이미지 결과를 얻기 전 이미지 개선을 주장하지 않는다. 사람 평가 작업은 없다.
