# 자동 항목별 상태 갱신과 기존 에이전트 비교

2026-10-03. 기존 H1–H3 및 추출기 점검에 사용한 T1–T4와 별도로 새 대화 U1–U4를 생성 전에 고정한다. 개발자가 작성한 제한 어휘의 합성 대화이며 독립 외부 사용자 자료가 아니다. 1차 추출기 중단은 `../state-tracking-v1/DEVIATIONS.md`에 기록했다.

## 자동 방법

`agent`는 기존 Qwen3 4B의 전체 이력 초안 작성·원문 대조 2회 방식이다. `tracked`는 같은 모델이 새 요청 하나에서 변경 항목과 새 값을 JSON으로 추출한다. 코드는 항목 이름·지원 값·명시적 언급을 검증하고 갱신한다. 이전 상태를 모델에 제공하지 않는다. 삭제값 `none`과 미변경 항목은 코드가 유지한다. 최종 프롬프트는 현재 상태의 6항목에서 생성한다. 형식 실패 때만 최대 1회 재시도하며 거부한 요청은 기록하고 상태를 유지한다. 정답을 모델에 주거나 결과를 보고 프롬프트를 고치지 않는다.

지원 항목은 재킷·상의·핀·목걸이·배경·배경 소품이다. 지원 값과 개발용 예시는 `local-studio/request_state.py`에 있다. 새 값의 색·종류·위치 단어가 요청에 있는지도 코드가 확인하며, 미언급 항목의 keep은 상태에 영향을 주지 않는 동작으로 생략한다. 범용 자연어 편집 성능으로 주장하지 않는다. 두 방법의 모델 호출 수, 처리 시간, 최종 프롬프트 길이를 보고한다. 방법별 모델 호출 예산이 달라 이 결과는 시스템 비교다.

## 생성 조건과 표본

기존과 같은 실제 인물 사진 R01–R06 × 새 8턴 대화 4종 × 시드 42·314 × 두 방법 = 96장, 최종 48쌍. 모든 조건을 생성한다. 최초 원본 입력·FLUX.2 Klein 4B 4bit·4스텝·원래 참조 크기를 동일하게 유지하고 방법 순서를 회전한다. 모델 가중치는 기존 캐시를 사용한다. 코드·대화·프롬프트·입력 해시는 이미지 생성 전에 고정하고 실행 오류를 기록한다. 결과에 따라 표본이나 프롬프트를 바꾸지 않는다.

## 평가와 개선 판단

자동 상태를 미리 적은 정답과 턴별·최종 항목별로 비교한다. 바뀌는 항목만의 정확도도 따로 집계한다. 정답은 자동 프롬프트가 모두 고정된 다음에만 평가에 사용한다. 추출 성공과 이미지 목표 충족을 구분한다.

방법명을 가린 48개 비교판의 최종 6목표를 AI가 시각적으로 채점한다. 성공 1, 실패 0, 판단 불가 null이며 null은 성공으로 세지 않는다. 점수 기록을 완료한 뒤에만 방법명과 ArcFace 수치를 결합한다. 얼굴은 원본 대비 InsightFace buffalo_l 코사인 유사도와 얼굴 수를 기록한다. 목표 충족과 얼굴 유사도를 함께 보고하며 6명 각각의 개선·동률·악화를 공개한다. 96장을 독립 표본으로 간주하지 않는다.

보조 평가자는 로컬 Qwen2.5-VL 3B 4bit이다. 방법명·프롬프트·1차 AI 점수를 주지 않고 가림 비교판에서 A/B 이미지를 잘라 각각 같은 6목표를 채점한다. 온도 0으로 한 번 평가하고 JSON 형식 실패는 결측으로 남긴다. 원문 응답과 모델 버전을 보존한다. 두 AI의 일치율과 별도 목표 충족률을 보고한다.

기존 108장 결과와 분모를 합산하지 않는다.
