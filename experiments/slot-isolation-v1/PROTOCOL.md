# 일반 추출의 항목별 오류 격리: 사후 개발

2026-10-06. 동작 분리+복원 제약의 M 고정 검증이 주 진행 기준을 충족하지 못했다(19/24 대 20/24). 일반 방식의 실패 중 맞게 추출한 배경·삭제 요청까지 다른 항목의 오류로 취소되는 문제가 있었다. 동작 분리 없이 같은 일반 추출 출력을 항목별로 검증하는 간단한 대조를 개발한다.

가장 최근의 구문적으로 해석 가능한 패치 한 개를 사용한다. 현재 값과 같은 값 및 keep은 변경하지 않는다. 잘못된 항목만 거부하고 나머지 올바른 항목은 적용한다. 최신 패치에서 빠진 항목을 이전 출력에서 되살리지 않는다. clarification이나 전체 JSON 오류는 원래 상태를 유지한다. 명시적 원본 복원 제약은 동일하게 적용한다.

N·M의 저장된 일반 출력으로 개발 성능을 재계산하며 새 모델 호출은 없다. 이는 사후 개발 분석이고 일반화 검증이 아니다. 기존 일괄 검증+무변경 생략+복원 규칙과 비교한다. 최신 패치 선택 방식만 같게 하고 항목별 거부를 일괄 거부로 바꾼 대조도 포함한다. 실제 효과의 새 검증은 별도 대화를 먼저 고정한 뒤 수행한다. 이 단순한 오류 격리 원리를 새로운 일반 알고리즘으로 주장하지 않는다.
