# 원본 사진 복원 표현의 처리 개선

2026-10-25. 표현·지시 순서 추가 검증 48개를 개발 자료로 사용한다. 이 자료에서 모델이 source photo를 포함한 복원 지시를 유지로 해석한 오류가 나타났다. 기존 구현은 보존하고 별도 방법으로 확장한다.

명시적인 원본 사진 복원, 현재 상태 유지, 대상 삭제의 구절을 먼저 구분하고 기존 표준 지시로 변환한다. 인식하는 항목 목록과 완전한 문형에만 적용하며 부정문·조건문·인용문과 알 수 없는 대상은 기존 처리에 맡긴다. 같은 항목의 뒤 지시가 앞 지시보다 우선한다. 모델에는 변환 전 요청을 입력한다. 후처리는 모델 응답과 직전 상태만 사용한다.

개발 자료 재계산과 새 요청 검증을 별도로 기록한다. 새 검증 전에 방법·자동 검사·요청·정답·모델 설정을 고정한다. 과거 실험의 구현과 응답을 수정하지 않는다. 자동 코드 검사는 실제 모델 응답을 사용한 대화 검증과 구분한다.
