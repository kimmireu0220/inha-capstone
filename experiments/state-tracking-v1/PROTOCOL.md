# 자동 상태 갱신과 기존 프롬프트 종합 비교

2026-10-03. 이전 H1–H3에서 관찰한 취소 조건 잔존을 해결하는 자동 방법을 평가한다. 새로운 영어 편집 대화 T1–T4는 생성 전에 고정한다. 개발자가 작성한 제한 어휘 과제이므로 독립적인 실제 사용자 대화로 일반화하지 않는다.

## 방법

- `agent`: 기존과 동일한 Qwen3 4B 초안 작성·원문 대조 2회 방식.
- `tracked`: Qwen3 4B가 매 턴 요청을 근거 구절이 있는 항목별 동작으로 추출한다. 코드는 검증된 동작만 현재 상태에 반영하고, 현재 상태만 최종 프롬프트로 출력한다. 삭제는 `none`으로 저장한다. 미지원 값·잘못된 근거·중복 항목은 전체 갱신을 거부한다. 형식 검증 실패 때만 최대 1회 재시도한다. 정답 상태는 모델에 제공하지 않는다.

6개 항목은 재킷, 상의, 핀, 목걸이, 배경, 배경 소품이다. 지원 값은 `local-studio/request_state.py`에 고정한다. 방법별 모델 호출 수·프롬프트 길이·종합 시간을 기록한다. 서로 다른 호출 예산의 시스템 비교이며 상태 표현만의 인과 효과로 주장하지 않는다.

## 고정 생성 조건

기존과 동일한 실제 인물 사진 R01–R06, 새 8턴 대화 4종, 시드 42·314, 두 방법을 교차해 96장(48쌍)을 모두 생성한다. 각 출력은 최초 원본 사진을 입력한다. FLUX.2 Klein 4B 4bit·4스텝·기존 사진 크기를 유지한다. 방법 순서를 회전한다. 프롬프트·대화·코드·입력 해시를 생성 전에 고정한다. 결과에 따라 프롬프트를 수정하거나 유리한 출력만 남기지 않는다. 형식·실행 실패도 기록한다.

## 평가

1. 상태 추출: 자동 상태와 미리 기록한 정답 상태를 항목별 비교한다. 정답은 프롬프트 생성이 끝난 뒤 평가에만 사용한다. 턴별·최종 정확도와 재시도를 기록한다.
2. 이미지 목표: 대화별 최종 6항목을 방법명을 가린 비교판에서 1/0/판단 불가로 채점한다. 판단 불가는 성공으로 세지 않는다. AI의 시각 판정으로 기록한다.
3. 얼굴: 원본–출력 ArcFace 유사도와 단일 얼굴 검출 여부. 시드·대화는 인물 내 반복 관측이며 독립 인물은 6명이다.
4. 개선 판단: 목표 점수와 얼굴 유사도를 함께 보고한다. 개선·동률·악화 인물 수와 취소 항목의 충족을 보고하고 성공 여부에 관계없이 전체 결과를 보존한다.

이 실험에서 인물 수와 이미지 모델을 확대하지 않으며 기존 108장과 분모를 합치지 않는다.
