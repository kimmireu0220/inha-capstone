# 실행 대상 검사 방법의 새 요청 검증

2026-10-25. 복원 표현 검증 32개에서 발견한 조건부 지시·인용문 오류를 바탕으로 실행 대상 검사 방법을 개발하였다. 이 32개는 실행 대상 검사의 개발 자료이며 개선에 사용하지 않은 대화 네 개, 요청 16개를 별도로 작성하였다. 모든 문장은 서로 다르고 앞선 두 실험의 요청과 겹치지 않는다.

첫 두 대화는 부정문·나중에 수행할 조건부 지시·캡션이라고 명시한 인용문과 다른 항목의 실제 변경을 함께 요청한다. 나머지 두 대화는 앞선 지시와 달리 뒤에서 직접 변경을 요청한다. 정답은 명시한 변경을 누적하여 계산한다. 같은 항목의 뒤 직접 지시가 우선한다. 방법과 요청·정답·설정을 모델 추론 전에 고정한다.

앞선 검증과 동일한 Qwen3-4B-4bit와 Llama-3.2-3B-Instruct-4bit, 온도 0, 최대 260토큰, 같은 지시문과 예시 일곱 개를 사용한다. 모델별 실제 호출 32회, 전체 64회다. 기준·이전 방법 여덟 개와 실행 대상 검사 결합을 비교하고 모든 응답과 결과를 보존한다. 전체 상태·항목별·최종 상태 일치 건수와 기준이 맞았지만 새로 틀린 요청 수를 모델별로 보고한다. 결과를 확인한 뒤 이 자료나 방법을 수정하지 않는다.
