# GPT 에이전트의 사후 이미지 평가

2026-10-26. 사용자의 요청으로 gpt-6.1-sol, reasoning effort low 에이전트 두 개를 새 문맥으로 병렬 호출한다. 기존 이미지 18장과 여섯 목표를 평가한다. 이미지 생성이나 사람 평가는 추가하지 않는다.

기존 평가 계획의 목표와 이미지 해시를 그대로 사용한다. 순서를 시드 20261026으로 섞고 V01–V18 식별자의 사본을 제공하여 생성 방식과 기존 점수를 가린다. 에이전트는 이전 대화·점수·방법 연결표·상대 평가 결과에 접근하지 않도록 지시한다. 각 이미지를 직접 열어 여섯 항목을 1(충족), 0(위반), null(판단 불가)로 평가하고, 항목마다 관찰 근거를 기록한다. 평가 지시에서 좌우는 화면 기준이고, 소품 부재는 실패로 처리한다.

각 평가자의 첫 결과를 보존하고, 두 평가자를 각각 집계한다. 동일 모델의 두 호출이며 독립된 모델 계열 또는 사람 평가로 해석하지 않는다. 합의 점수로 수정하지 않고 평가자 간 일치와 기존 7B 판정과의 차이를 보고한다. 이번 평가는 기존 결과를 확인한 뒤 추가한 사후 대조다. 배포 모델의 내부 버전과 온도는 에이전트 인터페이스에서 지정하지 않았다.
