# 동작 분리 후 값 추출: 개발 실험

2026-10-06. 앞선 C1–C4/V1–V4의 실패를 보고 설계한 개발 후보이며, V1–V4를 재사용한 결과는 별도 검증 성능으로 주장하지 않는다. 통과하면 방법을 고정하고 새 대화에서 비교한다.

첫 호출은 값 코드를 생성하지 않고 6개 항목의 동작만 set/remove/reset/keep으로 분류한다. 두 번째 호출은 원 요청과 첫 동작 계획을 받아 set인 항목의 값만 추출한다. keep은 이전 값, reset은 원본, remove는 none으로 코드가 결정한다. set 값의 어휘 근거와 지원 범위를 기존 규칙으로 검사한다. 잘못된 set 항목은 해당 항목만 이전 값으로 남기며 다른 항목의 검증된 동작을 취소하지 않는다. 이 차이도 시스템 구성의 일부이며 효과가 확인되면 제거 실험으로 분리한다.

같은 캐시 Qwen3-4B-4bit 리비전, 온도 0, 호출당 260토큰, 턴당 정확히 2회 호출이다. 두 번째 호출은 첫 응답이 무효여도 수행하며 무효 계획에서는 모든 항목을 유지한다. 정답은 모델 입력에 포함하지 않고 모든 출력을 저장한 뒤 평가한다. 코드·프로토콜·참조 대화·원래 상태 처리 코드 해시를 첫 실행 전에 고정한다. 원문·거부·시간을 저장한다. 기존 일반 재검토 32회와 같은 논리적 호출 예산으로 비교하되, 실행 시점이 달라 시간은 참고치다.

기존 V1–V4의 일반 재검토+무변경 값 생략(13/16, 93/96)보다 전체 상태 정확도가 높고 새 미변경 항목 훼손이 없으면 새 대화 평가로 진행한다. 그렇지 않으면 오류 원인을 보고 다음 후보를 설계한다. 얼굴 보존과 이미지 성공률은 별도 검증 전까지 주장하지 않는다. 사람 평가를 요구하지 않는다.
