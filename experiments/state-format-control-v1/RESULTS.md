# 전체 대화 상태 추출의 추가 비교

고정한 네 대화의 프롬프트로 48개 조건의 생성, 두 AI 평가, 얼굴 측정을 완료했다. 같은 실제 인물 6명·대화 U1–U4·시드 42와 314를 사용한다. 기존 96장의 두 방법은 이미지와 점수를 그대로 연결했다. 같은 대화를 재사용한 후속 진단으로 새로운 일반화 검증은 아니다.

| 방법 | 1차 AI 목표 충족 | 2차 AI 목표 충족 | 평균 ArcFace |
| --- | ---: | ---: | ---: |
| 자연어 종합 | 194/288 | 257/288 | 0.585593 |
| 자동 상태 갱신 | 240/288 | 261/288 | 0.675335 |
| 전체 대화 상태 추출 | 127/288 | 142/288 | 0.846995 |

추가 대조의 최종 상태는 10/24항목, 대화 단위로는 0/4가 정확했다. U1은 재킷 제거, U4는 배경 교체를 놓쳤다. U2·U3은 두 호출 모두 문자열 대신 배열을 반환해 사전 명세한 원본 유지 처리가 적용됐다. 결과 확인 뒤 프롬프트나 검증 규칙을 바꾸지 않았다.

48개 조건은 모두 새로 생성했으나 U2·U3의 같은 원본 유지 프롬프트 때문에 픽셀이 같은 12쌍이 있다. PNG 기록 정보를 제외한 고유 RGB 이미지는 36종이다. 독립 단위는 인물 6명이며 조건이나 중복 픽셀을 독립 반복으로 세지 않는다. 48장 모두 얼굴 하나가 검출됐다.

1차 AI의 판단 불가는 목걸이 1항목으로 성공에 포함하지 않았다. 2차 AI의 형식 파싱 실패는 없었지만 재킷이 있다고 설명하면서 ‘재킷 없음’을 성공으로 채점하는 모순이 있었다. 원점수와 설명을 보존했다. 전체 세 방법의 두 AI 항목 일치는 693/863이며 1차 판단 불가 한 항목은 제외했다. 일치율은 정확성 검증이 아니다.

프롬프트 준비는 8회 호출·61.4초, 추가 이미지 생성 시간 기록의 합은 5,428.7초다. 지시문·예시·호출 수·1차 채점 시점이 달라 상태 관리만의 인과 효과를 분리하지 못한다. 독립 인간 평가는 없다.

핵심 관찰은 얼굴 유사도가 높아도 요청된 편집을 수행하지 않았을 수 있다는 것이다. 출력 형식 준수와 실패 처리를 포함한 목표 충족을 얼굴 보존과 따로 평가해야 한다.
