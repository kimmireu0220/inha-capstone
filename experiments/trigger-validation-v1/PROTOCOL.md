# 고정 경보 시점의 원본 기반 일괄 적용 검증

## 생성 전 확정

새 가상 인물 P04·P05·P06 각각 원본 1장, 순차 편집 10단계 1회, 최초 LPIPS 경보 단계의 원본 기반 일괄 적용 1회를 생성한다. 최대 원본 3장·순차 30장·대응 3장이다. 각 요청의 첫 성공 출력만 보존한다. 열화가 없거나 대응이 더 나쁜 경우도 제외하지 않는다. 미경보 인물은 대응 미실시로 기록한다.

P03 calls.json의 run=1에 있는 10개 편집 프롬프트와 현재 요구 상태를 그대로 복제한다. 단계마다 새 요구와 전체 현재 요구를 함께 명시하고 직전 순차 결과만 입력한다. 대응 이미지는 원본과 해당 단계의 전체 현재 요구를 사용하며, 대응 결과를 순차 경로에 투입하지 않는다. 따라서 장기 정책 효과가 아닌 경보 시점의 1회 대응 비교다.

MAE≥0.0288375, SSIM≤0.842874, LPIPS Alex v0.1≥0.0555075를 변경하지 않는다. 주 개입 기준은 최초 LPIPS 경보다. 단계 결과를 저장할 때마다 계산하고 최초 경보를 기록한다. 전 단계 지표는 보조 분석으로 모두 보존한다. 정상으로 본 원본만을 보고 각 인물의 320×360 얼굴 ROI를 먼저 고정하며 단계별 이동·색상·크기 보정은 하지 않는다. 원본이 1024×1536이 아니면 임의 리사이즈하지 않고 이탈을 기록한다.

새 인물의 외형은 생성 전에 P04 성인 여성 약 35세 짧은 검정 머리, P05 성인 남성 약 55세 짧은 회색 머리, P06 성인 여성 약 45세 갈색 머리 뒤로 묶음으로 지정한다. 모두 정면·중립 표정·회색 긴팔 티셔츠·회색 배경·동일 촬영 조건이다. 인구집단 대표성이나 외형별 효과는 주장하지 않는다.

내장 이미지 생성 도구를 사용한다. 모델 버전·시드는 직접 고정할 수 없다. 실제 프롬프트·입출력 경로·호출 시각·출력 해시를 보존한다. 품질 재시도는 하지 않으며 도구 오류는 별도 기록한다.

## 평가와 해석

방법과 기존 결과를 가린 독립 에이전트에게 원본·순차·일괄의 전체 이미지 및 같은 얼굴 ROI를 제시한다. 현재 요구 충족, 비요청 얼굴 변화, 피부 자연스러움, 사용 가능 여부를 분리 평가한다. 사람에게도 같은 질문을 제시하며 실제 응답 전에는 결과를 채우지 않는다. 경보 단계만의 평가로 전체 감지 정확도를 주장하지 않는다. 전체 단계 얼굴 평가는 추가 사람 검증 자료로 준비한다.

기존 P03는 탐색 자료, P04~P06는 고정 규칙의 추가 사례로 분리한다. 세 인물·각 한 경로로 일반적인 최적 정책이나 통계적 우월성을 확정하지 않는다. 평가를 본 뒤 임계값·프롬프트를 조정하지 않는다. 요구 충족과 얼굴 지표 개선을 하나의 성공률로 합치지 않는다.
