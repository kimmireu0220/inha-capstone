# 독립 이미지 평가

manifest.json의 세 그룹을 평가한다. 이 폴더의 TASK.md·manifest.json 및 명시된 이미지 파일만 읽는다. 상위 폴더의 매핑·지표·프롬프트·다른 평가를 읽거나 방법을 추측하지 않는다. 모든 원본과 후보의 전체 이미지 및 얼굴 crop, 총 18파일을 직접 열어 본다.

각 후보에 대해 다음을 독립적으로 판단한다.

1. 명시된 각 요구가 반영됐는가? 각각 충족 / 일부만 충족 / 미충족 / 판단 어려움.
2. 원본에 비해 요청하지 않은 얼굴 특징 변화가 있는가? 0 없음 / 1 약함 / 2 뚜렷함 / 3 심함 / 판단 어려움.
3. 얼굴에 새로 생긴 부자연스러운 무늬·변형이 있는가? 같은 0~3 척도. 원본의 주름·모공 및 요청한 장신구는 결함에서 제외한다.
4. 현재 요구를 충족하면서 그대로 사용할 수 있는 인물 이미지인가? 예 / 아니오 / 판단 어려움. 경미한 차이는 허용할 수 있으나 뚜렷한 피부 인위성·요구 누락·비요청 변형은 이유를 명시한다. 전체 이미지의 의상·배경도 확인한다.

각 그룹에서 얼굴 보존·자연스러움 종합 최선 후보 ID를 고른다. 차이가 없다면 두 후보를 모두 선택한다. 어느 방법의 승리도 기대하지 않는다. 각 판단에 보이는 근거를 짧게 적는다. 불확실성은 숨기지 않는다.

응답은 이 폴더 ratings.json과 review.md에 apply_patch로 저장한다. JSON은 groups 배열, 각 그룹 id, candidates 배열(각 id, requirements 배열, face_change, skin_artifact, usable, evidence), best_face_ids 배열로 구성한다. 본인이 실제로 본 파일 목록도 viewed_files에 기록한다. 모델 설정을 확인할 수 없으면 임의로 적지 않는다. 완료 후 간단한 결과를 보고한다.
