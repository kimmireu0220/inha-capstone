# 최종 요구 종합 확대 비교

2026-09-30 생성 전 고정. 직전 [2인물·1이력 예비 실험](../prompt-synthesis-v1/PROTOCOL.md)을 실제 인물 6명·독립적인 편집 이력 3종·시드 2개·방법 3개로 확대한다. 총 6×3×2×3=108개 출력, 인물×이력×시드의 36개 세 조건 비교 세트다. 조건이 정확히 일치하는 기존 R01/R02·H1의 12개 출력은 해시와 입력을 검증해 재사용한다. 나머지 96개만 새로 생성한다. 기존 점수는 확대 평가에 재사용하지 않고 가림 비교판 전체를 같은 기준으로 다시 채점한다.

## 입력과 방법

R01·R02는 기존 실제 인물 사진을 사용한다. R03–R06은 새 Pexels 사진 4장으로, 동일한 사이트 전처리(최대 512×768, 16픽셀 배수)에 따라 한 번 축소한 입력을 사용한다. 사진 출처·크기·해시는 기록한다. 실제 인물 사진은 로컬 모델에만 입력한다.

H1은 기존 8개 요청을 그대로 사용한다. H2는 재킷·핀·목걸이·배경을 수정해 정원과 돌 벤치를 최종 목표로 한다. H3는 최종적으로 재킷과 핀을 없애고 회색 스웨터·금색 원형 펜던트·연한 파란 스튜디오와 화분을 남긴다. 세 이력 모두 이전 조건 4개 이상을 변경하거나 취소한다. 각 이력의 `history.json`과 최종 상태는 생성 전에 고정한다.

방법은 세 가지다. `history`는 요청 전체를 순서대로 이미지 모델에 주고 최신 요청 우선 규칙을 명시한다. `state`는 사람이 미리 구조화한 변경을 코드가 순서대로 적용한 최종 상태만 주는 상한 기준이다. `agent`는 로컬 Qwen3 4B가 자연어 이력만 읽고 초안·원문 대조 두 단계로 만든다. 구조화된 정답을 주지 않는다. 원문에 없는 성별 지칭만 고정 자동 치환하고 전후를 기록한다. 프롬프트는 이미지 생성 전 고정하며 결과를 보고 수정·재선택하지 않는다.

모든 신규 출력은 같은 로컬 FLUX.2 Klein 4B 4bit, MFLUX, 4 스텝, 고정 시드 42·314를 사용한다. 같은 인물·이력·시드의 세 조건은 동일한 입력 크기를 사용하고 실행 순서는 교차한다. 첫 성공 출력을 보존하고 실패 시 같은 조건만 재시도해 기록한다. 원본·프롬프트·입력·출력 해시 및 모델 설정을 검증한다.

## 평가와 해석

이미지 생성 전 각 프롬프트의 최종 목표 6개와 이전 조건 잔존 여부를 기록한다. 생성 후 방법명을 가린 비교판에서 이력별 최종 목표 6개를 각 출력에 대해 0/1/판단 어려움으로 채점한다. 요청하지 않은 얼굴·자세·구도 변화는 별도 메모다. 원본 대비 얼굴 정체성은 InsightFace `buffalo_l` 단일 얼굴 검출(640×640, 임계값 0.5) 및 ArcFace 코사인 유사도로 따로 계산한다. 검출 실패는 결측으로 기록하고 출력을 교체하지 않는다.

주 비교 단위는 인물이다. 같은 인물의 3개 이력·2개 시드는 반복 관측으로, 108장을 독립 표본으로 취급하지 않는다. 방법별 결과는 이력별·인물별로 보고하고, 인물별 차이의 방향 및 분포를 제시한다. `state`는 완벽한 사전 파싱을 받는 상한 기준이므로 구현 비용이 다른 두 방법과 같지 않다. 한 명의 가림 육안 점수이며 인물 6명은 일반화를 보장하거나 검정력을 입증하는 숫자가 아니다.
