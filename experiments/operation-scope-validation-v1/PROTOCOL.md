# 두 모델에서의 복원 표현 처리 검증

2026-10-25. 앞선 요청 48개는 방법 개선에 사용한 개발 자료다. 본 검증에는 새 대화 8개, 요청 32개를 사용한다. 복원 표현, 변경과 복원 혼합, 앞 지시의 수정, 부정·조건·인용의 네 유형마다 대화 두 개를 구성한다. 각 대화의 요청 네 개는 모두 서로 다른 문장이다. 연구자가 구성한 합성 영어 대화다.

방법과 요청·정답을 추론 전에 고정한다. Qwen3-4B-4bit와 Llama-3.2-3B-Instruct-4bit를 비교하며 정확한 배포 리비전과 라이브러리 버전은 frozen.json에 저장한다. 두 모델은 온도 0, 최대 출력 260토큰, 같은 지시문과 예시 일곱 개를 사용한다. 요청마다 추출과 재검토를 한 번씩 수행하고 원문을 모두 보존한다. 모델별 실제 호출은 64회, 전체 128회다. 모델별로 결과를 따로 집계한다.

기준, 기존 유지·삭제, 기존 정규화, 항목별 적용, 기존 정규화와 항목별 적용의 결합, 개선 정규화 및 JSON 최초 응답·재검토 우선 방식의 여덟 방법을 비교한다. 각 모델 안에서는 모든 방법이 같은 두 응답을 사용한다. 첫 응답만 사용하는 JSON 조건의 점수는 첫 응답으로 계산한다. 정답은 채점에만 사용한다.

전체 상태·항목별·최종 상태 일치 건수, 기준이 맞았지만 새로 틀린 요청 수, 유형별 전체 상태 일치 건수를 모두 보고한다. 오류가 남은 항목과 원문 응답도 기록한다. 앞 지시를 수정한 요청은 마지막 지시를 정답으로 한다. 조건부로 나중에 수행하라고 한 요청과 인용문은 현재 상태의 변경으로 계산하지 않는다. 자료나 방법을 결과에 맞춰 수정하지 않는다.
