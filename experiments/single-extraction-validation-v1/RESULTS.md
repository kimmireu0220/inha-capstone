# 한 번 추출한 응답에 지시 검사를 적용한 결과

새 합성 영어 대화 세 개, 요청 12개를 두 모델에 각각 적용했다. 문장은 모두 서로 다르며 이전 자료와 겹치지 않는다. 모든 비교를 위해 실제 호출은 모델별 24회, 총 48회 수행했다. 한 번 추출 조건은 최초 응답만 사용하므로 요청당 한 번 호출하는 방법이다.

| 방법 | 요청당 필요한 호출 | Qwen3-4B | Llama-3.2-3B |
| --- | --- | --- | --- |
| 기준 방법 | 2 | 3/12 | 1/12 |
| 기존 유지·삭제 | 2 | 3/12 | 1/12 |
| 기존 정규화 | 2 | 3/12 | 1/12 |
| 항목별 적용 | 2 | 3/12 | 1/12 |
| 기존 정규화+항목별 적용 | 2 | 3/12 | 1/12 |
| 복원 표현 개선 | 2 | 9/12 | 4/12 |
| JSON 최초 응답 | 1 | 3/12 | 3/12 |
| JSON 재검토 우선 | 2 | 3/12 | 1/12 |
| 추출·재검토+지시 검사 | 2 | 12/12 | 4/12 |
| 한 번 추출+지시 검사 | 1 | 12/12 | 12/12 |

## 한 번 추출과 지시 검사 결합의 상세 점수

| 모델 | 항목별 일치 | 최종 상태 일치 | 추가 오류 수 |
| --- | --- | --- | --- |
| Qwen3-4B | 72/72 | 3/3 | 0 |
| Llama-3.2-3B | 72/72 | 3/3 | 0 |

추가 오류 수는 기준 방법이 맞았지만 해당 방법이 틀린 요청 수다. 호출 수는 방법 실행에 필요한 모델 호출 횟수이며 처리 시간이나 금액의 측정값과 구분한다.

## 재검토의 영향

- Qwen3-4B: 한 번 추출이 맞고 재검토 결합이 틀린 요청 0개, 반대 경우 0개.
- Llama-3.2-3B: 한 번 추출이 맞고 재검토 결합이 틀린 요청 8개, 반대 경우 0개.
