# 한 번 추출한 응답에 지시 검사를 적용하는 방법의 검증

2026-10-25. 복원 표현 검증 32개의 개발 재계산에서 Llama의 재검토가 정답인 최초 응답을 삭제하거나 일부 항목만 남기는 사례를 확인하였다. 같은 개발 자료에 최종 지시 검사를 적용했을 때, 첫 응답만 사용한 경우와 추출·재검토를 사용한 경우는 Qwen3에서 각각 32/32, Llama에서 각각 27/32와 19/32였다. 이 결과를 바탕으로 첫 응답만 사용하는 조건을 새 요청에서 검증한다.

새 대화 세 개, 요청 12개를 구성하고 추론 전에 코드·자료·정답·모델 설정을 고정한다. 문장은 모두 서로 다르고 앞선 개발·검증 요청과 겹치지 않는다. 원본 복원과 유지, 삭제와 부정, 조건문과 인용문, 뒤 직접 지시를 조합한다. 연구자가 작성한 합성 영어 대화다. 정답은 채점에만 사용한다.

같은 Qwen3-4B-4bit와 Llama-3.2-3B-Instruct-4bit, 온도 0, 최대 260토큰, 공통 예시 일곱 개를 사용한다. 요청당 최초 추출과 재검토를 기록하여 모든 비교 방법의 입력으로 사용한다. 실제 실험 호출은 모델별 24회, 전체 48회다. 제안 조건은 최초 추출 응답만 사용하며 재검토 응답에는 접근하지 않는다. 이 조건의 실행에는 요청당 모델 호출 한 번이면 충분하다. 추출·재검토 조건은 두 번이 필요하다. 후처리 코드와 어휘는 변경하지 않는다.

이전 아홉 방법과 최초 추출·지시 검사 결합의 열 방법을 모두 비교한다. 전체 상태·항목별·최종 상태 일치 건수와 기준이 맞았지만 새로 틀린 요청 수를 모델별로 보고한다. 결과를 본 뒤 방법이나 자료를 바꾸지 않는다.
