# P 이미지 결과 해석

전체128조건·68개 고유 생성의 첫 성공 출력을 평가했다. 공통 기준과 유지 보호의 AI 목표 점수는354/384·355/384, 판단 불가는19·18, 얼굴 코사인 평균은0.914851·0.914108이다. 생성 도구 무응답으로 같은 입력을 기술적으로 재시도한 작업1개를 calls.json에 기록했다. 품질에 따른 출력 교체는 없다.

64대응쌍 중60쌍은 같은 입력과 출력을 공유한다. 실제 입력이 다른4쌍에서 목표 점수 차이는+1항목이다. R01-P2-2의 소품이 판단 불가에서 성공으로 바뀐 것뿐이며 확정 실패가 성공으로 바뀐 항목은 없다. R02-P2-2는 양쪽 모두 응답 파싱 실패로6항목 판단 불가다. 서로 다른 입력4쌍의 얼굴 코사인 차이 평균은-0.011885다. 전체 평균이 거의 같다는 사실만으로 얼굴 보존의 동등성이나 비열등성을 주장하지 않는다.

평가 원문에는 명확한 설명–점수 모순도 있다. R01-P5-4 기준 이미지의 응답은 배경이 사무실이 아니라고 설명하면서 여섯 점수를 모두1로 출력했다. 원점수는 바꾸지 않았다. 고유68개 평가 중 JSON 파싱 실패4개가 있으며 총25개 항목을 판단 불가로 기록했다. 공유 조건이 있으므로 이 수와 방법별 판단 불가 합계는 다르다.

따라서 P의 텍스트30→32/32를 뚜렷한 이미지 개선으로 해석하지 않는다. 이 실험은 제한 문형 유지 보호를 사후 선택한 탐색 실험이며 두 인물·고유 차이4쌍·한 AI 평가기만 사용했다. S의 다른 방법·다른 대화 실험과 표본을 합산하지 않는다. paired-audit.json은 모든 대응쌍의 점수·판단 불가·얼굴 차이를 보존하는 사후 기술 집계다.
