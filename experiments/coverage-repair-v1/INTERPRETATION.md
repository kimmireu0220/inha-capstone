# 파일럿 후 원인 대조

16개 요청 전체의 출력을 저장한 뒤 분석했다. 일반 재검토 15/16과 누락 검사 16/16의 차이는 C3-2 한 건이다. C3-2에서 모델은 배경·소품의 올바른 변경과 함께 기존 핀 값을 그대로 반환했다. 핀을 유지하라는 문장에 좌우 위치 단어가 없어 어휘 검사가 이를 거부했고, 같은 JSON의 정상 배경·소품 변경까지 적용되지 않았다. 누락 검사 재검토는 핀을 keep으로 바꾸어 이 거부를 해소했다.

따라서 관찰된 추가 효과는 누락 항목을 찾은 효과로 특정할 수 없다. 출력이 현재 상태와 같은 항목은 실제 변경 검사를 하지 않는 대조를 추가했다. 이 대조는 평가 정답이 아니라 각 방법 자신의 이전 상태만 참조하며 추가 모델 호출이 없다. 원문 JSON과 실제 변경의 검사는 그대로 유지한다.

- 첫 출력만 + 무변경 값 생략: 15/16, 94/96항목.
- 일반 재검토 + 무변경 값 생략: 16/16, 96/96항목.
- 누락 검사 재검토: 16/16, 96/96항목.

이 코드 대조는 파일럿 결과를 보고 설계한 사후 분석이다. 이 자료에서의 동률을 일반적인 효과로 주장하지 않는다. 같은 규칙을 고정한 다음 별도 coverage-validation-v1 대화에 적용한다. 해당 검증에서는 규칙을 실행 전에 고정한다. 이번 결과는 복잡한 프롬프트 검사를 새로운 기여로 성급히 선택하지 않아야 한다는 근거다.
