# 언급 항목 누락 검사: 개발 파일럿

2026-10-06. 이미지 생성 이전의 요청 해석 오류를 줄이는 방법 후보를 검증한다. 이전 U1–U4에서 발견한 누락에 착안했으며, 이 실험은 개발 파일럿이다. 아래 새 대화는 개발자가 작성한 제한 어휘 자료이며 독립 외부 검증 자료가 아니다. 이 결과를 보고 수정한 방법은 별도 고정 평가 세트에서 다시 확인해야 한다.

## 방법과 통제

같은 Qwen3-4B-4bit 리비전, 온도 0, 호출당 최대 260토큰을 사용한다. 매 요청의 첫 JSON 추출은 한 번 실행하고 양쪽이 공유한다. 일반 재검토와 누락 검사 재검토가 각각 두 번째 호출을 사용한다. 방법당 논리적 호출 예산은 턴당 2회다. 공유로 실제 호출은 턴당 3회이며 시간은 첫 호출 비용을 각 방법에 배분한다.

일반 재검토는 원 요청과 첫 출력을 보고 재검토한다. 누락 검사 방법은 같은 정보에 더해 코드가 요청에서 발견한 항목 목록과 누락·형식 오류를 제공한다. 언급된 모든 항목에 대해 변경 코드 또는 keep을 명시하게 한다. 두 방법 모두 같은 허용값·어휘 근거 검사와 상태 누적기를 쓴다. 두 번째 출력이 유효하면 사용하고, 아니면 첫 유효 출력, 둘 다 무효면 이전 상태를 유지한다. 누락 검사 방법의 유효 조건에는 언급 항목의 포함 여부를 추가한다. 두 번째 호출 순서는 대화/턴별로 교대한다.

정답 updates는 모델 입력에 넣지 않는다. 모든 출력 저장 후에만 평가한다. 대화·코드·프로토콜·모델 리비전 해시를 실행 전에 고정한다. 재실행 시 완료된 턴을 재사용하고 파일이 바뀌면 중단한다. 최초 출력과 실패를 모두 보존한다.

## 지표와 진행 기준

주 지표는 요청 이후 6개 항목 전체가 정답인 턴의 수다. 항목 정확도, 최종 대화 정확도, 변경 항목 정확도, 유지 항목 훼손, 형식 실패, 시간, 실제 호출 수도 보고한다. 동일한 첫 출력을 재검토하지 않은 결과도 추가 비용 없는 제거 실험으로 기록한다. 대화가 독립 단위이며 턴을 독립 표본으로 과장하지 않는다.

파일럿에서 전체 상태 정확도가 개선되고 유지 항목 훼손이 증가하지 않으면 독립된 추가 대화 설계 및 이미지 단계 검증으로 진행한다. 동률·악화면 이 후보가 효과를 입증하지 못했다고 보고한다. 이 단계에서는 얼굴 보존이나 이미지 성공률 개선을 주장하지 않는다. 사람 평가를 요구하지 않는다.

## 관련 연구와 차별화 과제

상태 추적 및 항목별 갱신·유지는 기존 연구다. 이 파일럿은 새 원리의 발명 주장이 아니라 제한 어휘 이미지 편집에서 누락 검사 피드백의 추가 효과를 분리하는 실험이다.
