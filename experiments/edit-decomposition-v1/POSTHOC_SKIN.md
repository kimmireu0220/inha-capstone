# 추가 진단 — 피부 내부 영역

주 분석의 14개 출력에 대한 수치를 확인한 뒤 추가한 탐색 분석이다. 사전 계획의 주 지표·출력·순위를 교체하지 않는다.

기존 얼굴 ROI는 얼굴만 분할한 마스크가 아니라 직사각형이므로 머리·경계·배경 일부도 포함한다. 이번 편집에 배경색 변경이 있어 전체 ROI의 차이를 피부 변화로 오인하지 않도록, 과거 실험에서 이미 정한 이마·양 볼 세 영역의 내부 변화를 함께 확인한다. 새 결과에 맞춰 영역을 선택하거나 조절하지 않는다.

- 기존 `nonhuman-followup-v1/metrics/analyze.py`의 REGIONS와 skin 함수를 그대로 사용한다.
- 이마 [452,144,568,178], 보는 사람 기준 왼쪽 볼 [412,264,448,306], 오른쪽 볼 [572,264,604,306].
- 고정 영역과 기존 주 분석에서 계산한 NCC sigma1/3/6 이동을 각각 적용한다.
- 원본 대비 RGB MAE·SSIM·고주파 MAE를 계산한다. MAE·고주파 MAE는 픽셀 수, SSIM은 유효 창 중심 수로 가중한다. 세 영역 수를 표본 수로 세지 않는다.
- 좁은 세 영역만으로 얼굴 전체·동일성·자연스러움·열화 등급을 판정하지 않는다. 이 분석은 배경 영향을 완전히 분리하는 인과 실험이 아니다.
- 동일 입력 제어, 기존 주 분석의 MAE·SSIM 직접 재계산, CSV와 JSON 수치 일치, LPIPS 가중치의 기존 구현 일치를 함께 검사한다.

생성 담당자가 출력에서 남색 셔츠·옅은 파란 배경·보는 사람 기준 오른쪽의 은색 원형 핀을 확인한 것은 비블라인드 실행 점검이다. 크기·색·위치의 정량적 요구 충족 점수, 독립 AI 평가 또는 사람 평가로 기록하지 않는다.
