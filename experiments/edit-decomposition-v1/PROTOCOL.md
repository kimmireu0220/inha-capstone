# 같은 요구의 분할 편집과 무변경 반복 — 사전 실행 계획

2026-09-08. 생성 결과를 보기 전에 고정한다. 내장 이미지 생성 도구의 새 실행이며, 기존 결과를 다시 집계한 실험이 아니다. 인간 응답·기존 인간 라벨은 읽거나 생성하지 않는다.

## 질문과 표본

동일한 최종 요구를 1회 또는 3회로 나누어 적용했을 때 비편집 얼굴의 원본 대비 차이가 어떻게 달라지는가? 무변경 재생성만 3회 반복해도 차이가 축적되는가?

입력은 기존 생성 인물 P04 원본 1장이다. 인물 수 확대가 아니라 요청 구성의 비교가 목적이며, P04 선택은 과거 분석의 ROI·수식 재사용을 위한 것이다. 미관찰 인물 검증이나 일반화 실험으로 부르지 않는다. 조건별 2회 독립 호출 경로를 실행한다. 같은 요청이어도 반복 간 출력을 공유하지 않는다. 시드와 정확한 내부 모델 버전은 노출되지 않아 고정할 수 없다.

## 세 조건

- batch: 원본에서 세 요구를 한 번에 적용. 1회 × 2반복.
- sequential: 직전 결과에서 셔츠 색→배경 색→핀 추가. 각 단계 갱신된 현재 요구를 함께 제공. 3회 × 2반복.
- no_change: 원본에서 시작해 직전 결과를 변경 없이 재생성. 3회 × 2반복. 편집 요구가 없는 진단 대조군이며 편집 성공의 비교군은 아니다.

최종 요구: 기존 긴팔 라운드넥 셔츠를 남색으로, 평평한 스튜디오 배경을 옅은 파랑으로, 보는 사람 기준 오른쪽 가슴에 작은 은색 원형 핀 하나. 얼굴·피부결·머리·표정·시선·자세·프레이밍·인물 조명·바지 등 나머지는 유지한다. 최종 요구는 batch와 sequential에서 동일하다. 모든 출력 1024×1536을 요청한다.

총 14호출을 상한으로 한다. 각 호출 첫 출력만 보존하고 품질 재시도·최선 선택을 하지 않는다. 거절·도구 실패는 원문 기록 후 해당 경로만 중단한다. 다른 모델/API로 전환하지 않는다. 생성 결과가 복수면 첫 반환 이미지가 관측 대상이며 나머지 존재도 기록한다. 같은 단계의 독립 경로는 함께 요청할 수 있으나 단계 간 입력은 반드시 직전 결과다.

## 측정과 산출물

- P04 기존 고정 얼굴 ROI [352, 88, 672, 448], 기존 구현의 RGB MAE·SSIM·LPIPS AlexNet v0.1을 사용한다. 실제 ROI는 실행 전 inputs.json의 P04 값과 대조해 확정한다.
- 원본 기준 고정 영역을 주 분석, 기존 NCC 정수 이동 보정 sigma3를 보조 분석으로 보고한다. sigma1/6도 보존한다. 출력 크기가 다르면 원본 지표를 그대로 계산하지 않고 차이를 명시한다.
- 각 단계의 원본 대비 거리와 직전 입력 대비 거리를 따로 계산한다. 마지막 결과만으로 반복 과정의 차이를 숨기지 않는다.
- batch와 sequential은 반복별 최종값·평균·범위를 제시한다. 2회로 유의성·검정력·모집단 효과를 주장하지 않는다. 세 지표가 갈리는 경우 그대로 보고한다.
- no_change의 수치는 재생성 과정의 차이 반응이며 곧 피부 열화량이나 편집의 인과효과는 아니다. sequential−no_change를 순수한 요구 복잡도 효과로 해석하지 않는다.
- 프롬프트, 단계 입력·출력 SHA256, 시각, 도구 원문, 실패, 입력 원본 해시를 보존한다. 기존 실험·평가·공개 설문은 바꾸지 않는다.
- 생성 담당자의 요구 충족 확인은 비블라인드 실행 점검으로만 기록하며 사람 평가나 독립 AI 평가로 세지 않는다. 피부 자연스러움·동일인 여부의 정답을 만들지 않는다.
