# 유지와 삭제의 명시적 지시 제약

2026-10-06. Q에서 유지 보호가 중간 오류를 막았지만 다음 삭제 요청 누락 때문에 최종 대화 기준을 통과하지 못했다. 이 결과를 본 뒤 v3를 개발했다. 명확한 `X unchanged` 절을 보호하고, `remove X` 절은 지원하는 재킷·핀·목걸이·소품에 한해 없음 값으로 적용한다. 이전 규칙과 같이 인용·조건부·부정·대명사·후속 동일 항목 변경·지원 범위 밖 목적어에는 개입하지 않는다. 원문 근거를 남긴다. 값 변경 전반을 해석하는 범용 문법기는 아니다.

모든 방법은 직접 추출과 일반 재검토 2회, 같은 Qwen3-4B-4bit 리비전4dcb3d101c2a062e5c1d4bb173588c54ea6c4d25, 온도0, 최대260토큰, 같은7예시를 쓴다. 코드 후처리만 다르다. 공통 기반은 기존 일괄 검증·동일 값 생략·원본 복원 제약이다. 정답은 추론에 포함하지 않고 전체 응답 저장 후 채점한다.

P·Q 재계산은 개발 진단이다. 새 S1–S8 8대화·32턴을 코드·프로토콜·모델과 함께 추론 전에 고정한다. 개발자 작성 제한 어휘의 스트레스 검사이며 외부 벤치마크나 대표 사용자 표본이 아니다. 기준, 유지 보호만, 삭제 실행만, 두 제약 결합의 네 방법이 같은 모델 원응답을 사용한다. 각 방법은 자기 이전 상태를 참조한다. 예외나 실패도 제외하지 않는다.

채택 기준은 결합 방식의 전체 상태 정확 턴이 무보호 기준보다 높고, 최종 대화 정확 수가 낮아지지 않으며 새 미변경 훼손이 늘지 않는 것이다. 두 단일 구성요소와 동률이면 결합의 추가 효과를 주장하지 않고 그 결과를 표시한다. 모든 턴·항목 정확 수·최종 대화·새 훼손·근거와 대화별 결과를 제시한다. 같은 대화의 턴은 독립 표본이 아니다.

이미지 우월성은 이 텍스트 기준만으로 인정하지 않는다. 이미지 비교를 진행한다면 S 전체 턴의 실제 두 상태 프롬프트를 먼저 대조하고, 동일 입력은 한 출력을 공유한다. 이미 진행 중인 P v1 이미지 실험은 별도 탐색 실험으로 완료·보존하며 S 검증으로 바꾸지 않는다. 사람 평가 작업은 없다.
