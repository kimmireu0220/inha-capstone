# P03 4단계 대응 비교

R01의 두 반복 최초 뚜렷함(4단계)을 선택한 탐색적 후속 실험이다. 자동 감지 기준을 재선정한 실험이 아니다. 기존 2단계 실험·임계값·사람 응답은 변경하지 않는다.

각 반복의 4단계 기준선과 피부 수정·3단계에서 4단계 재편집·최초 원본에 1~4단계 요구 일괄 적용을 비교한다. 각 방법 첫 성공 이미지 1장, 총 6장만 생성하며 품질 재시도를 하지 않는다. 재편집 입력인 3단계는 사람 약함이며 감지 지표상 이미 경보가 있어 정상/무경보 이미지라고 부르지 않는다.

요구는 양쪽 은색 링 귀걸이, 얇은 은색 목걸이와 작은 원형 은색 펜던트, 인물 왼쪽(화면 오른쪽) 가슴 버건디 원형 핀 하나, 남색 재킷과 아이보리 라운드넥 셔츠다. 배경·얼굴·표정·자세·인물 조명은 유지 대상이다. 원본 기반 일괄 적용은 장신구뿐 아니라 의상도 포함하므로 기존 accessory additions 문구만 current requirements로 바꾼다.

기존 P03 고정 ROI (352,64,672,424), MAE·SSIM·LPIPS 구현과 임계값을 동일 적용한다. baseline 재계산은 기존 4단계 수치와 완전 동일해야 한다. 얼굴 차이 지표는 완성 에셋 품질이나 요구 충족 지표가 아니다. 무작위 불투명 후보명으로 독립 에이전트가 전체 요구와 얼굴 crop을 평가하며 사람 답은 별도 수집한다. 방법·기존 판단을 평가 입력에 포함하지 않는다.
