# P03 단계별 얼굴 열화 평가

0~3 얼굴 열화 문항 20개만 유지한다. `face-responses.json`은 기존 혼합 제출에서 얼굴 응답 객체를 변경 없이 추출한 파생 자료이며 원본 제출을 새로 받은 것이 아니다. 원본 SHA256과 제출 시각을 기록했다. 대응 후보 선택 6문항은 형식 불일치로 삭제했다.

단계가 보이는 역사적 평가이므로 현재 최종 출력 평가와 합산하지 않는다. 과거 9~10단계 응답을 현행 교체 이미지에 적용하지 않는다.
