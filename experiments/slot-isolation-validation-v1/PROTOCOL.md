# 항목별 오류 격리의 별도 고정 검증

2026-10-06. N·M 사후 개발 후 방법을 고정하고 O1–O8의 새 8대화·32턴을 추론한다. O 대화는 개발자가 작성한 제한 어휘 검사이며 외부 사용자 데이터가 아니다. 이 연구 과정에서 여러 후보가 탈락한 사실을 공개하며 O 결과 하나를 독립적인 확증 연구나 일반 우월성으로 주장하지 않는다.

Qwen3-4B-4bit 리비전 4dcb3d101c2a062e5c1d4bb173588c54ea6c4d25, 온도0, 기존 7예시, 응답 상한260토큰을 유지한다. 각 요청의 직접 추출 및 일반 재검토로 2회, 총64회 호출한다. 같은 저장 출력에 서로 다른 적용 코드를 실행한다. 상태와 정답을 추론 모델에 주지 않는다. 모든 원문 저장 후 정답과 대조한다.

주 비교는 일반 재검토+무변경 생략+명시적 복원 제약 대 항목별 거부+동일 복원 제약이다. 최신 패치 선택은 같고 일괄 거부만 수행하는 대조를 포함해 효과를 분리한다. 복원 제약을 제거한 항목별 처리와 첫 추출만 사용하는 항목별 처리도 제시한다. 각 방법은 자기 이전 상태를 사용한다. 유리한 응답을 정답을 보고 선택하지 않는다.

사전 이미지 진행 기준: 항목별 처리+복원 제약의 전체 상태 정확 턴 수가 기존 대조와 최신 패치 일괄 거부 대조 각각보다 높아야 한다. 최종 대화 정확 수는 두 대조보다 낮아지지 않고, 새 미변경 항목 훼손 수도 많아지지 않아야 한다. 모든32턴을 포함하고 실패·JSON 오류를 제외하지 않는다. 대화가 의존 단위이므로 턴을 독립 표본으로 간주한 유의성 주장을 하지 않는다.

기준을 통과하면 O1–O8의2턴과4턴, R01/R02, 두 주 방법을 전부 이미지로 비교한다(64조건). 중복 원본·프롬프트·시드·설정은 출력 한 개를 공유하며 실제 고유 생성 수를 명시한다. 이미지 모델 실행 경로는 사용자 확인에 따른다. 생성 전 원본과 목표의 의존성 충돌 진단을 고정하되 어려운 조건을 제외하지 않는다. AI 목표 충족과 얼굴 지표를 분리하며 사람 평가 작업은 없다.
