# 판정과 다음 단계

고정 기준상 텍스트 단계는 통과했지만 개선은 O5의3턴 소품 변경 한 항목에만 있다. 사전 이미지 계획의2턴·4턴에서는 두 방법의 상태와 렌더링 프롬프트가 모두 같다. `image_input_audit.py`로16개 대화·시점의 프롬프트 바이트를 대조했다. 두 인물로 확장해도32쌍 모두 같은 입력이다.

따라서 이 계획으로 생성한 이미지 사이의 확률적 차이를 방법 효과로 해석할 수 없다. 동일 입력을 불필요하게 생성하지 않고 이미지 실험을 유보한다. 이미지 개선을 측정한 것은 아니다. 결과를 본 뒤3턴만 골라 기존 계획의 확증 실험처럼 바꾸지 않는다. 다음 고정 검증에서는 모든 턴을 포함할 계획을 먼저 정한다.

두 방법 모두 O4-3에서 유지할 식물을 일반 재검토가 none으로 바꿨다. 최초 출력은 해당 항목이 맞았고 재검토가 훼손했다. O7-2에서는 초록 재킷으로 변경하라는 요청을 keep으로 잘못 추출했다. 항목별 처리만으로 의미 오류를 해결하지 못한다. 다음 개발 후보는 명시적 유지 요청을 이전의 자기 상태와 대조해 보호하는 규칙이다. O 결과를 이용한 개발 결과와 새 검증을 구분한다.
