# 명확한 불변 지시만 보호하는 두 번째 구현

2026-10-06. v1의 P 결과와 사후 경계 진단을 본 뒤 개발했다. `keep X off`·색 지정·대명사를 통한 후속 변경에서 과잉 보호가 발견되어, v2는 허용 명사·수식어로 된 `keep/leave/retain X unchanged` 절만 보호한다. 대명사, 조건부·부정·인용, 원본 복원, 뒤의 동일 항목 변경이 있으면 개입하지 않는다. 지원하지 않는 표현은 기존 추출·재검토 결과에 맡긴다. 정답 상태를 읽지 않고 자기 이전 상태만 사용하므로 이미 잘못된 값을 복구하지 못한다.

단위 테스트와 P 재실행은 개발 진단이다. P의 기존 결과·방법 해시·이미지 프롬프트는 바꾸지 않는다. v2와 v1의 P 관측 상태가 모두 같은지 직접 비교하고, 같더라도 P를 v2의 별도 검증으로 부르지 않는다.

다음 Q 검증은 코드와 새 대화·모델 설정을 추론 전에 고정한다. 비교는 동일한 두 Qwen 호출의 응답을 쓰는 무보호 기준, v1 보호, v2 보호다. 재킷·상의·핀·목걸이·배경·소품 6항목을 평가한다. Q는 8개 대화·32턴으로 명확한 불변 절과 범위 밖 변경 표현을 섞은 개발자 작성 스트레스 검사다. 새 실사용 데이터가 아니고 표현 빈도를 대표하지 않는다. 전체 모델 추론이 끝난 뒤 정답과 비교한다.

v2 채택 조건은 전체 상태 정확 턴이 무보호보다 낮지 않고 v1보다 높으며, 새 미변경 항목 훼손 수와 최종 대화 정확 수가 무보호보다 나쁘지 않은 것이다. 이 조건은 과잉 보호 억제를 검증하며 이미지 우월성을 뜻하지 않는다. 대화별·항목별·보호 개입 횟수와 모든 원응답을 보존한다. 기준 미달이면 일반적 개선을 주장하지 않는다. 이미지 단계는 현재 진행 중인 v1 P 탐색 실험과 분리한다. 사람 평가 작업은 없다.
