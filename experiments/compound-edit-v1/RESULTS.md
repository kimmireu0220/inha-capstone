# 포즈와 표정을 포함한 복합 요청 검사

2026-10-08. 코드·요청·정답을 추론 전에 고정한 별도 확장 실험이다. 기존 S·T와 어휘, 예시 및 구현이 다르므로 결과를 합산하지 않는다. 최초 추출과 재검토에 총 96회 로컬 모델 호출을 사용했다.

## 상태 갱신

네 시나리오에 세 조건을 적용했다. 조건마다 네 턴이므로 12대화 48턴이다. 표정 목표는 같은 시나리오의 조건 사이에서 같다. 정확한 턴은 아홉 항목이 모두 정답인 경우다.

| 요청 조건 | 최초 추출 | 재검토 | 규칙 보정 |
| --- | --- | --- | --- |
| 표정 | 16/16 | 16/16 | 16/16 |
| 표정·몸 방향·손동작 | 16/16 | 16/16 | 16/16 |
| 속성 변경·유지·삭제·복원 혼합 | 4/16 | 4/16 | 16/16 |

표정·몸 방향·손동작은 모든 방법에서 조건별 48/48이었다. 혼합 조건의 전체 항목 정확도는 최초 추출·재검토 각각 124/144, 규칙 보정 144/144였으며 최종 정답 대화는 각각 0/4, 0/4, 4/4였다. 새 유지 오류는 세 방법 모두 0이다. 최초 추출은 턴당 한 번, 나머지는 두 번 호출한다. 재검토와 규칙 보정의 호출 수만 같다.

네 시나리오 모두 2턴의 식물 삭제를 `original`, 3턴의 목걸이 삭제도 `original`로 추출했다. 정답은 둘 다 `none`이다. 재검토도 같은 오류를 유지했다. 식물 오류가 세 턴, 목걸이 오류가 두 턴에 남아 4×(3+2)=20개 항목 오류가 되었다. 독립적인 20종 오류가 아니다.

결과 확인 후 삭제 규칙만 적용한 사후 재계산도 전체 48/48이다. C에서 유지·복원 규칙을 더한 효과는 없다. 규칙의 지원 문형을 반복한 검사이며 자유로운 사용자 대화나 포즈 전반의 성능을 나타내지 않는다. 단일 조건에는 삭제가 없어 세 조건의 차이를 포즈 복잡도의 인과 효과로 설명할 수 없다.

## 짧은 동작 대조

C 결과를 본 뒤 삭제·복원 단독 요청 네 개와 조합·순서 대조 네 개를 고정하여 16회 추가 추론했다. 최초 추출과 재검토 모두 7/8이다. 단독 요청은 네 개 모두 맞았지만 `Remove the plant. Restore the necklace to the original.`에서 식물도 원본으로 해석했다. 두 문장의 순서를 바꾸면 맞았다. 포즈를 넣지 않아도 동작 조합에서 오류가 발생한 사례다. 사후 진단이며 C의 48턴에 합산하지 않는다.

## 이미지 생성과 AI 평가

텍스트 집계 결과를 읽기 전에 C1 첫 턴의 세 조건과 두 원본 인물을 선택했다. 정답 요청을 직접 전달해 첫 성공 출력 6장을 생성했다. 출력 선별이나 재생성은 하지 않았다. 이미지 도구의 내부 모델 버전·시드는 공개되지 않는다.

| 인물 | 표정 | 표정·포즈 | 속성 지시 혼합 |
| --- | --- | --- | --- |
| R01 | 판단 불가 1개 | 2/3 | 5/6 |
| R02 | 판단 불가 1개 | 2/3 | 5/6 |

Qwen2.5-VL-7B-4bit의 원점수다. 표정 단독 두 응답은 예시 JSON을 복사하여 목표 수와 점수 수가 일치하지 않았다. 나머지 네 응답은 목표 문구를 설명에 반복하고, 몸 방향이 맞다는 설명과 실패 점수 0을 함께 반환했다. 점수를 임의 수정하지 않았다. 이 평가로 생성 성공률이나 몸 방향의 정답을 확정할 수 없다. 정답 요청을 직접 입력한 예비 검사이므로 규칙 보정의 이미지 품질 개선을 증명하지 않는다.

## 재현 자료

- `PROTOCOL.md`, `benchmark.json`, `frozen.json`: 텍스트 추론 전 고정 자료
- `run.py`, `transcripts.json`, `results.json`: 실행 코드와 전체 응답, 방법별 상태
- `check_operations.py`, `operation-control-frozen.json`, `operation-control.json`: 사후 진단의 새 추론
- `image_protocol.md`, `image-plan.json`, `generation-log.json`, `images/`: 이미지 선택 기준·요청·첫 출력
- `evaluate_images.py`, `image-evaluation-frozen.json`, `image-ratings.json`: 평가 전 고정 설정과 전체 원문
- `report.py`, `summary.json`, `verification.json`: 재계산과 해시 검사

`python -m unittest discover -s experiments/compound-edit-v1 -p 'test_*.py'`로 코드 검사를, `python experiments/compound-edit-v1/report.py`로 저장된 응답의 재집계를 수행한다. 재집계에는 모델 추론이 필요 없다. 원본 고정 파일을 수정하면 검증을 중단한다.
