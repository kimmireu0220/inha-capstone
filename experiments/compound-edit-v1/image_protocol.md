# 복합 요청의 이미지 생성 진단

2026-10-08. 텍스트 추론 실행 중, 집계 결과를 읽기 전에 선택 기준을 정한다. C1의 첫 턴을 세 복잡도에서 각각 사용하고 R01/R02에 적용한다. 총 6조건이다. 성공하거나 실패한 턴을 보고 선택하지 않는다. 요청을 정확히 종합한 정답 조건만 먼저 생성하므로 방법 간 우월성 검사가 아닌 생성 단계의 진단이다.

기존 실험의 동일 원본 사진을 사용한다. 단일 조건은 입을 다문 미소, 복합 조건은 여기에 몸을 인물 기준 왼쪽으로 돌리고 오른손을 드는 요청, 혼합 조건은 남색 재킷·파란 배경·식물 추가를 결합한다. 나머지 요소를 원본대로 보존하도록 모든 조건에 같은 문장을 사용한다. 직접 편집 요청을 내장 이미지 생성 도구에 전달한다. 첫 성공 출력만 사용하며 미관이나 목표 충족 여부를 보고 다시 생성하지 않는다. 모델 내부 버전과 시드는 통제하지 않는다.

평가에는 기존 로컬 Qwen2.5-VL-7B 4비트 모델을 사용한다. 생성에 사용한 요청 대신 별도로 기술한 시각적 목표를 전달하고 각 목표에 1/0/null과 설명을 받는다. 단일 조건은 표정, 복합 조건은 표정·몸 방향·손동작, 혼합 조건은 여기에 재킷·배경·식물을 평가한다. 조건마다 분모가 다르므로 성공 총수만으로 난도를 비교하지 않는다. 두 인물별 항목 판정을 그대로 제시하고 판단 불가와 설명 모순도 남긴다. 몸 방향은 인물 자신의 왼쪽, 즉 카메라에서 보아 오른쪽으로 돌아간 상태로 정의한다.

6조건은 생성 가능성을 살펴보는 예비 검사이며 반복 생성의 성공률이나 방법의 이미지 성능으로 해석하지 않는다. 이 이미지에 대한 AI 평가는 사람 평가를 대체한 정답으로 취급하지 않는다.
