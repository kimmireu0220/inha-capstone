# 포즈·표정 복합 요청의 상태 갱신 검사

2026-10-08. 기존 S·T 결과를 본 뒤 설계한 별도 확장 실험이다. 기존 실험의 사전 가설로 소급하지 않는다.

네 시나리오 × 세 복잡도 × 네 턴 = 12대화 48턴을 비교한다. 단일 조건은 표정만, 복합 조건은 표정·몸 방향·손동작을, 혼합 조건은 이에 의상·배경·소품의 변경·유지·삭제·복원을 결합한다. 같은 시나리오의 표정 목표는 세 조건에서 같다. 시나리오는 연구자가 구성한 영어 합성 요청이며, 조건 간 문장 길이와 동작 수도 함께 변한다. 따라서 복잡도의 인과 효과나 일반 사용자 성능으로 해석하지 않는다.

기존 여섯 항목에 body_direction, hand_pose, expression을 추가한 아홉 항목을 사용한다. direct는 최초 추출, review는 추출 후 한 차례 재검토, guarded는 review와 같은 응답에 명시적인 keep unchanged/remove/restore 절의 제약을 적용한다. guarded는 확장된 상태 표현과 새 보수적 절 검사를 사용하므로 기존 S·T 구현과 동일한 방법으로 합산하지 않는다. direct는 한 번, 나머지 두 방법은 두 번 호출하는 조건이다. review 대 guarded만 호출 수가 같다.

모델은 기존 Qwen3-4B 4비트 양자화 버전, 온도 0, 최대 출력 320토큰이다. 모든 방법은 현재 요청만 읽으며 실제 이전 상태는 각 방법이 따로 유지한다. 정답은 추론 입력에 제공하지 않는다. 예시는 평가 대화와 별도로 두 개만 고정한다. 자유로운 포즈 전반을 표현하는 것이 아닌 정해진 상태 값의 검사다.

코드·요청·정답·모델 버전은 추론 전에 SHA-256으로 고정한다. 첫 응답과 재검토 원문을 모두 보존한다. 중단 후 재개 시 기존 응답을 다시 생성하지 않는다. 형식이 잘못된 응답은 직전 유효 응답으로 되돌리고, 모두 잘못되면 이전 상태를 유지한다. 원문 중복 키와 허용되지 않은 값은 오류로 처리한다.

전체 아홉 항목 정확 턴, 요청에서 바뀌어야 하는 항목 정확도, 표정·몸 방향·손동작 정확도, 최종 상태 정확 대화 수, 새 유지 오류를 조건별로 보고한다. 세 복잡도는 대응 시나리오이므로 독립 표본으로 합산하여 통계적 유의성을 주장하지 않는다. 특정 방법이 실패한 턴도 제외하지 않는다.

이미지 검사는 상태 갱신 결과와 별도로 수행한다. 생성 전 선택 기준과 모든 입력을 고정하고, 정답 상태를 직접 입력한 조건을 포함하여 요청 종합 오류와 생성 오류를 구분한다. 이미지 평가 결과 없이 이미지 품질 향상을 주장하지 않는다. 사람 평가는 수행하지 않는다.
