# 동작 분리 상태의 이미지 단계 검증

2026-10-06. action-plan-validation-v1의 추론 전 계획에 따라 N1–N6의 2턴과 4턴을 전부 사용한다. 좋은 사례만 고르지 않는다. R01·R02 원본 사진, 일반 재검토+무변경 값 생략 및 동작 분리의 관측 상태를 기존 render_prompt로 변환한다. 정답 상태는 생성 프롬프트에 사용하지 않는다. 6대화×2시점×2인물×2방법=48조건이다.

실행 백엔드는 사용자 확인 후 첫 이미지 생성 전에 고정한다. 기존 로컬 FLUX.2 Klein 4B·4bit·4스텝·시드42를 유지하는 경로를 우선 확인 중이다. 내장 이미지 생성 도구를 선택하면 별도 모델 실험으로 기록하며 노출되지 않은 모델 버전·시드 제어를 주장하지 않는다. 실행 조건 확정 전 이미지를 생성하지 않는다.

같은 원본·프롬프트·시드·생성 설정의 중복 조건은 한 출력만 생성해 공유하며 48장을 모두 독립 생성했다고 표현하지 않는다. 각 조건과 실제 고유 생성의 연결을 남긴다. 조건 순서에서 방법은 교대하며 최초 성공 출력을 보존한다. 코드·원본·프롬프트·상태 원자료 해시를 생성 전에 고정한다. 안전한 재개는 기록과 파일 해시가 일치할 때만 허용한다.

## 평가

방법을 가린 각 출력의 6항목 목표를 고정 Qwen2.5-VL 3B로 한 번 채점한다. 성공1/실패0/판단불가null이며 null은 성공으로 세지 않는다. 목표는 정답 상태를 원본의 가시적 속성에 대응시켜 생성한다. 평가 모델에는 생성 방법·프롬프트·상태 추출 점수·ArcFace 값을 주지 않는다. JSON 실패는 결측으로 보존하고 유리한 점수를 얻기 위해 재시도하지 않는다. AI 점수와 설명 모순은 원문 그대로 보존한다.

원본 속성 대응: 두 원본 모두 재킷·핀·목걸이·식물/램프/벤치가 없다. R01의 원래 상의는 회색 반소매 티셔츠, 배경은 밝은 무채색 벽이다. R02의 원래 상의는 흰 반소매 티셔츠, 배경은 회색 질감 벽이다. 이 대응은 출력 생성 전 원본을 보고 고정했으며 실험 결과 이미지 평가가 아니다. original과 none이 가시적으로 같은 속성은 기호 상태 오류와 시각 실패를 구분한다.

InsightFace buffalo_l의 원본 대비 얼굴 코사인 유사도와 검출 얼굴 수를 별도로 계산한다. 요청 반영 없이 얼굴 점수만 높은 결과를 성공으로 부르지 않는다. 목표 성공 항목 수, 6항목 모두 성공한 출력 수, 얼굴 평균·인물별 수치, 실패/결측과 실제 생성 수를 모두 제시한다. 두 인물·한 시드의 제한된 이전 단계 검증이며 일반화나 새 알고리즘 우월성을 확정하지 않는다. 사람 평가 작업은 없다.
