# 생성 전 평가 준비 기록

2026-10-06. 이미지 생성은 아직 시작하지 않았다. 준비된 48조건과 프롬프트는 변경하지 않는다. `goals.py`, `evaluate.py`, `measure_faces.py`는 고정 목표의 AI 평가와 원본 얼굴 비교를 구현한다. 평가 모델은 방법 이름과 상태 추출 점수를 보지 않는다. 판단 불가와 JSON 오류는 성공으로 세지 않고 원문을 남긴다. 같은 출력·목표 쌍은 한 번 평가하고 조건별로 연결한다.

원본에 옷깃이 있는 재킷이 없는데 옷깃 핀을 유지하는 상태는 시각적으로 충돌할 수 있다. `preflight.py`는 생성 전에 이 의존성만 진단한다. 완전한 의미 이해나 모든 모순 검출을 주장하지 않는다. 조건을 제외하거나 프롬프트·정답을 수정하지 않는다. 주 집계에는 모든 조건을 포함하고, 이 플래그별 집계는 보조 진단으로만 제시한다. 이미지 결과를 본 뒤 어려운 조건을 삭제하지 않는다.
