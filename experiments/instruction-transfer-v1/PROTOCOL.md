# 표현과 지시 순서를 바꾼 추가 검증

2026-10-25. 기존 논문 검증을 마친 뒤 구성한 추가 실험이다. 기존 정규화 구현, 모델, 예시와 설정을 수정하지 않는다. 아래 요청과 정답은 결과를 확인하기 전에 고정한다. 연구자가 구성한 합성 영어 요청이며 실제 사용자 관측과 구분한다.

네 가지 편집 조건마다 세 표현 유형을 비교한다. 기존 어휘의 새 조합, 기존 규칙이 직접 다루지 않은 표현, 같은 대상에 대한 앞 지시를 뒤에서 바꾸는 표현이다. 각 대화는 초기 설정, 복원과 유지, 삭제와 유지, 별도 변경의 요청 네 개로 구성한다. 대화 12개와 요청 48개에 추출·재검토를 각각 한 번 수행한다. 실제 모델 호출은 96회다. 같은 목표를 표현 유형별로 반복하며 반복된 초기 설정과 후속 요청은 서로 다른 문장으로 집계하지 않는다.

정답은 명시한 항목별 변경을 누적하여 계산하고 채점에만 사용한다. 모든 방법은 같은 원래 요청과 모델 응답을 사용하며 각자 저장한 상태를 이어서 갱신한다. 기준, 기존 유지·삭제, 정규화, 항목별 적용, 두 처리의 결합 및 단순 JSON 적용 두 방법을 비교한다. 전체 상태, 항목별, 마지막 요청 후 상태의 일치 건수와 기준이 맞았지만 새로 틀린 요청을 집계한다. 표현별 두 번째와 세 번째 요청의 결과를 따로 보고한다.

결과가 낮아도 요청을 제거하거나 같은 실험의 구현을 수정하지 않는다. 코드 개선이 필요하면 이 실험을 개발 자료로 명시하고 이후 검증은 새 자료로 수행한다. 원문 응답과 모든 결과를 보존한다. 이 실험의 측정 대상은 편집 조건의 기록 정확도다.
