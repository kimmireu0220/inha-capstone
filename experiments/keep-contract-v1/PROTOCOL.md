# 명시적 유지 제약: 개발 단계

2026-10-06. O4-3에서 재검토가 정상 식물 유지 출력을 삭제로 바꾼 오류를 보고 개발했다. keep/leave/retain 절의 항목은 해당 방법의 자기 이전 상태로 보호한다. 정답 상태를 사용하지 않는다. 원본 복원은 기존 별도 규칙으로 처리한다. 인용·조건·부정·원본 언급·뒤에 재언급된 항목에는 유지 규칙을 강제하지 않는다. 변경 동사의 진행형도 절 경계로 인식한다.

N·M·O 저장 출력을 재사용한 분석은 전부 사후 개발로 표시한다. 일반 일괄 검증과 항목별 처리 모두에 같은 유지·복원 규칙을 적용해 각 요소를 분리한다. 새 추론 호출은 없다. 모든 대화와 오류를 보존하며 원하는 결과가 나온 대화만 선택하지 않는다.

이 규칙은 제한된 영문 요청용 보완 코드다. 일반 자연어 해석, 원본 시각 속성 인식, 조건부 의존 관계 해결, 모순 없는 편집을 보장하지 않는다. 다음 고정 검증에서는 대화의 모든 턴을 이미지 비교 대상으로 미리 지정하고, 그림으로 이어지는 입력 차이가 있는지 생성 전에 검사한다.
