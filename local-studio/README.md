# 원본 스튜디오 — 로컬 편집기

M1·16GB에서 검증한 공개 모델을 연결한 로컬 전용 시제품. 기존 공개 설문과 별도 서비스이며 인터넷에 배포하지 않는다.

시작: 저장소 루트에서 `./local-studio/start.sh`, 이후 http://localhost:8770 접속. 이미지 모델 `.venv-local-image`, 언어 모델 `.venv-local-prompt`, 웹 서버 `.venv-metrics` 환경을 사용한다. 의존성 잠금 기록은 experiments/local-open-model-v1에 있다. 모델은 최초 실행 때 Hugging Face 캐시가 필요하다.

사용 순서:
1. PNG/JPG/WebP 원본 업로드 또는 연구 샘플 선택.
2. 대화로 셔츠 색·배경·원형 핀의 현재 요구 갱신.
3. 표시된 설정을 확인. 필요하면 직접 수정하고 저장.
4. 원본에서 새로 생성. 직전 생성물을 입력으로 사용하지 않는다.
5. 버전 이력에서 이미지와 당시 설정 복원. 다시 생성하면 그 버전을 부모로 새 결과 저장.

원본은 별도 보존하고 모델 입력은 최대512×768,16픽셀 배수로 축소한다. 얼굴·자세 보존은 프롬프트 요청이며 보장되지 않는다. 무료 모델 Qwen3 4B는 요청 해석, FLUX.2 Klein4B 4bit는 이미지 편집을 담당한다. 모델은 동시에 실행하지 않는다. 요청 해석과 생성은 분리되어 사용자가 해석한 설정을 확인할 수 있다. 자의적인 편집 요구까지 모두 지원하는 범용 챗봇은 아니다.

데이터: `local-studio/data/` (Git 제외). 각 원본, 축소 참조 이미지, 상태, 요청 이력, 생성 결과, 시드, 프롬프트, 모델 메타데이터/로그가 로컬에 저장된다. 서버 재시작 시 미완료 표시를 해제하며 완성된 이전 버전은 보존한다. 중단된 생성은 자동 재실행하지 않는다. 이미지 업로드는15MB 이하, 처리 허용 최대24MP다. 외부 호출이나 유료 API는 없다. 파일 저장은 원자적 교체, 설정 변경에는 revision 검사를 사용한다.

보안 범위: 루프백127.0.0.1만 바인딩, Host 검사, 상태 변경 토큰, 경로 제한. 인터넷 공개/다중 사용자 운영용 인증·격리는 구현하지 않았다. 이 서버를 포트 포워딩으로 공개하지 않는다.

검증: `local-studio/smoke.py`는 실제 모델을 호출해 한국어 요청→생성→결과 조회→설정 수정→버전 복원→오래된 revision 거부를 확인한다. 실행할 때 실제 생성1회와 새 로컬 작업이 생긴다. 생성까지 약1~3분 이상 걸릴 수 있다. 로그와 결과는 data에 보존한다.

요청 해석 개선: 명확한 기본 표현은 동작 단위로 해석하고, 다른 표현은 모델이 구조화된 동작을 반환한다. 원본 복원은 색을 추정하지 않고 original로 지정한다. 모호한 이전 시점/취소 요청은 설정을 유지하고 이전 버전 선택을 안내한다. 질문은 대화 이력에도 저장된다. 최신 회귀 확인은 checks/RECHECK.md 참고.
